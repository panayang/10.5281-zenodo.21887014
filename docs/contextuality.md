# 上下文性在框架里能住在哪里（2026-09-30，空处 6）

> 不以量子为形状（D13）。这里只用 p-ZFC 的语言问一个结构问题：局部律能否粘成全局律（粘合失败度 η），以及在我们的框架里 η > 0 需要放宽什么。
> 量子理论的 Bell/Kochen–Specker 违背只作对照：它说明现实里 η > 0 的情形存在。

## 1. D1 的框架是非上下文的（命题 Q1）

在一个汇合分支内，D1 给出一个全局的（随机）(S, ≺, μ)；任何关于记录的问题——计数、关系、任意一种分块下的粗权重——都是它的函数。
所以所有语境（观察者选的分块、问的问题）上的局部律都是同一个全局律的边缘：**η = 0**。
- 这不是缺陷，而是 D1 推导里用到的粘合假设的直接后果：加细方向是有向的（D16：任意两个加细有公共加细），在有向语境上权重粘合（p-ZFC 权重层 = Kolmogorov）。
- 对照：F9 里的"视界诱导的上下文性"只出现在不汇合的分支之间（且至少两个空间维），实验室里没有视界，用不上。

## 2. η > 0 需要什么（命题 Q2）

p-ZFC："隐藏的全局结构存在 ⟺ 局部律能粘合"。D1 的全局结构来自两处粘合：宽度方向（汇合）与高度方向（加细有向）。宽度方向的失败就是视界（F7），已经有了。
**高度方向的失败 = 同一个世界有两种加细，没有公共加细**：沿一条加细路径产生的细记录，与沿另一条路径产生的细记录，不能同时存在于任何更细的世界里。
- 在这种情况下，每条加细路径上仍有 D1 式的局部表示，但它们不必是同一个全局核的边缘——各语境的律可以相容于重叠处（事实相容，P1）而没有全局律：η > 0 成为可能。
- 所以**在本框架里，上下文性 ⟺ 加细系统不是有向的**（必要条件已证；充分性只在形式上成立：任一上下文律族都可实现为互不相容的加细——把每个语境当作一条加细路径——但一个**自然的**、由原则产生的例子还没有）。这与"不汇合 ⟺ 视界"是同一个结构在两个方向上的出现：
  宽度方向的不汇合给出视界，高度方向的不有向给出不相容的加细。
- 对照（只作对照）：量子理论里不相容的测量，正好是"同一系统的两种更细描述，没有共同的更细描述"。本框架没有借用希尔伯特空间，只是指出这个结构位置。

## 3. 代价与开放问题

- 放弃加细的有向性，D1 的推导（Mecke、Janson 的粘合）只在每条加细路径内成立；"没有最细层"要改写成"每条路径都没有最细层"。
- p-ZFC 说上下文性与世界的合并在两个方向上相互独立。本框架里两种失败也可以分别出现：加速宇宙有视界，而每个汇合分支内 η = 0（D1）；循环核（§5 Q5）在无视界的平直律里给出 η > 0；F9 表明视界本身在 ≥ 2 个空间维时也能诱导上下文性。所以宽度与高度两种粘合失败**互相独立**，但前者可以诱导后者。
- law §7.2 的预序团（记录彼此没有先后）是另一个开口：团内记录的"先后"不是事实；它能否产生 η > 0，未知。
- **判断**：到目前为止框架是经典的（非上下文）。这是一个明确的地位陈述：若要容纳现实里观测到的上下文性，最小的放宽是加细的有向性，而不是局域性或因果序本身。

## 4. 一个由框架自身产生的例子：团的两两分辨（命题 Q3，`calc/q1_cluster_contextuality.py`）

**两种"团"要分开**
- (i) **永久双向相关**（F23，核的预序类）：团内记录彼此都在对方之前。加细永远不产生序。它不产生上下文性。
- (ii) **先后尚未成为事实**：团内两个记录之间的先后问题还没有被记录回答。加细可以回答它——这只**添加**事实，不改变已有事实，所以与 M4 相容。
  （若从 (i) 出发再"分辨"，就要把"b 在 a 之前"改成不成立，违反 M4；所以上下文性只能来自 (ii)。）

**设定** 三个记录 a、b、c 在一个 (ii) 型团里。语境 {x, y} = 一个只回答 x、y 先后的加细。三个语境两两不能同时实现（没有公共加细）。
律：`P(a≺b) = P(b≺c) = P(c≺a) = q`。全局候选 = 三个记录上的线性序（每个加细都回答所问的一对）。

| q | 三个循环概率之和 | 非上下文分数 NCF | η |
|---|---|---|---|
| 0.5–2/3 | ≤ 2 | 1 | 0 |
| 0.75 | 2.25 | 0.75 | 0.25 |
| 0.9 | 2.7 | 0.30 | 0.70 |
| 1 | 3 | 0 | 1（强上下文） |

`NCF = min(1, 3(1 − q))`，`η = max(0, 3q − 2)`：**η > 0 恰好在孔多塞界（law §6：三个循环关系的概率和 ≤ 2）被突破时出现**。

**读法**
- 这把三个先前分开的东西接在一起：law §6 的孔多塞界（不定因果序的界）、F23 的团、F24 的"上下文性需要加细不有向"。
  **在本框架里，不定因果序的一种形式（团内先后尚未成为事实，且由不相容的加细回答）就是上下文性的一个来源。**
- 它不借用量子的形状：没有希尔伯特空间，只有"哪些先后问题被哪种加细回答"。是否有物理对应，需要辨认（对照：量子开关实验涉及"序的叠加"，是否与此同类，未判断）。
- 它超出了 D1：D1 的样本里每一对记录的关系都是确定的。(ii) 型团正是 D1 的加细有向性失效的地方。


## 5. 什么律会产生 (ii) 型团（命题 Q4、Q5；`calc/q2_blocking_condorcet.py`）

**Q4（分块不会造出循环）** 任何锐利偏序的分块权重都满足孔多塞界：`w(A,B) + w(B,C) + w(C,A) ≤ 2`。
证明：对 a ∈ A、b ∈ B、c ∈ C，三个关系 a≺b、b≺c、c≺a 不能同时成立（否则成环），指示函数之和 ≤ 2；对独立抽取取平均即得。∎
数值核对：随机撒点与随机有向无环图的 8000 组簇，最大循环和 1.597。
**所以 F25 的上下文性不可能来自粗粒化**：在任何分辨率上看到循环和 > 2，就说明底下**没有**一个锐利的细序——这正是"加细不有向"。

**Q5（循环核 + 世界是偏序 ⟹ 加细被迫不有向）** 把 D1 的核放宽为**循环核**：W 的支撑不必包含在某个偏序里（三个区域两两之间"先于"的概率循环地都大于 2/3）。
- Janson 的表示要求 W 的支撑在一个偏序里，所以循环核在 D1 之外；它是律层面的"不定因果序"。
- P1 要求每个世界都是偏序。若一个加细同时回答了三对先后，按循环核它以正概率成环，违反 P1。
  所以律必须让**没有任何一个世界同时回答这三对**——加细被迫分成互不相容的路径，每条只回答其中一部分。
- 于是：**循环核 + 世界是偏序（P1） ⟹ 加细不有向 ⟹ η = max(0, 3q − 2) > 0**（F25）。上下文性在这里不是加上去的，而是在循环核存在时被 P1 强制的。
- 这回答了"什么律会产生 (ii) 型团"：循环核（在 D1 的锐利极限之外，W 取 (0, 1) 中的值且支撑有环）。
  它是否在现实里出现，是辨认问题；它出现的地方必然是 B1 的"锐利连续极限"失效之处（权重模糊的地方）。
