# 上下文性在框架里能住在哪里（2026-09-30，空处 6）

> 不以量子为形状（D13）。这里只用 p-ZFC 的语言问一个结构问题：局部律能否粘成全局律（粘合失败度 η），以及在我们的框架里 η > 0 需要放宽什么。
> 量子理论的 Bell/Kochen–Specker 违背只作对照：它说明现实里 η > 0 的情形存在。

## 1. D1 的框架是非上下文的（命题 Q1）

在一个汇合分支内，D1 给出一个全局的（随机）(S, ≺, μ)；任何关于记录的问题——计数、关系、任意一种分块下的粗权重——都是它的函数。
所以所有语境（观察者选的分块、问的问题）上的局部律都是同一个全局律的边缘：**η = 0**。
- 这不是缺陷，而是 D1 推导里用到的粘合假设的直接后果：加细方向是有向的（D16：任意两个加细有公共加细），在有向语境上权重粘合（p-ZFC 权重层 = Kolmogorov）。
- 对照：F9 里的"视界诱导的上下文性"只出现在不汇合的分支之间（且至少两个空间维），实验室里没有视界，用不上。

## 2. η > 0 需要什么（命题 Q2）

p-ZFC："隐藏的全局结构存在 ⟺ 局部律能粘合"。D1 的全局结构来自两处粘合：宽度方向（汇合）与高度方向（加细有向）。宽度方向的失败就是视界（F7），已经有了。
**高度方向的失败 = 同一个世界有两种加细，没有公共加细**：沿一条加细路径产生的细记录，与沿另一条路径产生的细记录，不能同时存在于任何更细的世界里。
- 在这种情况下，每条加细路径上仍有 D1 式的局部表示，但它们不必是同一个全局核的边缘——各语境的律可以相容于重叠处（事实相容，P1）而没有全局律：η > 0 成为可能。
- 所以**在本框架里，上下文性 ⟺ 加细系统不是有向的**（至少是它的必要条件；充分性需要例子）。这与"不汇合 ⟺ 视界"是同一个结构在两个方向上的出现：
  宽度方向的不汇合给出视界，高度方向的不有向给出不相容的加细。
- 对照（只作对照）：量子理论里不相容的测量，正好是"同一系统的两种更细描述，没有共同的更细描述"。本框架没有借用希尔伯特空间，只是指出这个结构位置。

## 3. 代价与开放问题

- 放弃加细的有向性，D1 的推导（Mecke、Janson 的粘合）只在每条加细路径内成立；"没有最细层"要改写成"每条路径都没有最细层"。
- p-ZFC 说上下文性与世界的合并在两个方向上相互独立（有上下文性而世界可合并，反之亦然）；本框架里宽度（视界）与高度（不相容加细）两种失败是否独立，需要检验。
- law §7.2 的预序团（记录彼此没有先后）是另一个开口：团内记录的"先后"不是事实；它能否产生 η > 0，未知。
- **判断**：到目前为止框架是经典的（非上下文）。这是一个明确的地位陈述：若要容纳现实里观测到的上下文性，最小的放宽是加细的有向性，而不是局域性或因果序本身。
