# 锚点 1：宇宙学概率问题的合法性（2026-09-30）

> 任务表述见 `docs/design.md` §0。本文件回答：在"世界 = 因果过去、记录与律全局、样本与完成物局部"之下，
> 宇宙学里哪些频率/概率问题提得合法、有唯一答案，哪些必须先声明一个个体化。先做了文献核对（§1），再给出框架内的分类与第一个计算（§2–§4）。

## 1. 文献核对：哪些已经被说过

| 已有结论 | 来源 | 与我们的关系 |
|---|---|---|
| 测度问题：永恒暴胀里每类事件都出现无穷多次，频率要靠截断定义；不同截断给出截然不同的预言 | Winitzki 综述（gr-qc/0612164）；Freivogel 综述（1105.0244）；Linde–Noorbala（1006.2170） | 问题本身，公认 |
| 截断依赖来自时间变量（切片）的选择；固有时截断偏好"年轻"区域（youngness paradox） | 同上；Guth–Vanchurin（1108.0665） | 对应我们的"个体化是局部的选择" |
| 频率依赖无穷集合的排列顺序，适当重排可得任意答案 | Guth–Vanchurin（1108.0665）；Linde–Noorbala | 对应 p-ZFC：单一标量 = 选一个线性延拓 |
| 满足一组自然公理的测度不存在（玩具模型给出不可能性） | Olum（1202.3376，PRD 86, 063509） | 对应 GLU₀ 的失败；公理里预设了全局粘合 |
| 局部（因果补丁）测度：只数一个观察者因果钻石内的事件；与光锥时间截断等价；避免年轻悖论 | Bousso（0901.4806）等 | **与"世界 = 因果过去"最接近**；动机是全息/互补，不是记录结构 |
| 光锥时间 t = −(1/3) log（因果未来的体积） | Bousso（0901.4806） | 与我们"时间 = 世界大小的对数"（extension §2）同形，但用的是未来而非过去；我们的 Cauchy 论证给出了为什么是对数 |
| 平稳测度：取马尔可夫真空动力学的平稳分布，截断无关 | Linde–Vanchurin–Winitzki（0812.0005） | 对应 p-ZFC"权重由对称性强制"（这里是时间平移对称） |
| 局部测度依赖观察者世界线起点的系综；局部测度 = 全局测度，当且仅当初始系综取全局测度的吸引子分布（局部–全局对偶） | 1204.1569 等；Bousso–Yang 等 | 在我们的表里：选系综和选全局截断是**同一个局部选择**；但文献没有给出"何时系综无关"的判据 |
| 有限可加、非阿基米德概率，处理无穷支撑上的均匀分布 | Wenmackers（SHPS 2023） | 改的是概率的值域；我们改的是"哪些问题有全局答案" |
| 减速 ⟺ 没有事件视界 | 标准（Rindler） | F7：汇合 ⟺ 无视界 |
| 用 Følner / 可顺从性判定频率是否与穷举方式无关 | 数学里标准（Banach 密度）；**宇宙学文献里没有找到**这样用 | 候选的新东西（§3） |

**结论**：锚点 1 的"问题"与"截断依赖来自切片"已被占据；"局部测度更好"也已有人（Bousso）从全息出发得到。
没有被占据的是：(i) 从记录结构（世界 = 过去、样本局部）**推出**应当用局部穷举；(ii) 一个**内禀的**判据，说明不同观察者的局部答案何时一致；
(iii) 把各种已有测度放进同一张地位分类表里。第 (ii) 条是可能的实际产出。

## 2. 框架里的分类

一个频率问题"A 类记录与 B 类记录之比"在框架里有四种地位：

| 类 | 问的是什么 | 地位 | 例子 |
|---|---|---|---|
| C1 | 一个世界（有限的过去）里的计数比 | **记录**，全局、确定 | 任何已完成的实验统计 |
| C2 | 沿一个观察者的过去序列的极限 | 律的性质；是否收敛是稳定化问题 | 一个观察者"最终"看到的比例 |
| C3 | 不同观察者的 C2 是否一致 | 对一切描述一致 ⟺ 窗口比 ρ → 0（M1 + M2）；无视界（汇合）必要但不充分 | "宇宙中"某类事件的比例 |
| C4 | 所有观察者合起来（跨越视界）的比例 | 问的是一个完成的整体；没有世界包含它 ⟹ 不是记录；只有当律的对称性强制出一个权重时才有值 | "多宇宙中观察者处在我们这类真空的概率" |

- 全局切片截断（固有时、尺度因子时间）是在 C4 上**选一个个体化**：它们给出的数是局部选择的产物，不同截断不一致是被强制的，不是技术缺陷。
- Olum 的不可能性定理是在 C4 上要求全局粘合的公理的失败。
- 平稳测度是 C4 上"对称性强制的权重"的一个例子——这是框架允许 C4 有值的唯一方式。
- 因果补丁测度是 C2。

## 3. 第一个计算：两种内禀的穷举条件（`calc/m1_foelner_frw.py`）

观察者的世界是它的因果过去 P(t)，不选任何切片。权重用四维体积代替"记录数"（测试族，只作对照）。两个量：
- **S_AB（观察者之间）**：两个共动观察者（共动距离 d）在同一固有时的过去的对称差 / 过去的体积。S_AB → 0 意味着两者的穷举给出相同的频率（对任何有界的不均匀性）——观察者之间的 Følner 型条件。
- **S_t（沿一个观察者；年轻性）**：最近一个固有时步长内新增的过去 / 过去的总体积。

| 情形 | S_AB（t = 10 → 10⁴） | S_t | 读法 |
|---|---|---|---|
| 平直 a ∝ t^0.5（减速） | 0.61 → 0.020 | → 0 | 观察者之间一致 |
| 平直 a ∝ t^0.8（减速） | 1.09 → 0.31（慢，∝ d/η） | → 0 | 一致，但收敛慢 |
| 平直 a ∝ t（匀速，**无事件视界**） | 1.46，不变 | → 0 | **不一致**：没有视界也不够 |
| Milne（开放，a = t） | 1.48，不变 | → 0 | 不一致（临界） |
| 平直 a ∝ t^1.5（加速） | → 2.00 | → 0 | 过去变成不相交 |
| de Sitter（平直切片，t = 5 → 40） | 0.45 → 1.49，趋于 2 | → 0 | 过去变成不相交 |

**三点结论**
1. **以过去为世界的穷举在所有情形里都没有年轻悖论**（S_t → 0，包括 de Sitter：观察者的过去在每个哈勃时间里只增加一个固定的体积，只线性增长）。
   年轻悖论是全局切片的产物——切片是个体化，是局部的完成物。这与已知的"因果补丁测度避免年轻悖论"一致，但这里的理由来自记录结构。
2. **观察者之间一致 ⟺ 严格减速**（在测试族里）。**没有事件视界（汇合）是必要的，但不充分**：匀速情形没有视界，S_AB 却不趋于 0。
3. 这个阈值与 F3 的刚性阈值**完全重合**：减速时宇宙时是序的事实、观察者之间频率一致；匀速是两者共同的临界情形；加速时两者都失败。
   同一个 p-ZFC 条件（窗口 / 经过时间 → 0）在这里以"对称差份额 → 0"的形式出现。这是一个内部一致性的检验，而不是输入。

### 3.1 为什么阈值重合：命题 M1

表里加算了这对观察者的窗口比 ρ = W / P（往返跨度 / 经过时间，p-ZFC 的同步比）：p = 0.5 时 S_AB = 0.0632、0.0200，ρ = 0.0642、0.0201；p = 0.8 时 S_AB = 0.313，ρ = 0.360。
**ρ 小时 S_AB ≈ ρ**；匀速情形两者都是常数；加速时 ρ = ∞（有视界）。（数值表用同一固有时匹配；M1 用下面的内禀匹配。）

**命题 M1（观察者之间的频率一致）** 设过程 i、j 的世界是各自的因果过去，大小以记录数计，V_i(t) = |P_i(t)|，t 为 i 的节拍数。
令 τ_j(t) 为 j 最早在过去里包含 i 的第 t 个记录的节拍，τ_i(·) 同理；**窗口** `W(t) = τ_i(τ_j(t)) − t` 就是 i 经由 j 的往返跨度（我们一直用的窗口）。
取内禀的匹配 `s = τ_j(t)`（不需要比较两者的速率）。若
(a) i 的过去增长**在时间上 Følner**：`V_i(t + u) / V_i(t) → 1` 对 `u = o(t)` 成立（例如多项式增长），并且
(b) 窗口比 `ρ(t) = W(t) / t → 0`，
则 `|P_i(t) Δ P_j(s)| / |P_i(t)| → 0`；因而对任何有界密度的记录类型，两者穷举得到的频率极限（若存在）相同。

**证明** 过去是传递闭合的，所以 `P_i(t) ⊂ P_j(τ_j(t)) ⊂ P_i(τ_i(τ_j(t))) = P_i(t + W)`。
于是 `P_i(t) Δ P_j(s) = P_j(s) \ P_i(t) ⊂ P_i(t + W) \ P_i(t)`，份额不超过 `V_i(t + W) / V_i(t) − 1`，由 (a)(b) 趋于 0。
有界密度的计数差不超过对称差的常数倍。∎

- 全部用内禀的量陈述：世界（过去）、记录数、节拍、窗口。没有切片、没有度规。
- **与 p-ZFC 的统一**：同一个条件 ρ → 0（在凹包络条件下）也是"这对过程的相对速率是序的事实"的充要条件。
  所以：**两个过程共享一个时钟（速率是序的事实）⟹ 它们共享频率**（在凹包络条件下经由 ρ → 0；反方向见下）。p-ZFC 的隐藏速率本来就是交错的相对频率，这不是巧合。
- (a) 在测试族里对所有情形成立，包括 de Sitter（过去只线性增长）。所以失败只能来自 (b)：窗口线性增长（匀速，临界）或无穷（视界）。
- ~~反方向没有证明~~（见 §3.2，已证）。

### 3.2 反方向：命题 M2（"属于哪个过程"这个描述本身就是见证）

我先前以为：在均匀的测试族里，任何描述的频率都一致，反方向只能靠律的不均匀性。**这不对**：类型只要是在空间上均匀的描述，确实一致；
但"这个记录属于过程 j"也是一个描述（律层面的，不是任意点集），而且它锚定在过程上。

**命题 M2** 沿用 M1 的记号，设单程比 `r₁ = lim τ_j(t)/t`、`r₂ = lim τ_i(s)/s` 存在。沿 i 的过去，j 的记录数与 i 的记录数之比 → `1/r₂`；
沿 j 的过去 → `r₁`。往返给出 `1 + ρ → r₁ r₂`。所以**两种穷举对"属于 j"这个描述的频率一致 ⟺ r₁ r₂ = 1 ⟺ ρ → 0**。∎
（沿 i 的过去：`n_j(τ_i(s)) = s`，所以 `n_j(t)/t → 1/r₂`；沿 j 的过去：`m_i(τ_j(t)) = t`，所以 `s/m_i(s) → r₁`。）

**数值**（`calc/m2_converse.py`，共动对，d = 1）：

| a ∝ t^p | t | 沿 i：1/r₂ | 沿 j：r₁ | ρ |
|---|---|---|---|---|
| 0.5 | 10⁶ | 0.9990 | 1.0010 | 0.0020 |
| 0.8 | 10⁶ | 0.9400 | 1.0647 | 0.133 |
| 1（匀速） | 任意 | 0.3679 | 2.7183 | 6.39，不变 |
| 1.5 | 任意 | j 永远看不到 i | — | ∞ |

**合起来（M1 + M2）**：在 (a) 过去在时间上 Følner、(b) 单程比有极限的条件下，
**"i、j 两个观察者对一切有界密度描述的频率一致" ⟺ ρ → 0 ⟺（p-ZFC 刚性定理，凹包络条件下）相对速率是序的事实。**
共享频率与共享时钟是同一件事。物理上的读法是熟悉的：每一方都看到另一方红移（对称的红移使两种计数互相矛盾）；
框架补上的是：这正是频率问题变成观察者相对的精确条件，而且阈值是严格减速，不是无视界。

## 4. 这给出了什么（实用性检验）

- **判据**：给定一个宇宙学概率预言，先问它是 C1–C4 中的哪一类。C1、C2 总是合法的；C3 对一切描述合法 ⟺ 这些观察者两两的窗口比 ρ → 0（测试族里 ⟺ 严格减速）；ρ 不趋于 0 时，只有对称性下均匀的描述仍有观察者无关的答案；
  C4 只有在律的对称性强制出权重时才有值，否则**不是预言**，不同测度之间的分歧不是要"解决"的问题，而是问题本身没有事实。
- **对我们所在的宇宙**：今天在加速，所以对于跨越将来视界的比较，频率问题在渐近意义上是观察者相对的；局部实验（束缚系统内）不受影响，与 Guth–Vanchurin 里"实验者的概率不受影响"一致。
- **谁能用**：做宇宙学预言的人，用它判断一个预言是不是依赖测度，以及依赖的是哪一种局部选择。

## 5. 诚实的限制与下一步

1. 权重用了四维体积（测试族）；框架里应当是记录数。换成撒点计数不会改变结论（撒点期望 = 体积），但要在无背景的设定里重述。
2. "同一固有时"匹配两个观察者，用的是共动观察者的对称性；M1 的证明只用各自的节拍，不需要这个对称性，但数值表仍依赖它。
3. Følner 条件保证"对有界不均匀性一致"；若律在空间上是可交换的，任何穷举都一致，条件可以放宽。需要把"不均匀性"本身写成律的性质。
4. C4 中"对称性强制的权重"何时存在，需要一个判据（p-ZFC 的"随机袜子"定理是起点）。
5. 文献补查（已做）：局部测度的观察者依赖被承认，通行做法是指定初始系综（局部–全局对偶）；没有找到"系综何时无关"的判据。M1 给出了充分条件。
