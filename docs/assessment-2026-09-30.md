# 解释力与实用性的审视（2026-09-30）

> 按 `docs/design.md` §0 的实用性检验逐项问：**谁能用它判定或算出以前不能判定或算出的什么？**
> 三种价值分开记：**新物理**（新的可检验预言）、**新地位**（把已知东西分成强制/偶然/无事实，或给出新判据）、**新语言**（已知结果换成计数表述）。
> 结论写在最前面，理由在后。

## 0. 结论

1. **框架现在是一个"地位理论"，不是一个"预言理论"。**（同日补：它不产生**值**，但产生**界**——孔多塞 2、Buchdahl 3（静态个体表面速率比 ≥ 1/3）、阈值 ρ → 0；见 `docs/matter.md` §3。） 它不产生任何新的数值预言；所有数（维数、G、Λ、γ）都是偶然的，由辨认得到。这一点在 F21 里是被证明的（律本身不跑动），不是暂时的缺陷。
2. **它的解释力集中在三处**，每一处都有明确的读者：
   - 宇宙学概率问题的合法性判据（锚点 1，F19）——给做多宇宙/测度问题的人；
   - 撒点与增长律的地位（D1、F17、F18）——给因果集方向的人；
   - 引力的计数表述与"只改 μ 的律"被零正性精确排除（F20、F26、F28）——给离散引力、修改引力的人。
3. **大部分引力结果是已知广义相对论事实的计数重述**（Raychaudhuri、Gibbons–Solodukhin、Birkhoff、Isaacson）。它们的价值是地位划分（哪条是强制、哪条是偶然、哪条可由计数直接问），不是新物理。
4. **最有可能变成"工具"的有两项**：(a) 宇宙学预言的 C1–C4 分类与 ρ → 0 判据；(b) 用区间计数随轴快度的依赖（二次 vs 四次）区分内容与潮汐，作为离散时空模型的诊断。后者目前受涨落限制，见 §3。
5. **最大的缺口**是物质与量子：框架给出了它们必须住在哪里（应力的物态方程是偶然的；上下文性需要加细不有向），但没有给出它们本身。

## 2. 与相邻理论比较的解释力

**相对因果集理论**：多出的是 (i) 撒点的理由（没有最细层，而不是洛伦兹不变 + 给定流形）与密度不固定；(ii) 增长律失败的原因；(iii) 整套地位结果（刚性、频率、汇合）；
(iv) 引力的计数表述附带地位划分。**少的**是：因果集有具体的作用量（Benincasa–Dowker）与量子化路线（和式历史），我们没有，也刻意不以量子为形状。

**相对广义相对论**：不多出任何可检验的东西。多出的是说明：哪些 GR 特征是强制的（自由下落 = 最长链、源不能是标量计数、内容守恒），哪些是偶然的（P5 ⟺ γ = 1、Λ、G、维数）。
这对"为什么是 GR 而不是 Nordström"给出了一个明确回答：在本框架里，这是一个可由计数检验的偶然事实，而且等价于"内容从不使快速自由过程散焦"。

**相对多宇宙测度文献**：多出一个判据（ρ → 0）与一个分类（C1–C4），把平稳测度的好表现解释为"它实际问的是单观察者极限"。**少的**是：我们没有给出任何具体测度的数值预言。

**相对量子基础**：只给出位置（加细的有向性）与一个阈值（孔多塞/因果不等式型），没有给出量子理论。

## 3. 实用性：什么能变成工具，差多少

1. **宇宙学预言的合法性检查（最接近可用）**：给定一个依赖测度的预言，判断它属于 C1–C4 哪一类、是否需要声明个体化。
   差的是：一份面向宇宙学读者的独立短文，把 F19 与 C1–C4 写成不依赖本框架术语的形式，并逐一对照现有测度（因果补丁、尺度因子截断、平稳测度）。
2. **离散时空的内容/潮汐诊断**：在一个撒点因果集里，按不同轴（最长链）做小区间，测记录数相对最长链的亏损随轴快度的依赖：二次项是内容，四次项是潮汐。
   差的是：可行性。亏损的相对大小 ~ (τ/L)²（内容）或 (τ/L)⁴（潮汐），Poisson 涨落 ~ N^{−1/2}，要求 N ≫ (L/τ)⁴ 乃至 (L/τ)⁸；对潮汐几乎不可行，对内容在强曲率区可行。需要一次数值可行性研究。**数量估计（同日）**：估计量 N/V₀(L) 的相对涨落主要来自最长链长度，约 N^{(χ−1)/d}（χ 为最长链涨落指数，1+1 维为 1/3）；取 d = 4、信号 δ ≈ 0.03(τ/L_curv)²、τ/L_curv = 0.3，单个区间需要 N 远超 10¹² 个记录，潮汐的四次项更差。对多个区间取平均可改善，但作为日常工具不可行。而且按 D16（没有最细层），N 是相对分辨率的：这个诊断在原则上是律层面的陈述，在实践上只在很粗的统计平均里有意义。结论：**降级为概念工具**。
3. **修改引力的快速排除**：任何只改 μ 的（标量共形）引力律，只要有静态孤立吸引源，就违反零正性（F28）。这是可以直接引用的判据；差的是核对它在修改引力文献里是否已有。
4. **因果集动力学的约束**：任何满足个体化不变与"没有最细层"的律都是 Cox 型撒点（D1）。对设计新动力学的人，这是"不要再找增长规则"的信号。差的是把 D1 写成严格的定理（graphex 额外项）。

## 4. 诚实的风险

- **重述风险**：引力部分的大多数"推出"在对照族里依赖已知定理；若把对照族拿掉，剩下的是计数原则与地位划分。评价时不能把 GR 的成功算作框架的成功。
- **可检验性风险**：地位理论的陈述大多不可证伪（它们是关于什么有事实的陈述）；可证伪的部分都在辨认里，而辨认结果与 GR/ΛCDM 一致，没有区分度。
- **借词风险**：已有词汇规则；本轮审视中未发现新的借词，但"内容""应力"的计数定义依赖对照族确认二次性，一般的 (S, ≺, μ) 里是假设。

## 5. 若要提高实用性，下一步最值得做的

1. 写锚点 1 的独立短文（面向宇宙学读者）——最短路径的"可用产出"。
2. 内容/潮汐诊断的数值可行性研究（Rust，撒点在 FRW 与强场里）。
3. D1 写成严格定理（graphex 的有向传递版本）——因果集方向可直接引用。
4. 物质：从"哪些物态方程允许内容自我维持为窗口有界的过程族"出发，看是否有被强制的限制（例如稳定性要求的压强下界）。
