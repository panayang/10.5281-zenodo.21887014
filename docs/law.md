# 规律住在什么对象上：权重序上的增长律（D20 第 1 步）

> 2026-09-29。只用计数比与权重；不借 GR、量子理论或因果集的现成动力学。
> 出发点：F17——P4（没有最细层）+ D18（分辨率是分块）⟹ 每一层的关系都是权重，锐利的序只是极限。

## 1. 对象：权重序

一层上的**权重序**：可数的簇集 C 与 `w : C × C → [0, 1]`（X 的成分先于 Y 的成分的比例），满足
- **反对称**：`w(X, Y) + w(Y, X) ≤ 1`；
- **Łukasiewicz 传递**：`w(X, Z) ≥ max(0, w(X, Y) + w(Y, Z) − 1)`。

这两条是分块的**必然结果**，不是假设：随机取成员 x、y、z，`P(x ≺ y ∧ y ≺ z) ≥ a + b − 1`（Fréchet 下界），而此时必有 `x ≺ z`。
锐利的偏序是 w 只取 0、1 的特例。

**逻辑上的含义** Łukasiewicz 传递律是 Łukasiewicz 多值逻辑里的传递性。p-ZFC 说排中律恰在语境不能再细化处成立；
D16 说每一层都能再细化。所以**在任何一层，"a 先于 b"都不是二值命题**；布尔式的锐利因果只在极限里出现（B1 的鞅极限，若锐利）。
这是对"绝对因果是否成立"的一个框架内回答（D19）：它是极限性质，不是任何一层的事实。

## 2. 两种扩张

- **宽度（增长）**：世界加入新的簇；旧簇之间的权重不变（P1 = M4）。
- **高度（加细）**：簇分裂为子簇；粗层权重 = 细层权重按份额的平均（塔性质，B1）。

一个**律**是关于这两种扩张的概率描述：每一层上一个增长过程，并且各层的增长过程在分块下相容。

## 3. 四条原则的权重版

| 原则 | 锐利版（因果集 CSG 里） | 权重版 | 在分块下是否保持 |
|---|---|---|---|
| P1 记录持久 | 新元素不改变旧关系 | 新簇不改变旧簇之间的权重 | 保持（平均保持等式） |
| P2 个体化不变 | 离散广义协变：带标号序列的概率只依赖最终的无标号序 | 同左，对权重序 | **待检验**（第 3 步） |
| P3 局域 | Bell 因果：两个转移概率之比只依赖两个新过去的并集 | 候选：**不传信**（远处的选择不改变此处的边缘分布） | Bell 因果**可能不保持**（见下）；不传信在求边缘时保持 |
| P4 没有最细层 | （CSG 有最细层：逐个元素出生） | 各层的律构成一个投影族，没有最细一层 | 按定义；投影极限由 Kolmogorov 保证存在 |

**关于 P3 的预判（要检验，不假设）** 在因果推断里，**条件独立在对隐变量求边缘时一般不保持**：被删掉的中间元素是共同原因，
会让粗层上本来"无关"的部分出现关联。Bell 因果是一种条件独立陈述，所以一个在细层满足 Bell 因果的律，粗粒化后可能不再满足。
而"不传信"（边缘分布不受远处选择影响）在求边缘时保持。如果检验证实这一点，P3 在跨分辨率的框架里应当取不传信的形式，
这与 p-ZFC 的网络定理（公开且不相互干扰 ⟹ 不受扰动）一致。

**连带结论（第 2 步）** 所有 CSG 律都满足 Bell 因果。所以若传递渗流粗粒化后违反 Bell 因果，它就在 CSG 族之外，
**CSG 族在粗粒化下不封闭**——第 2 步由第 3 步的检验一并回答。

## 4. 第 3 步的检验设计

对传递渗流从空序开始增长、再以概率 q 稀疏化，看保留下来的前几个元素构成的增长过程：
- **P2（协变）**：三元序"一条两元链 + 一个孤立元"有三种自然标号（`{1≺2}`、`{1≺3}`、`{2≺3}`），协变要求三者概率相等。
  传递渗流本身三者都等于 `p(1−p)²`。四元序有更多标号可比。
- **P3（Bell 因果）**：比较"已有一个元素 {1}"与"已有两个不相关元素 {1, 2}"两种情形下，新元素"以 {1} 为过去"与"没有过去"的概率之比。
  Bell 因果要求两个比值相等（传递渗流里都是 `p/(1−p)`）。
- **不传信**：新元素与元素 1 相关的边缘概率，是否依赖于与元素 1 无关的元素 2 的存在与关系。

## 5. 第 3 步的结果（F18）与修订

- 对照（传递渗流本身）通过全部检验；稀疏化后协变（P2）与 Bell 因果（P3）都大幅违反，CSG 族不封闭。
- 机制：被删掉的元素构成隐藏的时钟，细层的线性个体化泄漏进粗层（均匀线性延拓限制到子序上不再均匀）。
- **修订**：P2 不能以"带标号增长过程 + 事后要求协变"的形式出现，因为那预设了每一层都有一个线性个体化。
  律应当是**无标号（权重）序上的投影族**：每一层一个关于无标号权重序的律，各层在分块下相容，个体化不变性内建。
- P3 的检验需要在无标号的设定下重新设计（原"不传信"检验被隐藏时钟干扰）。
