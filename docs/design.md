## 0. 任务

**处境**：我们是系统内部的记录者，没有全局语境（p-ZFC：记录与律全局，完成物与样本局部）。
旧任务"找全局状态空间与运动方程"本身是 GLU₀（Gandy 的"下一步状态"、Kolmogorov 的单一样本空间、单一时间线）。

**物理学在这里要回答三件事**
1. **地位**：记录里的每个量或陈述属于哪一类——记录事实（扩张不改变、所有记录者共享）；律的性质（全局，只能渐近接近；再分极限可判定与否）；
   局部完成物（依赖某个个体化或完成：连续统、宇宙时、一条轨迹、一个截断）。
2. **强制与偶然**：哪些全局特征仅由"记录能持续、互相一致"（M4、汇合、扩张）强制，对任何记录系统成立；哪些是律的自由参数。
   解释一个特征 = 说明它被强制，或说明它为什么只能是输入。
3. **辨认**：内部记录者怎样从局部样本确定偶然参数、能确定到什么程度。GR、量子理论属于这一层：偶然律在某些分辨率下的紧凑描述，是对照与辨认对象，不是形状。

**实用性检验**（每个结果都要回答）：谁能用它判定或算出以前不能判定或算出的什么？答不出的归为"澄清"，可以保留，不算产出。
可接受的产出类型：(a) 排除候选律的约束；(b) 判定问题是否提得合法的判据；(c) 可测量之间的关系或内禀的无量纲数。

**两个锚点**
- **近期：宇宙学概率问题的合法性判据**（`docs/anchor-measure.md`）。只依赖已有的刚性结果与 p-ZFC 概率层，不需要先有动力学。
- **远期：粗粒化不动点的普适指数**——无尺度框架里唯一能内禀产出的数（另一来源是对称性强制的权重）。依赖动力学（R8）。

**词汇规则**：新词必须能用序、链、计数、记录、世界、扩张说出来；否则标"输入"或"对照"，不许以"显而易见"跳过。

## 1. p-ZFC 深读：可用的思想清单

p-ZFC 的统一形状（原文结尾）：**一个情形的全局内容，是在所有个体化下不变的东西**——
在所有世界下是可数核心，在所有位置下是结构，在所有线性化下是迹加速率。
经典的四个要求——一个宇宙、一个演化、一个样本空间、一个标量——**每一个都是要求做一次选择**。

| p-ZFC 思想 | 物理对应（本方案的用法） | 用在哪层 |
|---|---|---|
| GLU₀ 四条（唯一性、确定存在、良基形状、选择） | 旧设计里的四个全局假设：一个全局事件集、一个全局时间、一个全局 σ 场、一个全局态 | 全局检查（§2） |
| 可数记录全局；ℝ、幂集等完成整体局部（M4：记录不被后来的记录扰动） | 可预言的东西是**记录**（计数、共存事件间的序、律的编码）；连续统上的点值是局部的 | L0 |
| 事实能粘合，存在不能粘合（`Δ₀` 事实在所有包含它们的世界里相同；无全局配对） | 共存事件之间的序关系是全局事实；"所有事件构成一个偏序集"不是 | L0 |
| 律全局，样本局部；事件是描述；新鲜样本避开一切事先定义的点集 | （D16 修订）律 = 关于可数记录的描述，**不是**给定的流形；撒点只是生成测试用序的手段。原"几何是律、事件是样本"已撤回（W5） | L2 |
| 宽度扩张（力迫：同一高度加新记录）与高度扩张（秩：加层）；吸收定理：同高度不能粘合的，在更高处能粘合 | **假说 H-高度**：宽度 = 在同一分辨率下记录更多事件；高度 = 分辨率/尺度方向。"同分辨率下不相容、在更细/更大尺度上可合并" | L3（待检验） |
| 沿记录系统的稳定化；汇合 ⟹ 极限唯一 | 粗粒化/RG 作为记录系统；阈值 = 答案改变点；普适性 = 汇合 | L3 |
| 独立命题四分类：可判定 / 预言机位 / 极限可判定 / 开关 | 物理量四分类：**预言 / 常数（预言机位，只能测）/ 涌现量（极限可判定）/ 无事实（开关，如退行观察者之间的全局同时性）**，取代旧版"预言或输入"的二分 | 全局记账 |
| 上下文律：有全局律 ⟺ 存在在所有重叠上几乎必然一致的实现；障碍有限且是算术的 | 量子上下文性/Bell；非上下文分数作为可算量 | L4 |
| 提问的四种情形：再问、谁问、之前问了什么、同时问了什么；记录 = 公开且不受扰动；隐藏代价 = 残余行为数 | 经典记录 vs 量子；隐藏变量所需最小状态数作为定量指标；"时间是对重复提问的个体化指标"；位置只在扰动不可逆时是事实（时间箭头） | L4、L0 |
| de Finetti 与 Bell 是一个定理的两端（谁决定读哪条流：过程 / 位置 / 提问者） | 局域隐变量存在 ⟺ 律能粘合；两个做选择的类即可失败 | L4 |
| **隐藏速率 + 刚性相变**：迹之外唯一的全局隐藏参数是渐近速率；存在 ⟺ 同步无标度（`W/P` 不趋于 0） | **本方案的核心定理来源**（§3） | L1、L5 |
| GLU(π)：值/形状/语境三参数；排中律恰在语境不能再细化处成立；存在是局部的（罗素的袜子：全局对象无全局成员）；权重由对称性强制 | "没有基本粒子"的精确形式：物种是全局对象，其成员只存在于语境（分辨率）中；有限分辨率下的逻辑是直觉主义的；类玻恩权重由语境范畴的对称性强制 | L3、L4 |
| 触发器定理：理论设计的可和触发器只捕获有限多个对该理论"新鲜"的现象 | 方法论：怎样陈述"预言"、怎样避免只验证理论能描述的东西 | 全局记账 |
| 序维数 = 忠实表示所需的最少标量数；单一标量 = 选一个线性延拓 | "一个时间"= 因果序的一个线性延拓；1+1 维闵氏因果序的序维数是 2（两条零坐标） | L0 |

**文献关系（重要）**：p-ZFC 的"中心线性化 / 刚性"与 Brightwell–Luczak 的
"因果集自然延拓上的序不变测度"（Ann. Appl. Probab. 2011；CPC 2012）是同一个数学对象，
他们给出了存在唯一性的充分条件和极值测度的刻画。p-ZFC 没有引用。我们的数学新颖性要以此为底线来衡量。

## 2. 全局粘合检查：初稿里藏着的四个选择

| 初稿假设 | 属于 GLU₀ 哪条 | 修正 |
|---|---|---|
| L0：所有事件构成**一个**全局偏序集 | 确定存在 + 合并 | 事件是**语境中的记录**；全局的是共存记录之间的序**事实**。全局偏序集只在"可合并"的区域存在，那是经典极限，是一个**结论**而不是前提 |
| L1：存在一个全局 σ 场 | 唯一性 + 选择 | σ = 两个过程的**对数速率比**，永远是一对之间的量。它在刚性区是结构事实，在无标度区是律层面的隐藏参数（一个区间），不预设全局场 |
| L2：连续极限给出**一个**流形和度规（Malament） | 完成整体当全局对象 | （D16 修订）不预设流形也不预设最细层：各层记录可数，加密没有底，连续统是极限（p-ZFC 意义上是局部的） |
| 默认存在一个全局时间 / 宇宙时 | 选择（线性化） | 时间是**个体化**（线性延拓的选取）。只在刚性区被序唯一决定。§3 表明：宇宙时被因果序决定，当且仅当宇宙减速膨胀 |

## 3. 核心论断（修正后）与数值预检

### 3.1 论断
**尺度 = 两个过程之间的对数速率比。** 因果序在**束缚/刚性**区把它定死（是结构事实），
在**无标度同步**区把它留作全局隐藏参数。三种"尺度"是同一个量在不同区的样子：

| 情形 | 同步窗口 W 与经过时间 P | 刚性 | 速率比是什么 |
|---|---|---|---|
| 相对静止 / 引力束缚的两个观察者 | W 有界 | 刚性 | **引力红移**，由序唯一决定（结构事实） |
| 相互退行的惯性观察者（快度 η） | W ∝ P（无标度） | 非刚性 | 隐藏参数，取值区间恰为 `(e^{−η}, e^{η})`：**同时性的相对性 = 刚性失效**。两体时隐藏参数恰为标架快度（boost 在天球上是伸缩，与方向 B 接上）；多体时是渐近切片，惯性标架是其中的线性特例（F4） |
| FRW `a ∝ t^p`，共动观察者 | W ∝ t^p | p<1（减速）刚性；p=1（Milne）临界、无标度；p>1（加速、de Sitter）视界使窗口发散 | **宇宙时被因果序决定 ⟺ 减速膨胀**；旧版"时间是标度跑动的方向"恰好是临界点 Milne |

修正点：初稿说"σ 就是共形因子、是隐藏参数"。不对。束缚区的速率比（红移）**不是**隐藏的：
沿链计数本身就在序里。隐藏参数只出现在无标度区，而那里它是快度。

A3（能量 = 速率⁻¹ 标度）从公理降为定义：能量 = 事件速率（E = ħω），只有比值有意义（A5）。

### 3.2 数值预检（已移入 `calc/`，完整结果见 `docs/findings.md`）
方法：两条世界线各按自己的固有时每单位打一拍；由几何算出两条链之间的因果关系；
对所有线性延拓作精确计数（对数域逐行累加），看中间时刻的速率是否依赖终点（终点 = 最后一张同时面）。

| 几何 | N=250 | N=1000 | N=4000 | 结论 |
|---|---|---|---|---|
| 相对静止（d=20）：终点两极下中间斜率之差 | 0.030 | 0.000 | 0.000 | 刚性，斜率 1 |
| 静态、红移 0.8：终点斜率 0.7 / 0.8 / 1.2 → 中间 | — | 0.8006 / 0.8006 / 0.8006 | 0.8001 / 0.8001 / 0.8001 | 刚性，**锁定在红移值** |
| 退行 η=0.5：终点两极 → 中间 | 0.697 / 1.464 | 0.654 / 1.550 | 0.631 / 1.598 | 非刚性，趋向 `e^{∓0.5}` = 0.607 / 1.649 |
| 退行 η=0.5：终点 0.779 / 1 / 1.284 → 中间 | 0.802 / 1.004 / 1.265 | 0.785 / 1.001 / 1.279 | 0.780 / 1.000 / 1.283 | 中间跟随终点：速率由"选哪张同时面"决定 |
| FRW p=1/2：两极之差 | 0.094 | 0.040 | 0.019 | 刚性（差 ∝ N^{−1/2}，与 t^{p−1} 一致） |
| FRW p=2/3：两极之差 | 0.52 | 0.34 | 0.22 | 刚性但慢（≈ N^{−1/3}） |
| FRW p=1（Milne，χ=0.5）：两极 | 0.667 / 1.511 | 0.647 / 1.562 | 0.629 / 1.601 | 非刚性，趋向 `e^{∓χ}`（Milne 里共动间距就是快度） |
| FRW p=3/2（加速）：两极 | 0.63 / 1.91 | 0.41 / 2.83 | 0.22 / 2.96 | 非刚性且发散（视界） |

注意：有限 N；只考察两条链的子偏序；"均匀的序不变测度 = 不偏好任何个体化"是一个解释性步骤。

## 6. 工作规则（来自旧版教训）

1. 每个文件/脚本必须产出一个结果（一个数、一条定理或一个被否定的假设），不写纯自审文件。
2. 一个词只指一件事；新词进 `docs/glossary.md`（一行一个）。
3. 借来的东西写明借来；登记册 `register.md` 限一页。
4. Lean 只用于我们自己的数学核心（L1 的刚性/速率定理、L0 的语境结构）；轻量与符号计算用 Python，计算密集的用 Rust（`calc/rs/`）。
5. 结论先数值预检，再证明，再解释。
6. 文献底线：Brightwell–Luczak（序不变测度）、Sorkin 等（因果集、撒点、序列生长 CSG）、
   Malament / Hawking–King–McCarthy、de Boer–Solodukhin、Pasterski–Shao–Strominger、p-ZFC。
