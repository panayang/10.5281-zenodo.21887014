# 阶段性总结（2026-09-30）

> 覆盖 2026-09-29 重开（清空旧版 Lean/LaTeX）到今天。细节在各文件；这里只给现在站在哪里、靠什么站住、哪里还是空的。

## 1. 任务（`docs/design.md` §0，D22）

我们是系统内部的记录者，没有全局语境。物理学在这里回答三件事：
**地位**（记录事实 / 律的性质 / 局部完成物）、**强制与偶然**（哪些由"记录能持续、互相一致"强制，哪些是律的自由参数）、**辨认**（怎样从局部样本确定偶然参数）。
不以"推出已知物理"为任务；已知物理是对照与辨认对象。每个结果须过**实用性检验**：谁能用它判定或算出以前不能的什么。

## 3. 结果按任务分类

**地位（什么是事实、什么是律、什么是局部的）**
- 束缚 ⟺ 相对速率是序的事实；退行时速率是隐藏参数，只被限制在快度区间里（F1、F2、F4、F5、F6）。
- 宇宙时是序的事实 ⟺ 减速；匀速（Milne）是临界（F3）。汇合 ⟺ 无事件视界（F7）；共存模式与上下文性（F8、F9）。
- 刚性是律的性质，有限记录不可判定（extension §8）。连续统是局部的完成物（blocking B1 的读法）。
- **观察者之间对一切描述的频率一致 ⟺ 窗口比 → 0 ⟺ 速率是事实**：共享频率 = 共享时钟；无视界不够，须严格减速；以过去为世界的穷举没有年轻悖论（F19，锚点 1）。
- 宇宙学概率问题的四类地位（C1 记录、C2 单观察者极限、C3 观察者间一致、C4 跨视界全体：只有对称性强制出权重时才有值）（`docs/anchor-measure.md`）。

**强制**
- 扩张的量只能是份额的对数（Cauchy）；自相似 + M4 在 FRW 测试族里挑出匀速基线（extension §2–3）。
- 序贯增长律（CSG）不是基本律：它只有宽度方向，在粗粒化下不封闭（F17、F18；隐藏时钟随尺度分离变强）。
- **P2 + 没有最细层 + 宽度只向上 ⟹ 律是有序测度空间 (S, ≺, μ) 上的 Cox 型撒点**，只在汇合分支内存在；撒点被强制而不带回尺度（D1，条件性；Mecke、Janson）。
- 源不能是内容记录的个数（标量只给各向同性亏损，Schur 引理迫使它处处为常数）（D3）。

**偶然（律的自由参数，由辨认决定）**
- (S, ≺, μ) 本身：维数、各向同性不被强制（平移齐性 ⟹ 凸锥序，各向同性 ⟹ 洛伦兹锥）（D23）。
- P5：在对照族里 ⟺ 真空爱因斯坦空间（Λ 允许，是各向同性亏损）⟹ 内容必须改变序、外部 γ = β = 1、Nordström 型被计数排除（F20、D2）；P5 独立（D4）。
- 耦合 G 与 Λ：框架里仅有的有量纲量，随内容与真空进入。
- 物理无量纲数：律本身不跑动（每个律都是粗粒化不动点），样本指数相对分辨率；跑动只能来自内容在分块下的非可加性（F21，呼应 F10）。

**辨认**：尚未系统做；目前只有对照（太阳系 γ、ΛCDM 的 H·t、红移）。

## 5. 与物理实在的对应（只列站得住的）

| 物理 | 框架里的形式 | 地位 |
|---|---|---|
| 红移、束缚系统的时间膨胀 | 束缚对的速率比 = 互窗口比（F1、F14） | 强制 |
| 相对论的"无优先标架" | 退行对速率隐藏在快度区间内（F2） | 强制 |
| 宇宙时、事件视界 | 刚性 ⟺ 减速；汇合 ⟺ 无视界（F3、F7） | 强制 |
| 测度问题的截断依赖 | 截断 = 个体化；观察者系综无关 ⟺ ρ → 0（F19） | 强制 |
| 自由下落 | 最长链落向钟慢处（g3 数值） | 强制（与 Nordström、GR 都相容） |
| 光偏折 γ = 1、真空爱因斯坦方程、Λ | P5 在对照族里的推论 | 偶然，观测支持 |
| 撒点（因果集） | 由没有最细层强制，不是由洛伦兹不变性假设 | 强制（条件性） |

**不对应或未触及**：量子现象（刻意不以量子为形状）；引力波、强场；内容本身（物质）的内禀理论；具体数值（除对照外框架不产生数）。

## 6. 相对因果集理论多出的解释力

- 撒点的理由：来自"没有最细层"（Mecke），不需要假设洛伦兹不变或给定流形；密度不固定。
- 序贯增长律为何失败：只有宽度方向（F17、F18）；与 Brightwell–Georgiou 的否定结果相容，并给出原因。
- 刚性/隐藏速率的完整图谱、宇宙时与减速的等价、观察者间频率一致的判据：因果集文献里没有对应的陈述（以 Brightwell–Luczak 的序不变测度为数学底线）。
- 引力：用计数亏损 + P5 给出 γ = 1 与真空方程的形式，并把 P5 定为可检验的偶然性质；因果集方向用计数估 Ricci（Benincasa–Dowker 等），但没有这种地位划分。

## 7. 空的地方（按重要性）

1. **内容的内禀理论**：内容现在被定义为"使计数亏损依赖方向的东西"，但它与物质过程的关系、它在分块下的行为（锚点 2 的新位置）都没有。
2. **D1 的严格化**：σ-有限（开放宇宙）情形；Mecke 定理在一般空间上的条件；稀疏化与分块哪一种是分辨率的正确读法。
3. **辨认**：把偶然参数（d、各向同性、P5、G、Λ）与观测对上的系统工作。
4. **锚点 1 的剩余**：C4 中对称性强制权重的存在判据；在撒点计数下复核 F19；单程比无极限的情形。
5. **放宽"世界对过去封闭"**：只保留"不能加细成序的团"的方案（law §7.1）尚未与 D1 的表示协调（团若停止加细就是原子，与无原子强度冲突）。
6. **量子**：刻意未碰；p-ZFC 的上下文性与粘合失败度是现成的语言，但不以量子为形状。

## 8. 工作方式的教训

- 连续三次落入同一种惯性：把借来的对象（光、能量、局域性、测度）当作显而易见的定义。现在有词汇规则和 p-ZFC 检查（律/样本、全局/局部）。
- 最扎实的结果都属于"地位"与"强制"；每次试图"推出已知物理"时都在借形状。
- Rust 用于重计算；Python 只做符号与轻量计算。
