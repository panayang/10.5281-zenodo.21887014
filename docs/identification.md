# 辨认：偶然参数与观测（2026-09-30，空处 3）

> 任务第三部分：框架里的偶然参数（律的自由部分）怎样由记录确定、现在确定到什么程度。观测数据只作辨认的证据，不作前提。
> 每一项先写它在框架里是什么（能否用计数问），再写对照的观测。

## 2. 由此得到的地位陈述（关于我们的宇宙）

1. **宇宙时**：减速期（辐射、物质主导）共动过程之间的速率是序的事实；加速开始后，渐近地不再是（F3、C1）。
   若 Λ 为常数，"宇宙有没有一个由序决定的宇宙时"的答案在律层面是"没有"——这是一个关于律的结论，不是某个时刻的事实。
2. **宇宙学概率问题**：在渐近加速的律里，跨越将来视界的频率比较是观察者相对的（F19）；C4 类问题一般没有事实（anchor §6.3）。
   局部实验（束缚系统内）不受影响。
3. **引力**：在太阳系精度内 P5 成立，所以内容通过改变序本身起作用（F20）；Nordström 型的律被排除，排除的依据可以写成计数陈述。

## 3. 框架提出的、不同于标准做法的检验

- **P5 的计数形式**与 PPN 的 γ 检验在对照族里等价，不是新的检验；新的是它的地位（偶然的律性质，由计数直接问）。
- **C1（聚焦 ⟺ 刚性）**：在非均匀的律里若成立，预言"局部时间是否是序的事实"由局部内容的聚焦符号决定。可检验性取决于把 F1–F3 推广到非均匀情形（未做）。
- **宇宙学预言的分类**（C1–C4）：对每个依赖测度的预言，给出它是否有事实。这是可立即使用的判据，不需要新数据。
- **诚实地说**：框架目前不产生任何新的数值预言。它产生的是地位划分和判据；数值都来自辨认。
