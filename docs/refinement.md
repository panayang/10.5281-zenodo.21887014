# B 的地基：离散而无尺度的加密系统（D16）

> 2026-09-29。只用序、链、计数。没有背景流形，没有最细一层，没有量纲性的量。
> 撒点、GR 几何只用来生成测试用的序。

## 1. 定义

**加密系统** 一个有向集 Λ（"层"），每层一个可数偏序 `(E_λ, ≺_λ)`；对 `λ ≤ μ` 有嵌入 `ι_{λμ} : E_λ → E_μ`，满足
- **完全**：`a ≺_λ b ⟺ ι(a) ≺_μ ι(b)`（粗层的序关系在细层里原样保留，细层也不给粗层事件添加新的关系）；
- **相容**：`ι_{μν} ∘ ι_{λμ} = ι_{λν}`；
- **无底**：每一层都有真加密（`E_μ ⊋ ι(E_λ)`）。

这是 p-ZFC 的记录系统在"分辨率"方向上的实现：世界 = 一层，扩张 = 加密；
完全性就是 M4（已有记录之间的事实不被后来的记录扰动）；无底就是 M3（每个世界都有真扩张），也是旧版 A6"开放"。
"离散"只表示每一层可数。连续统是加密的极限，在 p-ZFC 的意义上是**局部**的，不是背景。

**过程** 一族链 `C_λ ⊂ E_λ`，跨层相容：`ι(C_λ) ⊂ C_μ`（粗的一层是细的一层的子链）。

**跨层计数比（能标）** 过程 C 上两个粗层事件 `x ≺ y` 之间，在 λ 层与 μ 层分别有 `N_λ(x,y)`、`N_μ(x,y)` 个节拍。
`log(N_μ / N_λ)` 是 λ 到 μ 的**能标差**。它和 σ（同一层里两个过程之间计数比的对数）是同一类型：只有比值，没有单位。

## 2. 命题（证明都很短）

**命题 1（可区分性是按钮）** 两个过程在事件 x 附近"可区分"= x 在另一过程上的窗口非空。
由完全性，可比关系在加密中不变，新事件只会增加不可比元素，所以可区分性一旦成立就永远成立：
它是 p-ZFC 意义上的持久答案，沿加密至多改变一次。
**推论**："内容随分辨率单调增长"与"阈值有明确定义"（旧版 Emergence 的核心）不需要任何尺度就成立。
阈值 = 某结构第一次变得可分辨的那一层；它是一个能标**差**，不是绝对能量。

**命题 2（民主加密保持速率与窗口类）** 称一次加密是**链接细分**，若它只在粗层的每个覆盖关系 `x ⋖ y` 上插入 k 个新事件，
新事件的过去 = x 的过去，未来 = y 的未来（这是保持全部旧关系、不添加新"类空"结构的最小加密）。
新事件 z（插在 `x ⋖ y` 上）与任一旧事件 w 的关系：`w ≺ z ⟺ w ⪯ x`，`z ≺ w ⟺ y ⪯ w`；传递性直接验证，所以加密后仍是偏序，且是完全嵌入。
对**饱和链**（相邻节拍之间没有其他事件，即相邻节拍构成覆盖关系）的过程，链接细分使节拍数乘以 k+1；
另一过程上插入的新事件 z（在 `b_j ⋖ b_{j+1}` 上）与 `a_i` 不可比，当且仅当 `b_{j+1} ⋠ a_i` 且 `a_i ⋠ b_j`，
所以窗口长度变为 `(k+1)·W + O(k)`。于是速率比不变，窗口的四分类不变（这是 F10 第 1 条在加密方向上的对应）。
一般的加密还会加入新的不可比结构（新的"类空"事件），这就是"内容"的来源。

**命题 3（过程被粗层钉住）** 设 C 是过程。对任意粗层事件 `x ≺ y`（都在 C 上），C 在更细层里位于 x、y 之间的部分，
只能落在区间 `{e : x ≺ e ≺ y}` 里。所以细层的"涨落"被关在粗层相邻节拍之间的区间内，**不会随持续时间累积**。
（对照：F12、F13 的单链过程是在**同一层**里定义的，没有被钉住，涨落随 T 累积。那是"最细层 + 单层定义"的产物。）

**命题 4（能标 × 尺度，纯比值形式）** 两个过程在 λ 层的窗口有 `W_λ` 个节拍。若加密到 μ 层时窗口按因子 `r = N_μ/N_λ` 放大
（链接细分时 r = k+1），则在 λ 层"合并"（W_λ < 1）的一对，在 `r·W ≳ 1` 的层上第一次变得可分辨。
所以阈值能标差 `log r* ≈ −log W`：**分辨一个窗口为 W 的结构所需的能标差，等于它的尺度的对数取负**。
这是 F10 第 2 条的无尺度版本：两边都是比值。

## 3. σ 场作为极限浮现

取过程 A、B 上的一列粗层区间，随加密逐层缩短（每层都用更细层的事件把区间切小）。
在每个区间上取跨过程计数比 `N_B / N_A`（同一层里、被区间两端的序关系对齐的节拍数之比）。
若在缩短的区间上这个比值收敛，其对数就是沿过程的**局部 σ**。若对一族过程都收敛，σ 就是一个**场**。

- 这是旧版"标度场"的无背景版本：σ 不是预设的场，而是从计数比里浮现的极限；
- 极限是否存在，是对加密系统的**条件**（"光滑加密"），不是预设。它是 p-ZFC 稳定化的一个实例：
  "局部速率落在某个区间里吗"沿加密变化有限次 ⟺ 局部速率在极限里是可判定的；
- 在刚性（窗口次线性）的一对之间，局部速率是序的事实；在线性窗口的一对之间，局部速率只在给定切分时有意义（与 F2 一致）。

## 5. 未决问题

1. **光滑加密的条件**：什么样的加密使局部速率收敛？（需要一个不预设几何的判据；可能与 p-ZFC 的汇合、稳定化层级有关。）
2. **新的不可比结构从哪里来**：一般加密除了细分，还加入新的"类空"事件。它们的规律决定"内容"如何随能标增长。
   旧版的 CV² = 1（阈值在对数尺度上均匀）是这里的一个候选假设，**要检验，不能预设**。
3. **σ 场的动力学**：什么约束 σ 场？旧版把它交给 GR 方程；这里不行（D13）。候选：跨层一致性本身（各层的计数比必须相容）是否就约束了 σ。
4. **与 p-ZFC 的"高度扩张"的关系**：p-ZFC 的吸收定理说同一高度不能粘合的，在更高处能粘合。在完全嵌入下，序关系不变，所以不会发生；
   要么这里的类比不成立，要么需要允许"粗粒化"方向（合并）作为另一种扩张。
