# 框架陈述 v0.5（2026-09-30）

> 这是目前框架的统一陈述，取代 `docs/preprint-short.md`（早于 30 日的重审）作为入口。每一条后面给出证据所在；"条件性"指依赖已写明的附加前提或证明草稿。
> 读法约定：**强制** = 由原则推出；**偶然** = 律的自由参数，由辨认决定；**对照** = 洛伦兹流形等已知物理，只用于翻译和核对。

## 0. 处境与任务

我们是系统内部的记录者，没有全局语境（p-ZFC：记录与律是全局的，完成的整体与样本是局部的）。
物理学的任务：**地位**（每个量是记录事实、律的性质，还是局部完成物）、**强制与偶然**、**辨认**。不以推出已知物理为任务；每个结果须回答"谁能用它判定或算出什么"。（`docs/design.md` §0）

## 1. 原始对象

| 对象 | 定义 |
|---|---|
| 记录 | 可数的、一旦出现就不变的事实（p-ZFC 的原子） |
| 序 | 记录之间的先后关系（偏序） |
| 世界 | 一个记录的过去（下集）；世界之间由扩张相连 |
| 宽度扩张 | 在世界之上添加记录（新记录不在旧记录之下） |
| 高度扩张（加细） | 同一区域里记录更细的记录；粗世界的记录集是细世界的子集 |
| 过程 | 一条链；**节拍** = 链上的记录数；自由过程 = 两端之间最长的链 |
| 窗口 | 过程 i 经由 j 的往返跨度，以 i 的节拍计 |
| 分块 | 一个世界内对记录的分组（观察者分不清簇内记录）；粗层关系是权重 |

## 2. 原则

- **P1 / M4**：记录不被后来的记录扰动；事实在重叠处相容。
- **P2**：个体化不变——标号不携带信息；宽度扩张的先后只以序本身出现。
- **P4**：没有最细层；只有计数比，没有固定的离散尺度（D16）。
- **A5**：只有比值可观测。
- **不是原则**：局域性（Bell 因子化、条件独立）——它是律层面的全局粘合，其程度是被测量的（W10）。

## 3. 表示定理（强制，条件性）

**D1** 在一个汇合分支内，P1 + P2 + P4 ⟹ 律是一个（随机的）有序测度空间 (S, ≺, μ) 上的 Cox 型撒点：记录是以 μ 为强度的 Poisson 样本，关系由 ≺ 给出。
- 撒点被强制，而且没有固定密度（Mecke：可任意稀疏化 ⟺ Cox；Janson：可交换偏序 ⟺ 核表示）。（dynamics §2、§2.1）
- 加细是子集，所以高度方向的粗粒化是稀疏化；分块是世界内的描述。两者在表示里都封闭、互相交换。
- **律本身不跑动**：每个律都是粗粒化的不动点；样本层面的指数相对分辨率，在加细极限中消失。跑动只能来自内容。（F21）
- 序贯增长律（CSG）不是基本律：它只有宽度方向，在粗粒化下不封闭。（F17、F18）
- 全局表示只在汇合分支内存在；跨视界没有。

## 4. 地位结果（强制）

| 结果 | 内容 | 证据 |
|---|---|---|
| 刚性二分 | 束缚 ⟺ 相对速率是序的事实；退行时速率隐藏在快度区间内；多个观察者时隐藏参数是渐近切片 | F1、F2、F4–F6 |
| 宇宙时 | 宇宙时是序的事实 ⟺ 减速；匀速是临界；刚性是律的性质，有限记录不可判定 | F3，extension §8 |
| 汇合 | 汇合 ⟺ 无事件视界；共存模式由视界足迹的神经决定；视界上下文性需要 ≥ 2 个空间维 | F7–F9 |
| 分辨率 | 速率比不随分辨率跑动；σ 由束缚对的互窗口比局部读出；纯几何只给幂律 | F10、F14–F16 |
| 频率 | 两个观察者对一切描述的频率一致 ⟺ 窗口比 → 0 ⟺ 速率是事实（共享频率 = 共享时钟）；以过去为世界没有年轻悖论 | F19 |
| 扩张 | 扩张量只能是份额的对数；自相似 + M4 在 FRW 测试族里挑出匀速基线 | extension §2–3 |

## 5. 偶然的律

(S, ≺, μ) 本身是偶然的。平移齐性 ⟹ ≺ 由凸锥给出；各向同性 ⟹ 洛伦兹锥；维数不被强制。（D23，dynamics §3）

## 6. 内容与引力

- **计数亏损**：小区间的记录数 N 相对其最长链 L 的基线关系的偏离，领头系数是轴的二次函数。（dynamics §6）
- **内容** = 亏损的方向依赖部分：流向是亏损最大的轴，量是本征值，守恒由可积性强制；Λ 是各向同性亏损，属于真空，不是内容。（`docs/content.md`）
- **P5（偶然）**：空处亏损不依赖轴。对照族里 P5 ⟺ 真空爱因斯坦空间（Λ 允许）⟹ 内容必须改变 ≺（只改 μ 不产生外部场），外部 γ = β = 1。（F20）
  P5 独立于全部原则（Nordström 型是模型），可由计数检验，太阳系观测支持到 10⁻⁵。（F21）内容由计数定义后，P5 等价于符号条件"内容从不使近零速的自由过程散焦"（单参数族内；dynamics §8.2）。
- **源不能是记录数**：标量只给各向同性亏损，而 Schur 引理迫使各向同性亏损处处为常数。（D3）
- **内容的聚焦 ⟺ 过程族平均的刚性**：FRW 里沿共动轴的方向依赖部分为正 ⟺ 减速 ⟺ 宇宙时是事实；成对的刚性还受远处的潮汐影响。（F22）
- 无压内容的过程是最长链（可积性 ⟹ 守恒 ⟹ 测地运动，EIH 型）：自由下落不需要另一条定律。（content §2）
- 耦合 G 与 Λ 是框架里仅有的有量纲量；跑动 = 内容在分块下的非可加性（亏损的非线性）。（content §5）

## 7. 概率与宇宙学

宇宙学的频率问题分四类（`docs/anchor-measure.md`）：C1 一个世界里的计数（记录）；C2 沿一个观察者的极限（须极限可判定，否则是"开关"，没有事实）；
C3 观察者之间一致（⟺ 窗口比 → 0）；C4 跨视界的全体比例（只有当律的对称性给出唯一不变概率时才有值；永恒暴胀里一般没有）。全局切片截断 = 选一个个体化。

## 8. 边界

- **上下文性**：汇合分支内框架是非上下文的（η = 0）；η > 0 需要加细不有向（同一世界的两种加细没有公共加细），与宽度方向的视界对称。（F24）
- **放宽"世界对过去封闭"**：只保留"不能加细成序的团"，它在 D1 中是核的预序等价类；传递性缺口不可表示。（F23）
- **团内先后尚未成为事实、由不相容的加细回答**：η = max(0, 3q − 2)，阈值即孔多塞界——不定因果序的这种形式是上下文性的一个来源（F25）。

## 9. 与观测

维数、各向同性、P5（γ = 1）、G、Λ、内容的正性都由辨认确定；框架目前**不产生新的数值预言**，它产生的是地位划分与判据（`docs/identification.md`）。
没有观测到的东西也有地位：没有最细层与没有洛伦兹破坏型离散效应相容。

## 10. 开放问题（2026-09-30 末）

1. **物质的种类**：应力已有计数定义（content §4.1）；物态方程是偶然的；个体性问题 = 哪些物态方程允许内容自我维持为窗口有界的过程族（框架提出、不回答）。
2. **内容的跑动**：平面波例子已算（F27）：局部潮汐是正的、对轴四次的表观内容，随尺度跑动；多波长平均后变成对轴二次、不再跑动的真内容（Isaacson 型）。剩下：非平面波（例如球对称源）中的同类计算。
3. **D1**：各世界表示空间之间的标准 Borel 识别；宽度次序不带信息的精确陈述。
4. **上下文性**：(ii) 型团由循环核产生，且循环核 + 世界是偏序强制加细不有向（F26 Q5）；剩下：宽度（视界）与高度（不相容加细）两种粘合失败是否独立；与观测到的上下文性是否同类。
5. **P5**：零正性排除一切只改 μ 的律（一阶普遍成立；球对称时精确成立，dynamics §8.3–8.4）；"零正性 ⟹ 源外无内容"一般不成立（源外可有正内容），正确的一般陈述是内容必须改变 ≺。剩下：无对称性的非线性情形。
6. **C1 的一般形式**：已归结为判据 C1′（潮汐聚焦抵消相对速度，F26）；剩下：在具体非均匀律里计算。
