## F1 束缚的观察者：相对钟速由因果序唯一决定

## F2 退行的两个观察者：未定的速率恰好是一个标架快度
**陈述** 两个惯性观察者从同一事件出发、相对快度为 η：
- 序固定 Doppler 因子 e^η（节拍计数之比，结构事实）；
- 序**不**固定相对进度：序不变测度的极值速率恰好铺满 `(e^{−η}, e^{η})`；
- 快度为 φ 的惯性系的同时面给出速率 `s(φ) = cosh φ / cosh(η − φ)`，这是 ℝ → `(e^{−η}, e^{η})` 的严格递增双射；
- 以标架 φ 的同时面为终点作条件，中间速率重现 `s(φ)`。

即：**Doppler 不变 = 结构；时间膨胀随标架变 = 个体化（线性延拓）的选择**。狭义相对论的这一对区分，
恰好是"序的事实 vs 序不变测度不唯一"。

**证据** `calc/t2_rapidity.py`：
- 符号证明 `ds/dφ = sinh η / cosh²(η − φ) > 0`，两端极限为 `e^{∓η}`；
- 极值按 a + b·N^{−1/2} 外推（N = 1000…8000）：η=0.25 → 0.7800 / 1.2816（理论 0.7788 / 1.2840）；
  η=0.5 → 0.6075 / 1.6461（0.6065 / 1.6487）；η=1 → 0.3688 / 2.7143（0.3679 / 2.7183）；
- 标架条件化（η=0.5，N=4000）：φ = −0.5, 0, 0.5, 1 → 0.7328 / 0.8875 / 1.1272 / 1.3661，
  对应 s(φ) = 0.7308 / 0.8868 / 1.1276 / 1.3684。

**数学来源** 非唯一性来自 p-ZFC 隐藏速率定理（`W/P` 不趋于 0 ⟹ 速率区间）。区间的精确端点和标架映射是这里算的。

## F3 FRW 宇宙：宇宙时由因果序决定 ⟺ 减速膨胀
**陈述** 1+1 维 FRW，`a ∝ t^p`，共动观察者，共形间距 χ。同步窗口
`W(t) = 2χ t^p (1 + O(t^{p−1}))`（p<1）；`W(t) = 2t sinh χ`（p=1，Milne）；p>1 时有事件视界，
有限时间后窗口无穷。按 p-ZFC 的刚性判据（ρ = W/P → 0 ⟺ 刚性）：
- p<1（减速）：刚性，共动速率被序定死，**宇宙时是序的事实**；
- p=1（Milne，匀速）：临界、无标度，隐藏速率区间 `(e^{−χ}, e^{χ})`——Milne 里共动间距就是快度，
  与 F2 一致（Milne 就是闵氏时空的一块）；
- p>1（加速，含 de Sitter）：非刚性，宇宙时不再由序决定。

旧版的"时间是标度跑动的方向"（`t = log` 尺度）恰好是临界点 Milne。

**证据** `calc/t3_frw_exponent.py`：W/t 精确按 t^{p−1} 变化（p=0.5：0.127 → 0.063）；
p=1 时 W/t → 2 sinh χ = 1.042。极值差的拟合指数：p = 0.5 / 0.6 / 2/3 / 0.8 / 0.9 → −0.54 / −0.36 / −0.30 / −0.15 / −0.03
（p−1 = −0.5 / −0.4 / −0.33 / −0.2 / −0.1；越接近 1 有限尺寸滞后越大，与 t^{p−1} 型修正一致）；
p=0.3 完全刚性；p=1 的极值差 0.879 → 0.991（N=500→8000），趋向 1.042。
de Sitter（视界在 τ=1000）与 p=1.5 均非刚性。Poisson 节拍下（`l2a`）p=0.5 与 p=1 的结论不变。

**数学来源** p-ZFC 相变定理（凹包络条件下 刚性 ⟺ ρ→0）+ 这里算的 W(t) 渐近式。
快速文献检索未见"减速 ⟺ 宇宙时由因果序决定"的先例（**需认真查**）。

**状态** 速率部分为初等定理（F5）。测度部分：p-ZFC 相变定理要求窗口有凹包络（允许 O(√W) 误差）。
减速 FRW 的精确窗口 `W(t) = t[(1+ε)^k − (1−ε)^k]`（`k = 1/(1−p)`，`ε = χ(1−p)t^{p−1}`）只含 ε 的奇次项：
领头项 `2χ t^p` 给出 `W″ ≈ −2χ p(1−p) t^{p−2}`，下一项的二阶导为 `O(t^{3p−4})`，p<1 时是更高阶的小量，
所以 **W 最终是凹的，对一切 p < 1 条件成立**，整个序不变测度唯一（引用 p-ZFC 定理，C1）。
数值核对：p = 0.1 … 0.95、t = 10³ … 10¹² 时 W″ 均为负（sympy + mpmath 精确求导）。

## F4 三个以上观察者：隐藏参数是渐近切片，不只是洛伦兹标架（修正 F2 的推广）
**陈述** 三个两两退行的惯性观察者（快度 0、0.5、1）：惯性系只给出速率 `(s_B, s_C)(φ)` 的一条曲线，
但序不变测度的隐藏速率是**二维**的：终点取在曲线之外，中间也照样重现。与 p-ZFC 多链定理一致
（速率多面体维数 = 无标度边数）。对照组：A、B 相对静止（有界边）、C 退行，则 B 的速率锁定、只剩 C 一个隐藏参数。

所以一般陈述是：**因果序固定束缚对之间的 lapse 比，把退行对之间的 lapse 比留作全局隐藏参数；
隐藏部分是切片自由（GR 的"多指时间"）的渐近部分，惯性标架是其中的线性特例。**

**证据** `calc/t4_three_chains.py`，`calc/out/t4_three_chains_N240.txt`：

## 这四条合起来说的是什么

"尺度" = 两个过程之间的对数速率比。它有两种身份：
- **结构事实**：束缚对之间（引力红移、束缚运动的时间膨胀、减速宇宙里的宇宙时）；
- **全局隐藏参数**：退行对之间（标架、切片、加速宇宙），取值范围由结构事实（Doppler 因子、窗口增长）框定。

能量 = 速率，所以同样的二分适用于能量：**不变质量**（束缚系统内部的速率）是结构事实，
**能量**（相对某个切片）是隐藏参数的函数。这与狭义相对论完全一致，并给 L3 一个入口：
旧版"质量 = 阈值位置"应该对应刚性一侧（待做）。

## F5 数学上其实朴素：速率论断归结为窗口的几何（证明草稿）

**速率集合 = 容许区域的渐近斜率集合。** 两条链的线性延拓就是格点 (i, j) 平面上、
留在容许区域 R 里的单调格路径（design：`calc/twochain.py` 的文档串）。任何路径的渐近斜率都落在
R 的渐近斜率范围内。所以：
- **F3 的速率部分是初等的**：`W/P → 0` ⟹ R 的渐近斜率只有 1 ⟹ 每一种个体化的宇宙时速率都相同。
  减速 FRW 的 `W ∝ t^p`（p<1）直接给出结论，不需要 p-ZFC 的深定理；
- p-ZFC 相变定理加强的是**整个序不变测度唯一**（没有任何隐藏参数），不只是速率唯一。

**F2 的区间有显式构造。** 令 `P_p` 为 Bernoulli 游走：每步以概率 p 走 A 的一拍、以 1−p 走 B 的一拍。
条件在"永远留在锥 R 内"：`μ_p(前缀 π) ∝ p^{i}(1−p)^{j} · S_p(i, j)`，其中 (i, j) 是前缀终点，
`S_p` 是从那里出发的生存概率。
- 前缀概率只依赖终点 ⟹ μ_p 是**序不变**的；
- 漂移斜率 `s = (1−p)/p` 严格落在 `(e^{−η}, e^{η})` 内时，由大数律 `S_p > 0`，μ_p 良定义，渐近速率为 s；
- 路径被限制在锥内，所以区间外的速率不可能出现。

结论：**序不变测度实现的渐近速率恰为 `(e^{−η}, e^{η})`（至多加端点）。** 极值性（μ_p 是否是极值测度）没有证，物理论断也不需要它。
同一构造解释了刚性情形：带状区域里任何倾斜游走都几乎必然离开（生存概率为 0），指数倾斜族不存在。
F4 的二维性同理：三维容许区域的渐近锥是二维的。

**这意味着什么。** 物理论断的数学核心是朴素的；价值在**对应关系**：Doppler 因子 = 结构，
时间膨胀 = 个体化；减速 = 窗口次线性；隐藏参数 = 渐近切片。新颖性要这样说，不能说成新定理。

**相关文献**
- Andersson–Galloway–Howard（1998）的宇宙学时间函数：用过去因果曲线**长度**的上确界定义宇宙时，需要度规长度，不是纯序。
- 关于 Milne 宇宙里共动系约定性、宇宙学红移的运动学解释，已有讨论（与 F3 的临界情形一致）。
- 两次检索都没有找到"减速 ⟺ 宇宙时由因果序决定"的陈述。

**状态** 证明草稿（F2 的包含关系与区间外排除；F3 的速率部分）。

## F7 p-ZFC 的两种粘合失效，都落在 FRW 的膨胀史上（定理，证明初等）
**陈述** 空间平直的 FRW，尺度因子 a(t)。
1. **汇合（S4.2 的 .2）**：任意两个事件有共同的因果未来 ⟺ 共形时间向未来无界 ⟺ 没有宇宙学事件视界
   ⟺ `∫^∞ dt/a = ∞`。幂律 `a ∝ t^p` 时 ⟺ `p ≤ 1`。
2. **刚性**（F3）：共动对的同步窗口 `W(t) = 2χ a(t) (1 + o(1))`，所以速率由序定死 ⟺ `a(t)/t → 0`
   （共动邻居的退行速度趋于零）。幂律时 ⟺ `p < 1`。
3. **嵌套**：`a = o(t)` ⟹ 最终 `1/a ≥ c/t` ⟹ 积分发散。所以**刚性 ⟹ 汇合**，反之在 Milne 失效。

| 宇宙 | 速率（个体化） | 记录（汇合） | 模态逻辑（Diodorean） |
|---|---|---|---|
| 减速 p<1 | 由序定死 | 汇合 | S4.2 |
| Milne p=1 | 隐藏参数 | 汇合 | S4.2 |
| 加速 p>1 / de Sitter | 隐藏参数 | 不汇合（事件视界） | S4（1+1 维由 [SS05] 给出） |

**证明** (1) 共形变换保持因果序，所以因果序就是闵氏序限制在 `{η < η_max}` 上。
u、v 最早的共同未来在 `η = (η_u + η_v + |x_u − x_v|)/2`。`η_max = ∞` 时总存在；`η_max < ∞` 时，
在任意 w 的未来里取两个接近 `η_max`、相距接近 `2(η_max − η_w)` 的点，就没有共同未来。
(2) `dt/dη = a`，所以 `t_± = t ± χ a(t) + O(χ²)`。(3) 如上。
数值核对 `calc/t5_confluence.py`：W 与 `2χ a(t)` 吻合到三位以上；p = 1.5、2 的反例对最早共同未来落在 `η_max` 之后。

**模态逻辑** Goldblatt（1980）：闵氏时空因果序的逻辑恰为 S4.2。一个框架的逻辑是其点生成子框架逻辑的交；
`p ≤ 1` 时每个点的未来与闵氏光锥序同构，所以是 S4.2。p>1 就是 Lewis–van der Schaaf（2026）讨论里的
"2⁻-闵氏"半平面 `{t < 0}`，其逻辑为 S4（Shapirovsky–Shehtman 2005，Lemma 3.6，1+1 维）。
更高维的"恰为 S4"没有核实，但 .2 的失效是确定的。

**物理读法（与 p-ZFC 的对应）**
- p-ZFC：力迫扩张的模态逻辑是 S4.2，"对象发散、可能性汇合"。时空：S4.2 = 没有事件视界。
- p-ZFC 稳定化定理：有 .2 时极限唯一；没有 .2 时，"极限"是记录了所走路径的持久集。
  时空：**在加速宇宙里，一个问题的最终答案取决于观察者的世界线**（视界相对的知识，与 de Sitter 互补性的思路相近）。
- p-ZFC 的"全局性有严格层级"在这里实现为**刚性 ⊂ 汇合 ⊂ 一般**：减速宇宙两者皆有，
  Milne（即狭义相对论）只有记录汇合、没有唯一时间，加速宇宙两者皆无。
- 我们的宇宙正在加速：渐近地处在**记录不能全局粘合**的一层。这给 D5（不在全局粘合之下思考）一个物理理由，而不只是方法论偏好。
- 另一个对照（只作类比，未论证）：p-ZFC 里 S4（汇合失效）出现在非良基的"顶部扩张"；
  这里出现在共形时间有上界时。

**文献底线** Goldblatt 1980；Shapirovsky–Shehtman 2005；Lewis–van der Schaaf 2026（arXiv:2606.31927，
他们讨论了半平面给出 S4，没有联系到宇宙学或刚性）。

**状态** 证明（1、2、3 的初等部分）；更高维"恰为 S4"未核实。

## F8 加速宇宙里"能被一并记录的事件族"：视界足迹的神经（定理，经典结果的推论）
**设定** 共形时间有上界的平直 FRW（p>1，含 de Sitter），平移使 `η_max = 0`，空间维数 d。
L0（D10）：世界 = 因果过去，一族事件**共存**（能被某个观察者一并记录）⟺ 有共同的未来。

**陈述**
1. 事件 e 的未来在未来共形无穷 𝓘⁺ 上留下一个**足迹**：开球 `D_e = B(x_e, |η_e|) ⊂ ℝ^d`。
   一族事件共存 ⟺ 它们的足迹有公共点。所以**共存复形 = 足迹族的神经**。
2. **Helly**：一族事件共存 ⟺ 其中每 d+1 个共存。3+1 维里由四元组决定，1+1 维里由两两关系决定。
3. **空心模式存在**：存在 d+1 个事件，其中每 d 个共存、全体不共存（正则 d-单形顶点处、同一时刻的事件，
   足迹半径介于面外接半径 `√(1 − 1/d²)` 与外接半径 1 之间）。
4. **Wegner**：ℝ^d 中凸集的神经必为 d-Leray 复形。所以不是每种共存模式都能出现：
   p-ZFC 里"每种单纯复形都能作为共存模式实现"（其共存定理），在 de Sitter 里被**空间维数截断为 d-Leray 复形**。
5. 没有事件视界（p ≤ 1）时足迹是整个空间，任意事件族都共存（完全单形）。

**证明** 共同未来 z 满足 `η_z ≥ η_i + |x_z − x_i|` 且 `η_z < 0`，等价于 `x_z ∈ ∩ B(x_i, −η_i)`（取 η_z 略小于 0）。
其余是 Helly 定理与 Wegner 定理（凸集神经的 d-Leray 性）。

**物理读法**
- 在渐近 de Sitter 的宇宙里，"一组事件能否被同一个观察者最终一并看到"是一个**由空间维数控制复杂度**的粘合问题：
  两两能看到不代表三个能一起看到（d ≥ 2），而 d+1 个一组的检查就足够。
- 与 F7 合起来：事件视界既打破了汇合（.2），又把共存模式限制为 d-Leray 复形。
  这是 p-ZFC 的"共存模式"在时空里的具体样子，也是"空间维数"第一次以结构方式出现在我们的框架里
  （只作为非粘合的阶，不是推导出维数）。

**证据（F8）** `calc/t6_coexistence.py`（精确判据：候选极点枚举，不用优化器；d=1 与光锥精确公式在 5000 组上 0 分歧）：
- Helly：d = 1 / 2 / 3 检验了 19230 / 15144 / 8386 个 (d+2)-族，每 d+1 个共存的族全部共存，**0 次违例**；
- 空心 (d+1)-族（每 d 个共存、全体不共存）：d=1 为 343 例（即不共存的对），d=2 为 46 例，d=3 为 3 例；
- 显式构造：正则 d-单形顶点处的同时刻事件，足迹半径取在面外接半径（0.8660 / 0.9428）与 1 之间，
  每 d 个共存、全体不共存（d = 2、3 均确认）。

**状态** 定理（经典结果的推论）+ 数值核对。

## F9 视界诱导的上下文性至少需要两个空间维度（定理 + 数值）
**设定** 同 F8。一个观察者的"语境"= 他最终能一并记录的事件族，即共存复形（视界足迹的神经）的**极大单形**。
p-ZFC 的上下文律定理：各语境上的局部律能粘成全局律，当且仅当存在在所有重叠上一致的实现。

**陈述**
1. **d = 1**：足迹是区间。区间族的神经 = 区间图的团复形（区间的 Helly 性），区间图是弦图，
   弦图的极大团超图是 α-无环的。由 Vorob'ev（1962）/ Beeri–Fagin–Maier–Yannakakis（1983）
   （"两两一致 ⟹ 全局一致"对一切取值空间成立 ⟺ 超图 α-无环），**任何在重叠上一致的局部统计都能粘成全局律**。
   1+1 维的视界结构不给上下文性留任何空间。
2. **d ≥ 2**：存在空心三角（F8），语境超图可以不是 α-无环。于是存在两两一致、却没有全局律的局部统计
   （最简单的：三个 ±1 变量，每对都完全反相关，每对都被某个观察者看到，但没有观察者看到全部三个）。

**证据** `calc/rs`（Rust，`scd-calc nerve 50000`，输出 `calc/out/f9_horizon_contextuality.txt`）：
随机事件族 → 精确共存判定 → 用 Helly 性补全神经 → 极大单形 → GYO 约简。每种设定 5 万个覆盖、0 个判不准：

| 设定 | α-无环 | 含空心三角 |
|---|---|---|
| d=1，k=8 / 12 个事件 | **100% / 100%** | 0 / 0 |
| d=2，k=8 / 12 | 72.9% / 63.0% | 20.4% / 27.5% |
| d=3，k=8 / 12 | 57.4% / 51.3% | 34.9% / 39.4% |

（非 α-无环的覆盖多于含空心三角的覆盖：还有更长的无弦环，例如环形排列的四个圆盘。）

**要说准的地方**
- 这是关于时空**允许什么**的结论。如果每个事件都带一个与观察者无关的记录（全局事实），全局联合分布平凡地存在（事实能粘合），
  上下文性不会出现。只有当"记下什么"依赖于"谁来记"（p-ZFC 的"谁在问"这一情形失效）时，d ≥ 2 的视界覆盖才可能出现不可调和的统计。
- 与 p-ZFC 的"上下文性与世界合并在两个方向上都独立"一致：视界（合并失效）只提供了上下文性的**空间**，不强迫它出现。
- 这一步开始进入 L4（量子/观察者层），但还没有涉及量子理论本身。

**状态** d=1 为定理（经典图论 + Vorob'ev/BFMY）；d ≥ 2 的存在性由 F8 的空心单形给出；数值核对。

# B：分辨率作为第二种扩张（以下只用框架内的概念）

**设定** 分辨率 = **民主粗粒化**：每个事件独立地以概率 q 保留，粗的序是细的序的子序。
这个操作不需要任何几何（撒点的"均匀"要用体积，而这里只要求对所有事件一视同仁）。
p-ZFC 意义上这是第二种扩张：细的世界包含粗的世界，关于粗记录的事实在加密下不变（M4 成立）。

## F10 尺度不跑动，内容跑动；"能标 × 尺度 ≈ 1"的内禀版本（引理，朴素）
1. **速率比在民主粗粒化下不变**：两条链各保留约 q 倍的节拍，比值不变（大数律）。窗口类（F 系列的四分类）也不变，
   窗口长度按 q 缩放。所以本框架里 **σ（尺度）不随分辨率跑动**。
2. **随分辨率变化的是内容**：一对过程在 `a_i` 处的窗口长度为 W（由序决定）。粗粒化后窗口里剩下的元素数服从 `Binomial(W, q)`，
   窗口非空的概率为 `1 − (1 − q)^W ≈ 1 − e^{−qW}`。窗口一空，这两个过程在该分辨率下两两可比、合成一个过程。
   **跨越发生在 `q·W ≈ 1`**：要把一个"尺度"为 W 的结构分辨成两个过程，节拍密度至少要到 `1/W`。
   - "尺度"在这里的定义是窗口，即两个过程之间的不可比跨度（纯序的量）；"能标"是保留下来的节拍密度（分辨率）。
   - 这是旧版 A3（能标 × 尺度 = 1）第一次在框架内部被推出：只用计数，不用 ħ，也不用傅里叶。
3. **读法**：一个束缚系统在粗分辨率下看起来是"一个"过程，在细分辨率下显出内部结构；
   分辨它所需的分辨率与它的尺度互为倒数。旧版"内容依赖于分辨率"（Emergence）由此得到一个内禀形式。

**状态** 引理（初等概率）。价值在对应关系，不在数学。

## F11 最长链过程的可区分性阈值：ρ ≳ T⁴/d⁶（条件性；数值 + 标度论证）
> **条件（2026-09-29 清账，D16）**：本条依赖按固定密度 ρ 往给定流形里撒点，即依赖一个最细层级和一个背景。框架不采纳这两点；本条只作为"假如存在最细层"的条件性结果保留。

**陈述** 用"两个事件之间的最长链"作为过程（最大节拍数的过程，是链的内禀选择），两个相隔 d 的过程在持续时间 T 内，
在密度（分辨率）ρ 下是否可区分？最长链的横向涨落按 `ρ^{−1/6} T^{2/3}` 增长（Ulam/KPZ 指数 2/3，最后通过渗流里的已知结果），
涨落超过间距时两条链聚合、共享事件。所以可区分性应只依赖于 `x = d ρ^{1/6} / T^{2/3}`，
阈值在 x 约为 1 处：**需要 `ρ ≳ c · T⁴ / d⁶`**。

**证据** `calc/rs`，`scd-calc collapse 6`，输出 `calc/out/b5_coalescence_collapse.txt`。
ρ ∈ {0.5, 2, 8}、T ∈ {250 … 4000}（六种组合，ρ 与 T 各跨 16 倍），每点 6 个种子：

| x | 0.1 | 0.25 | 0.5 | 1 | ≥ 2 |
|---|---|---|---|---|---|
| 共享比例（六组范围） | 0.61 – 0.89 | 0.35 – 0.75 | 0 – 0.27 | 0 – 0.07 | 0 |

数据按 x 塌缩，转变在 x ≈ 0.5 – 1。残余离散来自种子太少和有限链长（链越长，小 x 处共享比例越高）。

**与 F10 的对比** F10 的阈值是 `q·W ≈ 1`（对 1+1 撒点，W ∝ √ρ·d，即 `ρ ≳ 1/d²` 型），与持续时间无关；
F11 的阈值 `ρ ≳ T⁴/d⁶` 依赖持续时间：**持续得越久，要把两个固定间距的过程区分开，需要的分辨率越高**。
两者的差别来自"过程"的定义：F10 的过程是给定的链，F11 的过程是最长链（会在随机的序里游走）。

**要说准的地方** 聚合现象本身是已知的（随机环境里测地线聚合），指数来自 KPZ 普适类，这里只在 1+1 维撒点上检验。
新的是读法：它给出了一个与"能标 × 尺度 ≈ 1"不同的、依赖持续时间的分辨率阈值，并且完全用序陈述。
更高维的指数（KPZ 横向涨落指数随维数变化）没有做。

**状态** 数值（数据塌缩）+ 标度论证。

（以下三条出路是在"存在最细层"的前提下写的；D16 之后，首要的出路是**不存在最细层**，见 F14 起的工作。）

所以 F12 的现实冲突指向更深的地方，框架只剩三条出路（按我的判断从强到弱）：
1. **过程是聚合**：物理对象是许多链的聚合，它的"位置"是聚合的平均，离散涨落被平均掉。
   若各链独立，偏离按 `1/√N` 缩小；越"重"（内部事件越多）的对象越直——这与"重物体走经典轨迹"的现实对应，
   而且不需要引入量子理论。但 F11 表明同一样本里相邻链会聚合（强相关），独立性不能假设，要算。
2. **序不是泊松式的随机**：更规则的序涨落更小。但现实里洛伦兹不变性被检验得极精确，而规则的序一般会选出优先标架；这条路代价很大。
3. **ξ₄ 实际上 ≤ 0.5**：F12 的 3+1 维估计很粗（链只有约 44 个元素），不能排除。需要更大的计算。

**状态** 数值。出路 1 是目前最自然的方向，但它决定"物质/过程"在框架里是什么，属于设计层面的选择。

## F14 σ 的局部读法：束缚对的速率比 = 互窗口之比（命题 + 数值）
**陈述** 对一对窗口有界（束缚）的过程，`a_i` 在 B 上的窗口 `W_B(a)`（B 的节拍数），与 `b_j` 在 A 上的窗口 `W_A(b)`（A 的节拍数），
在"同一处"比较时满足 `W_B(a) / W_A(b) → e^{σ_B − σ_A}`（速率比），误差 O(1/W)。
理由：容许区域是宽度有界、局部斜率为 s 的带，竖直宽度 / 水平宽度 = s。
- 这给出 σ 差的**局部**读法，不需要渐近极限：每个过程用自己的节拍去数对方"看到的不可比跨度"，两个读数之比就是尺度比；
- 对退行的一对，比值依赖于拿哪个 `a_i` 和哪个 `b_j` 比（`j = s·i` 时比值为 `1/s`），即依赖切分——与 F2 一致，σ 差在那里不是序的事实；
- 在链接细分下两边窗口同乘 k+1，比值不变（与命题 2 一致，无尺度）。

**证据** `calc/b1_mutual_windows.py`，输出 `calc/out/b1_mutual_windows.txt`：

| 情形 | 互窗口之比 | 速率比 |
|---|---|---|
| 静态对，lapse 比 0.8，窗口约 32 / 300 拍 | 0.7805 / 0.7980 | 0.8 |
| 静态对，lapse 比 1.3，窗口约 40 / 400 拍 | 1.3250 / 1.3025 | 1.3 |
| 振荡的束缚对（周期平均） | 0.8968 | 0.9028 |
| 减速 FRW，p = 0.5 | 1.0000 | 1 |
| 退行 η = 0.5，比较 `j = s·i`，s = 0.779 / 1 / 1.284 | 1.2833 / 1.0000 / 0.7820 | 依赖切分（带形公式 1/s） |

**与物理实在的对应** 两座处在不同势位的钟用雷达往返测量彼此，各自读到的往返时间之比恰好是红移因子（广义相对论里的精确事实）。
这里它是一个纯序的恒等式，也是旧版 A4"物理长度 = 裸长度 × 局域单位"的关系式版本：同一段"间隔"被两个过程计数，读数之比就是尺度比。

**σ 场的约束（下一步）** 三个两两束缚的过程，σ 差沿回路之和必须为零：
`log(W_B(a)/W_A(b)) + log(W_C(b)/W_B(c)) + log(W_A(c)/W_C(a)) = 0`。这是对序的非平凡约束。
在静态（以及定态）的对照例子里它自动成立（两点往返对称）；不成立时 σ 就不是势，这是旧版"非恰当梯度（𝕋 支）"在序里的位置。

**状态** 命题（带形区域的初等几何）+ 数值。

## F15 分块版地基：连续极限由鞅收敛保证，结构逐渐显现（定理 + 命题；D18）
详见 `docs/blocking.md`。要点：
- **B1（定理，Doob）** 粗层权重 = 细层权重按份额的平均（塔性质），所以沿嵌套簇序列的权重是有界鞅，几乎必然收敛。
  连续统作为加细的极限存在，是定理而不是假设；它在 p-ZFC 的意义上是局部的，记录永远是簇。
  极限是否锐利（几乎处处 0/1）是可检验的条件。
- **B2** σ 由过程的份额承载，跨层可加，所以不随分辨率变（红移消色差）；经过的**簇数**之比不是 σ。
- **B3** F14（互窗口比 = 速率比）在以份额计时保留。
- **B4** 嵌入版的"可区分性是按钮"在分块下**不成立**：粗层的不可比可能是分块假象。结构在一个分辨率范围内**逐渐显现**，
  对应现实里的**形状因子**，比嵌入版的锐利阈值更像现实。
- **B7（标度论证）** 纯几何的测试序只给出 `(簇尺度 / 窗口)¹` 型的幂律（指数 = 光锥余维数 1）；
  对数型的跑动只能来自分布在许多分辨率上的额外内容（条件句，不预设内容分布，D17）。

**状态** B1 为定理；B2–B6 为初等命题；B7 为标度论证，待数值核对。

## F16 B7 的数值核对：纯几何的模糊份额 = 4 ·（簇尺度 / 窗口），指数 1.000
`calc/b2_blocking_powerlaw.py`（1+1 维两个静态过程，窗口 2d = 100；分块为光锥坐标下边长 δ 的方块，即因果钻石；权重由一维区间精确计算）：

| δ / 窗口 | 0.01 | 0.02 | 0.05 | 0.1 | 0.2 | 0.5 | 1 | 2 | 4 |
|---|---|---|---|---|---|---|---|---|---|
| 模糊份额（每单位窗口） | 0.04 | 0.08 | 0.20 | 0.40 | 0.80 | 1.5 | 2.0 | 3.0 | 5.0 |
| 合并份额 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

δ/窗口 ≤ 0.2 时拟合指数 1.000，与 B7 一致。合并份额在单一规则网格下是锐利跳变（δ = 2 × 窗口）；
网格的放法本身是一种个体化选择，对网格位置取平均后，合并变成以 δ ≈ 窗口为中心的平滑过渡（B4、B6 的"逐渐显现"）。

**读法** 纯几何只有幂律。这把"对数型跑动从哪来"的问题压实了：它不可能来自序的几何本身，只能来自分布在多个分辨率上的内容。

# 规律（D19、D20）

## F17 传递渗流不满足 P4：它在粗粒化下不封闭（数值）；P4 + 分块 ⟹ 律必须作用在权重上（推论）
**检验** 传递渗流 TP(p)：元素依次出生，每对以概率 p 独立连边，取传递闭包（Rideout–Sorkin 的 CSG 族里最简单的成员）。
粗粒化取最简单的随机稀疏化（每个元素以概率 q 保留，取诱导子序）。在很宽的网格（0.4p … 4p）上找一个 TP(p′)，
使 15 个统计量（距离 1…8 的相关概率 r_k，三个相邻元素的 7 种关系模式）的 χ² 最小。
`calc/rs`，`scd-calc perc 2000`，输出 `calc/out/p4_percolation_thinning.txt`。

| 设定 | 最优 p′ | 最小 χ²（自由度 14） | 只按 r₁ 拟合时的 χ² |
|---|---|---|---|
| p = 0.1，q = 0.5 | 0.127 | **7163** | 25389 |
| p = 0.05，q = 0.25 | 0.086 | **14905** | 39409 |
| p = 0.02，q = 0.5 | 0.022 | 80 | 207 |

**结论** 没有任何 p′ 能同时拟合所有统计量：**传递渗流在稀疏化下不封闭**。偏差的形状一致——稀疏化后，相关概率随距离增长得比任何
TP(p′) 都快，三元模式也不符。被删掉的中间元素成了"隐藏的共同原因"，产生 TP 表达不了的长程关联。
偏差随 p 减小而变小：弱耦合极限下 TP 近似封闭，但不精确。

**推论（比数值更根本）** 按 D18 分辨率是分块，分块的产物是带权重的关系；按 P4 没有最细层。
所以**每一层的关系都是权重**，锐利的序只能作为极限出现（命题 B1）。传递渗流和整个 CSG 族都是锐利的，
**不可能是分块下的不动点**，最多是极限对象。律必须从一开始就作用在带权重的序上（p-ZFC 的"值"参数取权重）。

**关于绝对因果（D19）** 这给出一个不借量子理论的框架内回答：**在任何有限分辨率下，因果关系都是权重；锐利的、绝对的因果只是极限性质**，
而且要以 B1 的极限锐利为条件。"不定因果序"（D19 的开放选项）在这里有一个经典的、弱化的对应：粗层上的因果关系本来就不是 0/1。
它与"共存记录之间的因果序不能全局粘合"是不同的两件事，后者仍待审视。

**状态** 数值（稀疏化）+ 推论。分块下的检验、以及更大的 CSG 族是否封闭，尚未做。

## F18 协变（P2）与 Bell 因果（P3）在粗粒化下都不保持；CSG 族不封闭（数值 + 机制）
**检验** 传递渗流从空序开始增长，以概率 q 稀疏化，看最先保留的 3–4 个元素构成的（带标号的）增长过程。每组 2000 万次。
`calc/rs`，`scd-calc covbell`，输出 `calc/out/p23_covariance_bell.txt`。

| 设定 | P2：三元"链 + 孤立元"三种标号 {1≺2} / {1≺3} / {2≺3} | P2：四元（24 自由度）χ² | P3：Bell 比值相对 {1} 情形的偏差（反链 / 链） |
|---|---|---|---|
| p=0.1，q=1（对照，即传递渗流本身） | 0.0810 / 0.0810 / 0.0810（χ² 0.5） | 19.5 | −0.04% / +0.09%（误差内） |
| p=0.3，q=1（对照） | 0.1471 / 0.1469 / 0.1471（χ² 1.9） | 23.7 | −0.08% / −0.08%（误差内） |
| p=0.1，q=0.5 | 0.0850 / 0.0930 / 0.0850 | 47047 | +7.9% / +20% |
| p=0.3，q=0.5 | 0.1278 / 0.1524 / 0.1277 | 216223 | +5.7% / +42% |
| p=0.1，q=0.25 | 0.0910 / 0.1185 / 0.0909 | 456341 | +22% / +74% |

**结论**
1. 对照组全部通过：代码可靠，传递渗流本身协变且满足 Bell 因果。
2. 稀疏化后**协变与 Bell 因果都大幅违反**。所有 CSG 律都满足这两条，所以稀疏化后的传递渗流不在 CSG 族里：
   **CSG 族在粗粒化下不封闭**（D20 第 2 步由此回答）。
3. **机制：被删掉的元素是一个隐藏的时钟。** {1≺3} 比 {1≺2}、{2≺3} 更常见，因为 1 与 3 之间隐藏着更多被删元素、底层"经过"更久。
   细层的出生顺序（一种线性个体化）泄漏进了粗层。这是内在的：一个序上的均匀线性延拓，限制到子序上一般**不是**均匀的。
4. 我设计的"不传信"检验受同一个隐藏时钟干扰（第三个元素本来就比第二个晚出生），**不能作为结论**，需要重新设计。

**含义** "带标号的逐个增长 + 协变"这种律的写法，在每一层都预设了一个线性的个体化（p-ZFC：线性时间只是个体化的指标）；
粗粒化会把这个个体化泄漏出来，破坏协变。所以在跨分辨率的框架里，**律不能写成逐个元素的增长过程**，
而应直接写在无标号（或权重）的序上，个体化不变性从一开始就内建，而不是事后要求。
这是本框架与因果集动力学的第一个实质分歧点，而且来自 P4（没有最细层），不是来自偏好。
