# 物质：个体、质量与被强制的界（2026-09-30）

> 接 `docs/content.md`：内容 = 计数亏损的方向依赖部分；应力 = 正交于内容主轴的部分；物态方程是偶然的。
> 本文件问：什么是一个物质个体；质量是什么；框架对物质有哪些**被强制的**限制（与物态方程无关的）。对照族只用于翻译。

## 1. 个体 = 窗口有界的内容族（定义 M1）

- **定义** 一个物质个体（粒子、天体）是一族内容过程，它们两两的窗口有界（刚性，F1）。
- **跨分辨率的读法** 在比窗口界更粗的分辨率上，这一族分块成**一个**粗过程；在更细的分辨率上，它显出内部结构。
  所以"个体"就是 D15 所说的"跨层相容的一族链"的一个具体来源：刚性使它在粗化下保持为一个过程。
- **p-ZFC 的对应** "一个源有记录，当且仅当两次独立读取以一致有下界的概率一致"。窗口有界的族在粗层是一个可重复读取的过程——一个有记录的源；
  窗口无界的内容（辐射、弥散的物质）在粗层没有持久的个体，只有律。
- 这给出"有个体的物质"与"弥散的内容"之间的一条内禀界线：**刚性**。

## 2. 质量（命题 M2）

- **质量 = 个体在粗层作为源的量**：粗层区间的亏损中由这个个体贡献的部分（content §1 的本征值，对个体所在区域积分）。
- **非可加性是强制的**：内部运动使内容的贡献按相对快度加权（D3：aγ² + b），内部潮汐场在粗层表现为附加的正内容（F27）。所以个体的质量 ≠ 其部分的质量之和；
  差额就是"结合能"。这是 F10"尺度不跑动，内容跑动"在个体层面的形式。
- **质量之比何时是事实**：两个个体若相互束缚，它们内部节拍的比是序的事实（F1）；若退行，是隐藏参数（F2）。所以"质量比"作为节拍比时，只在束缚的情形下是序的事实。
  （旧版的 H-质量假说——质量 = 内部节拍率——在这里只剩一个条件陈述；它需要 ħ 把节拍率换成质量，而 ħ 属于内容，见 `docs/quantum.md` §5。）

## 3. 被强制的界：不依赖物态方程的数（命题 M3）

框架不产生"值"，但可以产生**界**——对一切满足原则与零正性的物质都成立的无量纲不等式。
- **表面钟速的界**：在对照族里，静态球对称、密度向外不增、满足零正性（及 P5 的外部解）的个体满足 Buchdahl 界 `2GM/(Rc²) ≤ 8/9`，
  等价于表面相对无穷远的红移 `1 + z ≤ 3`。在框架里，红移就是束缚对的速率比（F14：互窗口之比），所以这个界读作：
  **任何静态的物质个体，其表面过程与远处过程的速率比不小于 1/3**——一个由计数可读、与物态方程无关的普适数 3。
- **束缚需要正的应力**：无压内容沿最长链运动（content §2），不能保持窗口有界的静态构型；静态个体必须有抵抗自身聚焦的应力（对照：流体静力平衡；位力定理）。
- **应力不能负到散焦快速过程**（零正性，dynamics §8.2）：这排除了"负压撑起"的静态个体。
- 这修正了 F21 的一个说法："框架不产生数"应改为"框架不产生**值**，但产生**界**"：孔多塞界 2（law §6）、Buchdahl 的 3、F19 的阈值 ρ → 0 都是这一类。

## 4. 物质的种类仍是偶然的

- 物态方程（应力与内容量的关系）不被强制；它决定哪些个体存在（例如恒星、白矮星、中子星的质量–半径关系）。
- 框架能提出、不能回答的问题：**哪些物态方程允许内容自我维持为窗口有界的过程族，而且在粗化下稳定？** 这是"物质为什么分成个体"的框架内形式。
- 离散的物种与质量谱（粒子物理）完全不在框架现有的范围内；它们需要内容的内部结构，而那大概与量子问题（`docs/quantum.md`）连在一起。

## 5. 限制

- M3 的 Buchdahl 界是对照族里的定理（静态、球对称、密度单调）；在框架里它是"P5 + 零正性 + 单调性"的推论，不是新的物理。新的是地位：一个与物态方程无关的、可由计数读出的普适数。
- M1 的"个体 = 刚性内容族"是定义；它是否与观测到的个体（恒星、原子）一一对应，是辨认问题。


## 6. 哪些内容能形成稳定个体：刚度阈值（命题 M4，`calc/mt1_stiffness_threshold.py`）

对照族的牛顿极限、d 个空间维：内部能 ∝ R^{−d(Γ−1)}，引力能 ∝ −R^{−(d−2)}；平衡处 `E'' = B n R^{−n−2}(m − n)`（m = d(Γ − 1)，n = d − 2）。
所以**稳定的个体 ⟺ Γ > 2 − 2/d**；d = 3 时 Γ > 4/3。
- **辐射型内容恰好在临界**（Γ = 4/3）：它不能形成稳定个体。这与 §1 的内禀界线一致——辐射只有律，没有持久的个体。
- 相对论修正把阈值抬高（Chandrasekhar），与 Buchdahl 界一起说明：没有任意致密的稳定个体。
- 又是一个"界"：阈值 2 − 2/d 只依赖维数（偶然的 d），与物态方程的细节无关。

## 7. 等效原理的地位（命题 M5）

- **弱等效原理是强制的**：无压内容沿最长链运动，与它的量无关（content §2，可积性 ⟹ 测地运动）。所有个体以同样方式自由下落，不需要"惯性质量 = 引力质量"的额外假设。
- **强等效原理**（自引力的个体也同样下落，Nordtvedt 效应为零）在对照族里依赖场方程的形式：GR 型（P5）成立，标量型（只改 μ）一般不成立。
  所以在框架里，**强等效原理与 P5 同一地位：偶然、可检验**（月地激光测距把 Nordtvedt 参数限制在 10⁻⁴ 量级）。
