# 扩张律：动力学的位置（R9，晚间探索，2026-09-29）

> 用户睡前同意方向："从世界如何扩张的规律入手找动力学"。本文件是自主探索的记录，**未经用户审阅**。
> 约束照旧：不以 GR/量子为形状（D13），不引入尺度（D16），推出来才算，放进去不算。

## 1. 对象：一个开放的记录系统

两种扩张（`docs/law.md` §2）：
- **宽度**：世界 W 扩张为 W′，加入新记录；旧记录及其关系不变（M4）。
- **高度**：加细（分块的逆），各层权重相容（B1）。

R9：没有完成的宇宙；每个世界都有真的宽度扩张（M3）。一个**扩张律**是关于"世界如何增长"的概率描述，
在每个世界内部对个体化不变（可交换，R4），在宽度与高度两个方向上都相容。

## 2. 扩张的量只能是比值，于是自然时间是"大小的对数"

扩张的"多少"只能用内禀的量表示：W 在 W′ 中所占的份额 `f = |W| / |W′|`（计数比；在权重层是份额之比）。
没有绝对单位（A5）。两次扩张复合时份额相乘，所以 `s = −log f` 可加。
**若宽度方向也没有最小的扩张步（P4 在宽度方向的对应），扩张律就是以 s 为参数的连续单参数半群。**
这个 s 就是框架自带的时间参数：**世界大小的对数**。它和 σ（跨过程的计数比的对数）、能标（跨层的计数比的对数）是同一类型的量。
旧版"时间就是标度跑动的方向"在这里不是公设，而是"只有比值 + 可复合"的结果。
**证明**：扩张量 φ 是份额 f ∈ (0, 1] 的函数，复合可加 `φ(f₁f₂) = φ(f₁) + φ(f₂)`，且扩张越多 φ 越大（单调）。
单调的 Cauchy 函数方程只有解 `φ = −c log f`。所以唯一的选择是对数，常数 c 只是单位（A5）。
（剩下要论证的是"宽度方向没有最小扩张步"，即 f 可以取 (0, 1] 中任意值；它是 P4 在宽度方向的对应，与 M3 相容但不由它推出。）
**（2026-09-30 标注）** 连续的份额是**律层面**的量（p-ZFC：无原子的源有律而无记录；记录层的份额总是离散的）。另有一个类比（非定理）：p-ZFC 里旧世界的点集在新世界里一般零测或只有窗口 [μ_*, μ*]；"世界大小之比"是否总有确定值，列为开放问题。
**同夜续：宽度方向的无最小步可以归结为高度方向的无底。** 在计数层面份额总是离散的（一次加一个记录）；连续的份额只在权重层有意义（D18：权重是加细下计数比的极限）。设 W ⊂ W′ 是两个世界（下集），取 W′∖W 上的一个线性扩张（个体化），令 W_s = W ∪ {前 s 份权重的记录}：每个 W_s 仍是下集（线性扩张保序），份额随 s 单调；它连续地扫过 [|W|/|W′|, 1] 当且仅当权重**没有原子**（没有一个记录或团携带正的权重份额而不能再分）。而"没有原子"正是 D16 的无底加密在权重层的说法：每个团都能加细成权重更小的子团。所以 f 可取任意值 ⟸ 无底加密 + 权重无原子；宽度方向的 P4 不是新假设，是高度方向 P4 的推论（前提是加细在每个团里都进行，即不存在"停止加细"的团——这与 law §7.1 里"不能加细成序的团"的选项有张力，要一起考虑）。

## 3. 无内容的基线：自相似扩张挑出匀速膨胀（命题 E1）

**命题** 在平直幂律 FRW 测试族 `a ∝ t^p` 里，同位相似变换的生成元 `ξ = t ∂_t + (1−p) x ∂_x` 把每条共动世界线映到自身，当且仅当 `p = 1`。
- A5（扩张没有优先尺度）⟹ 律在某个同位相似下不变；
- M4（扩张不改变哪个过程是哪个过程）⟹ 这个同位相似固定每个过程；
- 两者合起来 ⟹ **匀速膨胀** `a ∝ t`（`calc/e1_selfsimilar_extension.py`，sympy 验证）。

**与已有结果的一致性**
- 匀速膨胀正是 F3 的临界情形：共动对的窗口线性增长，速率是隐藏参数（没有由序决定的宇宙时），但记录仍汇合（没有事件视界）。
- Milne 观察者的过去体积 ∝ τ^D，所以 s = log(大小) = D·log τ：s 就是 Milne 的共形时间。基线里"时间 = 标度的对数"精确成立。
- **开端（同夜更正措辞）**：严格自相似的律向过去限制时也自相似，所以基线里**没有最小的世界**（旧版"没有第一时刻"的对应）。
  但 Milne 基线里所有共动过程向过去汇聚到一个**极限点**（同位相似的不动点）：它不是一个记录，任何世界都不包含它。
  所以准确的说法是"没有第一个记录，但所有过程共享一个作为极限的过去端点"，而不是简单的"没有开端"。
  内容打破自相似后情况如何，仍然开放。

## 4. 与现实的对照（要说准）

| 量 | 无内容基线（匀速） | 观测（平直 ΛCDM，Ω_m = 0.315） |
|---|---|---|
| H·t | 恒为 1 | a = 0.1 时 0.667，a = 0.5 时 0.721，今天 0.951，a ≈ 1.09 时穿过 1，之后增长 |

- 真实宇宙**不是**匀速膨胀的：早期减速（物质），晚期加速（暗能量）。
- 框架的读法：**匀速是无内容的基线，内容（输入，D17）打破自相似**；物质使 H·t < 1，暗能量使它增长。
- 今天 H·t ≈ 0.95 接近基线值，在 ΛCDM 里是时间上的巧合。**不当作证据。**已有的"R_h = ct"匀速宇宙学是边缘模型，被多组数据不支持；本框架不主张宇宙在匀速膨胀。
- 真正的问题因此变成：**内容如何打破扩张的自相似？** 这正是动力学（R8）的内容，也是引力应该出现的地方。

## 5. 通向引力：候选原则与"是否偷放进去"的判据

引力在这里的形状应当是：**内容在局部打破扩张的自相似**，其读数是静态过程之间的 σ 差（F14：互窗口之比）。
要检验的里程碑：在一团内容周围，σ 是否自发出现 1/r 型的变化（牛顿极限）。

| 候选 | 内容 | 判据：是否偷放进去 |
|---|---|---|
| 跨世界一致（粘合） | 重叠世界里的扩张量必须相容 | 单靠它只能得到"σ 是势"（F14 的回路条件），得不到方程——**不够** |
| 最小速率不均匀 | 在给定内容下，σ 取使 `Σ(σ_i − σ_j)²` 最小的分配 ⟹ 拉普拉斯方程 ⟹ 三维中 1/r | **有偷放的风险**：选二次泛函就等于选了拉普拉斯形式；除非二次性本身能推出来 |
| 局部自相似破缺 | 内容处扩张不再自相似；远处恢复基线 | 最贴近本框架，但还没有把它写成定量规律 |
| 稳定化 / 汇合 | 要求沿记录变化有限次的问题有唯一极限 | 会偏好无视界的律；与加速膨胀的关系要先想清楚 |

**我的判断**：目前没有一条候选能在不偷放的情况下给出牛顿极限。"最小速率不均匀"最容易"成功"，但那正是最可疑的一条。
下一步应当是把"局部自相似破缺"写成一个可计算的玩具律，看 σ 的剖面**自己**长成什么样，再与 1/r 比较。

## 6. 规律必须提供什么：静态网络 = 光学度规 + 势

对一组相对静止（束缚）的过程，窗口 `W_ij` 是 i 用自己的节拍数到的往返跨度。由 F14，`W_ij e^{−σ_i}` 对 i、j 对称，
所以序数据恰好分解为
- 一个对称的 **光学度规** `d_ij = W_ij e^{−σ_i} / 2`（往返距离；还须满足三角不等式：经由第三个过程往返不会更快），
- 一个 **势** σ（在回路条件下，F14）。

在运动学层面 d 与 σ 都是自由的。**规律要提供的恰好是：给定内容时 σ 与 d 的关系**——本框架里爱因斯坦方程的位置。
（对照：广义相对论的静态真空方程说 lapse 相对空间度规是调和的；空间度规与光学度规差一个 lapse 的共形因子。这只作为要达到的对照目标，不作为前提。）
牛顿极限的对照目标写成框架的量：远处 `σ ≈ −(常数) × (源的内容量) / d`。

## 7. 两个结构性观察（假说级）

**7.1 引力 = 把隐藏速率变成结构事实的机制。** F1–F3：束缚对、减速宇宙里速率是序的事实；退行对、加速宇宙里是隐藏参数。
物理上是物质把东西束缚住、让膨胀减速。所以引力在本框架里的角色很可能是：**内容把无标度的扩张局部地变为刚性**，使时间在局部成为结构事实。
这把全部运动学结果的核心二分（刚性/隐藏）与动力学接了起来。它是一个串联已有结果的假说，还没有定量规律。

**7.2 引力耦合必然是唯一的有量纲量。** 在只有比值的框架里，σ 的亏损若 ∝（源的计数率）/（窗口），其单位是 1/节拍²：
任何给出牛顿式衰减的规律都必须带进一个有量纲的常数。这与旧版 `Weight.lean` 的"引力是唯一跨越分级的相互作用"一致。
所以 D16 排除的是**离散尺度**；引力耦合是另一回事：它是框架唯一的有量纲量，随内容进入，并打破无内容时的自相似基线（§3）。
要警惕：这一条是量纲计数，不是动力学；它说明"引力一定带尺度"，没有说明引力怎么来。

## 8. 刚性是律的性质，不是记录的事实（p-ZFC 稳定化）

一对过程是否束缚（窗口相对经过时间趋于 0）是一个**渐近性质**：
- "窗口曾经超过 k"一旦成立就永远成立：p-ZFC 意义上的按钮（持久答案）；
- 但"窗口 / 经过时间 → 0"含"对所有 ε，最终都小于 ε"的无穷量词。对**每个固定的 ε**，在窗口比单调的情形下，
  "当前比值 < ε"至多改变一次，是极限可判定的；刚性是**无穷多个这样的问题的合取**，不是单个有限次改变的问题，
  在任何有限阶段都判定不了（更正了初稿里"一般是开关"的说法）。
- 任何有限的记录集合，都同时与"束缚"和"退行"相容。

所以**刚性（结构时间）是律的性质，不是样本（记录）的事实**。"宇宙有没有宇宙时"在任何一个世界里都不是事实问题，只在律的层面有意义。
这与 p-ZFC 的"完成整体是局部的、律是全局的"一致，也修正了 F3 的读法：F3 说的是"若律是减速型的，则宇宙时是序的事实"，
而"律是不是减速型的"本身不能由有限记录判定——它是物理里靠拟合律（而不是读出记录）得到的结论，这与宇宙学的实际做法相符。
