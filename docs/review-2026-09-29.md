## 2. 现在站得住的东西

**数学事实**（都朴素，但正确，有证明或精确数值）
- 窗口四分类与速率刚性（F1–F5），互窗口之比 = 速率比（F14）；
- 分块系统的连续极限（Doob 鞅收敛，B1），权重序的 Łukasiewicz 结构；
- 有事件视界 ⟺ 汇合失效（F7），共存复形的 Helly/Wegner 性质（F8），1+1 维覆盖无环（F9）；
- 逐个增长的律（CSG）在粗粒化下失去协变与 Bell 因果（F18）。

**有精确观测对应的**：红移消色差（σ 不随分辨率变）；两钟雷达互测的读数之比 = 红移因子；狭义相对论里 Doppler 与时间膨胀的区分。
**定性对应**：形状因子式的逐渐显现；分辨尺度与能标互为倒数。

**方法**：每条结论先数值预检；撤回留痕（W1–W7）；GR/量子只作对照（D13）；不引入固定尺度（D16）；计算密集用 Rust。

## 3. 不牢靠或缺失的

1. **没有动力学。** 所有物理结论都是运动学的："给定一个序，它决定什么。"序从哪里来、哪些序会出现，框架没有说。离物理实在的距离主要在这里。
2. **测试用的序仍来自 GR 几何或撒点。** 结论形如"若序像 X，则 Y"。在规律出来之前，这是不可避免的，但要记住它的地位。
3. **能标统一只完成了概念层**：能标与 σ 是同一类型的量（跨层计数比 vs 跨过程计数比），内容是输入（D17）。没有新的可检验预言。
4. **p-ZFC 用得仍不全**：稳定化层级（Ershov 四分类）、提问的四种情形、"结构 vs 演化"、GLU(π) 的形状参数（非良基、循环对象）都还没进入。
   其中"**演化 = 结构 + 位置的个体化**；关系理论能预言的是个体化不变量"与 F18 直接相关：规律应当约束结构，而不是写成演化。

## 5. 满足 R1–R6 的现成数学：偏序极限与可交换随机偏序

Janson（Combinatorica 2011）建立了偏序极限理论（图极限理论在偏序上的对应）：
- 每个收敛的有限偏序序列都有极限，可表示为有序概率空间上的**核** W(x, y) ∈ [0, 1]（x 先于 y 的概率）；
- 每个核都可以作为生成随机偏序的模型；反之，由核生成的随机偏序收敛到该核；
- 由此得到**全部可交换的随机无穷偏序**：这是偏序版的 de Finetti 定理，也是 Aldous–Hoover 可交换阵列表示定理的特例；
- Hladký–Máthé–Patel–Pikhurko（Trans. AMS 2015）：每个偏序极限都能表示为 [0, 1]（带通常序）上的核。

**逐条对应**

| 我们的要求 / 结果 | 偏序极限理论里的对应 |
|---|---|
| R1 记录可数 | 有限（可数）样本 |
| R2 没有最细层 | 样本可以任意大；没有"最小样本" |
| 分块 = 簇之间的权重 | 核的阶梯函数近似（偏序的正则性引理） |
| B1 鞅极限 | 核本身（极限对象） |
| R4 个体化不变 | **可交换性**：标号的置换不改变分布。这正好解释 F18：逐个增长的律不可交换，所以粗粒化后露出隐藏时钟 |
| p-ZFC"律全局、样本局部" | 核是律（可由可数数据编码），样本是局部的新鲜抽样 |
| R5 只有比值 | 核定义在总测度为 1 的概率空间上：没有尺度；样本大小就是分辨率的层级 |
| 权重、因果非二值（D19） | 核可以取分数值：**极限本身也未必锐利** |
| 全局线性时间只是个体化 | "偏序极限总能全序化"：总存在一个带全序的表示，但表示不唯一——线性时间是表示的选择，不是事实 |

**要说清的代价与问题**
1. **P4 在这里自动满足，因而不再有选择力。** 任何核在任何分辨率下都自洽。它曾经有力地排除了逐个增长的律（F17、F18），但在可交换律内部，它什么也不排除。
2. **无穷体积**：撒点得到的无穷时空（闵氏、FRW）在这个理论里是"稀疏"的（无穷测度），需要类似稀疏图极限（graphex）的推广。
3. **这仍是运动学**：它精确刻画了"律住在什么对象上"（R1–R6），但没有回答"是哪个核"（R8）。动力学问题被**精确化**了，而不是被解决了。

## 6. 结构上还需要什么

核心只剩 R8：**在核（可交换律）的空间里，什么原则选出物理的那些？** 这就是本框架里爱因斯坦方程的位置，也是最容易把 GR 形状带回来的地方。候选方向（都未决定）：

| 候选原则 | 内容 | 顾虑 |
|---|---|---|
| 对称/齐性 | 核的保测序自同构群可迁（"没有优先的地方"） | 闵氏满足（庞加莱群），但可能太弱，也可能预设了太多 |
| 局域（P3 的核版本） | 以隐变量为条件的独立性结构 | Aldous–Hoover 表示里已经部分内建，需要找真正有约束力的版本 |
| 跨层一致之外的"跨世界一致" | 不同语境（世界）的样本在共存处粘合的条件 | 最贴近 p-ZFC，但还不清楚怎么写 |
| 典型性/最大熵 | 在约束下最典型的核 | 因果集的"熵问题"警告：最典型的偏序（Kleitman–Rothschild 三层）完全不像时空 |
| 稳定化 | 沿记录变化有限次的问题有唯一极限（p-ZFC 的 .2）作为对律的要求 | 与 F7 相连：它会偏好无视界的核，可能与加速膨胀冲突 |

## 8. 追问后的修正：宇宙学根本问题与载体（同日）

用户追问："时空是无穷的吗？背景本身存在吗？"以及"我们离引力有多远？"

**8.1 "无穷体积"是 GR 惯性。** 每个世界的记录可数，每个世界都有真扩张（M3）：时空只是**潜无穷**，永远可扩张，
从来不是完成的无穷整体（p-ZFC 的潜在主义）。"时空有限还是无穷"在对象层面不良定；良定的是"扩张是否永不终止"——按 M3 是。
第 5 节"无穷体积需要稀疏推广"的问题因此**撤回**：它是被 GR 舞台带出来的。

**8.2 背景与"块宇宙"。** 核的隐变量空间只是表示，内容只是有限记录模式的频率（纯关系）。
**但一个核是块宇宙**：固定概率空间上的律，抽更多样本只是加密，不是向未来扩张；它把宇宙当作完成整体，违反 M3 与 p-ZFC 的 GLU₀ 立场。
所以第 5 节的载体建议**不能原样采用**：一个核只描述一个世界（一个阶段）；宽度方向的扩张需要一族跨扩张相容的律，
**这族律如何增长就是动力学**。R8 的位置因此从"从静态核里选一个"移到"世界如何扩张的规律"；
宇宙学（整体扩张）与引力（局部扩张）可能是它的两面。新增要求：

> **R9 开放**：没有完成的宇宙；律必须描述一个永远可扩张的记录系统，而不是一个固定的整体。宽度扩张（新记录）与高度扩张（加细）必须区分。

**8.3 宇宙学根本问题**

| 问题 | 在框架里 | 状态 |
|---|---|---|
| 有限还是无穷 | 潜无穷 | 由 M3 给出 |
| 开端 | 高度方向没有最细层（D16）≠ 宽度方向没有最早记录 | 开放 |
| 膨胀 | 共动过程之间窗口相对经过时间的增长（F3 的 W/P），不需要背景 | 有内禀定义 |
| 加速 | 窗口超线性 ⟹ 记录永不全局汇合（F7）；"宇宙作为整体"不是事实对象 | 结构性结论；加速本身未解释 |
| 宇宙学原理 | 律的对称性（没有优先的记录） | R8 的候选 |

猜测（未论证）：若基础结构本来不全局粘合，渐近不汇合（加速）可能是自然的，减速反而意味着最终全局粘合。

**8.4 离引力有多远** 已有的是引力的运动学读数：红移是序的事实并可局部读出（F1、F14），σ 在回路条件下是势，视界（F7、F8），束缚/退行之分。
缺的：(1) 内容（源）的内禀定义；(2) 联系内容与序结构的规律（R8，爱因斯坦方程的位置）；(3) 自由下落（"什么是过程"未解，F12、F13）；
(4) 牛顿极限。我们有一种能**表达**引力可观测量的关系语言，还没有**产生**引力的东西；框架能否推出引力，目前不知道。
可检验的里程碑：提出一条扩张规律后，看它能否在内容集中处自发给出 σ 的 1/r 型梯度——推出来才算，放进去不算。
