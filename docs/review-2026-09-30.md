## 2. p-ZFC 原文里关于测度的几条（重读）

按 `reference/pzfc-preprint.tex` §5（概率层）与 §6（粘合方案）：

1. **测度属于描述，不属于点集。** 事件是描述（Borel 码）；描述的测度在扩张下不变；**每个局部点集在某个扩张里都会变成零测**；不可测是局部的、暂时的。
2. **样本是局部的。** 新样本不在原世界里；独立性就是扩张（第二个样本相对含第一个样本的世界是新的）。
3. **记录是原子。** 一个源有记录，当且仅当两次独立读取在前 n 个答案上一致的概率对 n 一致有下界；**无原子的源（连续随机性）有律而没有记录。**
4. **旧点集的命运是二分的。** w ≼ w′ 时，w 的实数在 w′ 里要么零测，要么外测度满；对"好"记录，每个旧集合的测度要么完全保留，要么完全丢失；
   部分丢失需要局部的选择对象作参数。测度的不确定正好是一个**窗口** μ_* ≤ μ* ，即不可测性。
5. **Kolmogorov 扩张定理是 GLU₀ 的一个实例**（引言里与 ZFC 的外延性、隐变量模型、"机制的下一步状态"并列）。
   在有向的语境上，权重层确实粘合（全局权重唯一）——但粘合出来的是**律**，不是样本。
6. **隐变量 = 粘合。** 全局隐结构存在当且仅当局部律能粘合；de Finetti 与 Bell 是同一个定理的两端；失败度 η 是有限的、与世界无关的。
7. **关系可以是记录，而两端都不是**（同步耦合让"相等"确定，而两边都不是记录）。

## 3. 局域性不是原理，是一个被测量的量

- CSG 的 Bell 因果（转移概率之比只依赖两个过去的并集）是"以共同过去为隐变量的因子化"。按 §2.6，**它就是律层面的全局粘合假设**。
  我们把它写成 P3，是把 GLU₀ 从后门放回来了。
- 我在 law §8 里提出的"给定世界条件独立""粗世界是充分统计量"，同样预设了一个全局的条件概率结构，是同一个问题换了说法。
- gravity §5 的"局域（马尔可夫）+ 中心极限"：马尔可夫随机场本身就是一个全局样本（所有过程上一个 σ 构型）加一个全局律。按 §2.2，样本只能是局部的。
- **p-ZFC 给出的替代**：不假设局部律能粘合，而是**测量粘合失败的程度**（语境分数、η）。能保留为原理的只有更弱的一层：
  **事实在重叠处相容**（记录不受扰动，M4；p-ZFC 的"事实粘合，存在不粘合"）。它相当于各语境的边缘分布相容（不传信的那一半），不相当于因子化。
- 这样，"局域性成立到什么程度"变成一个问题而不是前提；它的答案（η 是否为 0）是律的性质，由比较确定，不由我们规定。
  （这里不引入量子的形状：η 只是"局部律能否粘成一个全局律"的度量，是 p-ZFC 在任何语境族上都有的量。）

## 4. 测度与信息：哪些用法站不住

**4.1 分块的连续极限（B1）** 我们说"权重沿嵌套簇列是有界鞅，几乎必然收敛"，并据此说"连续统是加细的极限"。
按 §2.2、§2.5：Kolmogorov 给出的是各层律的全局相容，**一条贯穿所有层的嵌套簇列是一个样本，一个完成的整体，是局部的。**
所以连续统（一组确定的连续权重）只相对某个完成了的加细路径存在，不是全局事实；全局的只有各有限层的记录和跨层的律。
这不推翻 B1 的数学，但改变它的读法：**光滑连续统是局部的完成物**，这与 p-ZFC 的"R 是局部的"对应得很准。

**4.2 扩张份额与"时间 = 大小的对数"（extension §2）** 计数层的份额是离散的、是记录；我把连续份额归结为"权重无原子"。
按 §2.3，**无原子的源有律而没有记录**——所以连续的份额不是记录事实，而是律层面的量。更进一步，按 §2.4，若把"旧世界在新世界中的份额"看作旧点集在新世界里的测度，
p-ZFC 的二分说它一般要么是 0，要么根本没有值（只有窗口 [μ_*, μ*]），中间值需要局部的选择参数。
**这是类比，不是定理**（物理记录不是实数），但它提示："世界大小之比"可能一般是一个窗口而不是一个数；Cauchy 论证预设了份额是 (0, 1] 里确定的实数。
需要重想：扩张的"量"在计数层是离散的，在律层是什么，是否总有确定的值。

**4.3 充分统计量与隐藏时钟（law §8，b4、b4b）** 计算本身没错：在传递渗流这个固定的带标号模型里，隐藏间隔确实影响粗层关系。
但"充分统计量""条件独立"都是在一个固定世界里的 Kolmogorov 语言，把它提升为原理（P3 的跨分辨率形式）就是 GLU₀。
可以保留的读法：它是 p-ZFC"隐藏参数恰是渐近速率"的一个实例——被删掉的元素构成了隐藏的速率；不应再往"退耦原理"上推。

**4.4 仍然站得住的** F1–F9 是有限偏序上的计数与存在性陈述，是记录层面的；隐藏速率定理本身来自 p-ZFC 的概率层，已经是"律全局、样本局部"的形状。
F14（互窗口之比 = 速率比）对束缚对是记录事实（束缚 ⟹ 速率被序决定）。

## 5. 待讨论的处理（先不动文件）

1. **撤回 gravity §12（源与 γ），降级 §6、§9 为对照**；把"光偏折"改写成内禀的问题：内容是否改变静态过程之间关系的对称部分（extension §6 的 d），还是只改变 σ。这个问题不需要"光"。

3. **gravity §5 的 1/r 推导降级为"条件性草图"**，明确它依赖的三项放进去的东西：全局 σ 样本、马尔可夫局域、三维各向同性。
4. **blocking B1 改读法**：连续统是局部完成物；全局的是有限层记录与跨层律。
5. **extension §2 的连续份额**：标出它是律层面的量，并把"份额可能只有窗口"的问题记为开放。
6. **加一条工作规则**（与 D13 并列）：每个新词先过 §1 的判据，定义不出来就标"输入"或"对照"，不许以"显而易见"跳过。

## 6. 我对"框架里的光"的初步想法（开放，不作结论）

p-ZFC §2.7："关系可以是记录，而两端都不是。"框架里最接近"光"的是**关系本身**（尤其是链接），而不是一个在两个事件之间穿行的对象。
如果这样读，"光"不是过程，不带节拍，也就谈不上"光的能量""光是否产生引力"——这些问题要么消失，要么必须改写成关于关系与过程的计数问题。
它和"无质量粒子没有内部节拍"听起来相似，但来源不同：一个是借来的粒子图像，一个是框架里"只有关系"的直接后果。是否采用，待讨论。
