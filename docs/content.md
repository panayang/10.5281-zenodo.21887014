# 内容的内禀理论（2026-09-30，空处 1）

> 以前"内容"是输入（D17），然后在 dynamics §6 被定义为"使计数亏损依赖方向的东西"。本文件把这个定义推到底：内容是什么、它有什么性质是强制的、什么是偶然的、它在分块下怎样变化。
> 对照族（洛伦兹流形 + 按体积撒点）只用于翻译和核对。

## 1. 定义：内容是计数亏损场的方向依赖部分

- 对一个点附近、轴为 u 的小区间，亏损的领头系数是 u 的二次函数：`c(u) = A_ab u^a u^b + c₀`（对照族里 `A_ab = R_ab/30`，`c₀ = −R/180`）。
  二次性在对照族里由 Gibbons–Solodukhin 的展开给出；在一般的 (S, ≺, μ) 里它是一个假设（领头阶对轴的依赖是二次型）。
- **内容场** = A 的迹零部分加上由可积性连带确定的迹部分（§2）。无内容 ⟺ A 与 u 无关（P5）⟺ A 的迹零部分为零。
- **内容的过程** = A 的主类时方向（使亏损最大的轴）的积分曲线；**内容的量** = 对应的本征值。
  所以"内容沿哪条过程流动"也是由计数读出的：**内容流向记录相对最长链最多出来的那个方向**。
- 这里没有第二种东西：记录都一样，内容是律 (S, ≺, μ) 在一个区域里的一种**模式**。

## 2. 强制的性质

1. **守恒**（在对照族里）：各区间的亏损来自同一个有序测度空间，所以 A 满足可积性（收缩的 Bianchi 恒等式）；按 §1 定义的内容因此自动守恒——
   内容不能凭空出现或消失。D3 里"内容守恒"原是一个前提，按这个定义它变成恒等式。
2. **源不是计数**（D3）：这在定义里已经体现——内容是方向依赖的部分，标量的记录数只贡献各向同性部分，而各向同性部分被 Schur 引理锁成常数（即 Λ）。
3. **Λ 不是内容**：它是 A 中与方向无关、且处处相同的部分。按定义它属于真空。这与"Λ 是一种物质（暗能量流体）"的读法不同：在这里它是律的真空性质。

## 3. 内容的符号决定时间是不是事实（命题 C1）

F3 说宇宙时是序的事实 ⟺ 减速；F19 说观察者之间频率一致 ⟺ 窗口比 → 0，阈值相同。
**核对**（`calc/c4_focusing_rigidity.py`，平直 FRW a ∝ t^p）：沿共动轴，亏损的方向依赖部分 `R_tt/30 = −p(p − 1)/(10t²)`：

| p | R_tt | 膨胀 | 速率 |
|---|---|---|---|
| 1/2、2/3 | > 0 | 减速 | 序的事实（F3） |
| 1 | 0 | 匀速 | 临界 |
| 2；de Sitter | < 0 | 加速 | 隐藏 |

**C1** 在测试族里：**沿共动轴的内容是"聚焦的"（记录相对最长链多出来）⟺ 刚性 ⟺ 共享时钟 ⟺ 共享频率。**
- 这把 extension §7.1 的假说"引力是把隐藏速率变成结构事实的机制"变成了精确陈述：让时间成为事实的，是亏损方向依赖部分的符号。
- 对照：R_uu ≥ 0 是强能量条件，它通过 Raychaudhuri 方程使自由过程聚焦；聚焦使窗口次线性，即刚性。Λ（R_uu < 0 对所有 u）破坏刚性。
- 一般情形（非均匀）要分开两件事（对照族里的测地偏离）：**一对**自由过程是否重新靠拢（刚性）取决于沿它们间隔方向的潮汐分量，包括 Weyl 部分；而一**族**过程的平均聚焦（体积）只取决于 Ricci 部分，即内容。所以 C1 的一般形式是：**内容的聚焦 ⟺ 过程族平均意义上的刚性**；成对的刚性还受远处内容的潮汐（形状）影响——例如行星绕太阳的束缚来自 Weyl 型的潮汐，而不是当地的内容。FRW 里没有 Weyl 部分，两者重合。

## 4. 偶然的性质（由辨认决定）

- **正性**（沿自身轴聚焦）：不被强制。观测上普通物质满足，暗能量（Λ）不满足；在本框架里 Λ 按定义不是内容，所以"内容总是聚焦的"是一个可检验的陈述。
- **耦合 G**：内容量与亏损之比；框架里唯一随内容进入的有量纲量。
- **内容聚成束缚过程**（粒子、天体）：没有解释。框架里的"束缚"是刚性，所以问题是：什么样的内容模式会自我维持为一族窗口有界的过程？这是内容的动力学，尚无。

## 5. 分块下的内容：跑动的位置（锚点 2 的具体化）

- 一个大区间的亏损不是其中小区间亏损的平均：体积展开在 τ⁴ 阶含有曲率的平方项（包括 Weyl 的平方，即潮汐场）。
  所以在较粗的分辨率上读出的"τ² 系数"会包含细层潮汐场的贡献：**粗层的有效内容 = 细层内容 + 细层潮汐场的二次贡献**。
- 这就是内容在分块下的非可加性，也是律不跑动（F21）时唯一可能的跑动。修正的大小只依赖比值（区间尺度 / 内容变化的尺度），与 A5 相容。
- 对照：这对应宇宙学里的"平均化反作用"（Buchert 等：对非均匀宇宙平均后，平均方程出现有效的额外源）。在本框架里它不是修正项，而是"内容"这个概念在不同分辨率下必然不同的原因。
- 未做：τ⁴ 阶系数的计算与一个可解的非均匀例子。

## 6. 这给出了什么

- "内容"不再是输入：它是计数亏损场的方向依赖部分，其流向、量、守恒都由计数读出或由一致性强制。
- C1 把刚性（时间是不是事实）与内容的符号连起来，统一了 F3、F19 与引力的角色。
- 跑动的来源被定位为亏损的非线性（潮汐场的二次贡献）。
- 仍然是空的：内容为何聚成束缚过程（物质的个体性），以及任何量子特征。
