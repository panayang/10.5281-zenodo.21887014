# 内容的内禀理论（2026-09-30，空处 1）

> 以前"内容"是输入（D17），然后在 dynamics §6 被定义为"使计数亏损依赖方向的东西"。本文件把这个定义推到底：内容是什么、它有什么性质是强制的、什么是偶然的、它在分块下怎样变化。
> 对照族（洛伦兹流形 + 按体积撒点）只用于翻译和核对。

## 1. 定义：内容是计数亏损场的方向依赖部分

- 对一个点附近、轴为 u 的小区间，亏损的领头系数是 u 的二次函数：`c(u) = A_ab u^a u^b + c₀`（对照族里 `A_ab = R_ab/30`，`c₀ = −R/180`）。
  二次性在对照族里由 Gibbons–Solodukhin 的展开给出；在一般的 (S, ≺, μ) 里它是一个假设（领头阶对轴的依赖是二次型）。
- **内容场** = A 的迹零部分加上由可积性连带确定的迹部分（§2）。无内容 ⟺ A 与 u 无关（P5）⟺ A 的迹零部分为零。
- **内容的过程** = A 的主类时方向（使亏损最大的轴）的积分曲线；**内容的量** = 对应的本征值。
  所以"内容沿哪条过程流动"也是由计数读出的：**内容流向记录相对最长链最多出来的那个方向**。
- 这里没有第二种东西：记录都一样，内容是律 (S, ≺, μ) 在一个区域里的一种**模式**。

## 2. 强制的性质

1. **守恒**（在对照族里）：各区间的亏损来自同一个有序测度空间，所以 A 满足可积性（收缩的 Bianchi 恒等式）；按 §1 定义的内容因此自动守恒——
   内容不能凭空出现或消失。D3 里"内容守恒"原是一个前提，按这个定义它变成恒等式。
2. **源不是计数**（D3）：这在定义里已经体现——内容是方向依赖的部分，标量的记录数只贡献各向同性部分，而各向同性部分被 Schur 引理锁成常数（即 Λ）。
3. **无压内容沿自由过程运动**（对照族）：守恒 ∇^a T_ab = 0 对无压内容（亏损的主轴族没有横向应力）推出主轴的积分曲线是测地线——即内容的过程是**最长链**，与 gravity §7 把自由下落定义为最长链一致。这是 Einstein–Infeld–Hoffmann 型的结论：内容如何运动由亏损场的可积性决定，不需要另一条运动定律。
4. **Λ 不是内容**：它是 A 中与方向无关、且处处相同的部分。按定义它属于真空。这与"Λ 是一种物质（暗能量流体）"的读法不同：在这里它是律的真空性质。

## 3. 内容的符号决定时间是不是事实（命题 C1）

F3 说宇宙时是序的事实 ⟺ 减速；F19 说观察者之间频率一致 ⟺ 窗口比 → 0，阈值相同。
**核对**（`calc/c4_focusing_rigidity.py`，平直 FRW a ∝ t^p）：沿共动轴，亏损的方向依赖部分 `R_tt/30 = −p(p − 1)/(10t²)`：

| p | R_tt | 膨胀 | 速率 |
|---|---|---|---|
| 1/2、2/3 | > 0 | 减速 | 序的事实（F3） |
| 1 | 0 | 匀速 | 临界 |
| 2；de Sitter | < 0 | 加速 | 隐藏 |

**C1** 在测试族里：**沿共动轴的内容是"聚焦的"（记录相对最长链多出来）⟺ 刚性 ⟺ 共享时钟 ⟺ 共享频率。**
- 这把 extension §7.1 的假说"引力是把隐藏速率变成结构事实的机制"变成了精确陈述：让时间成为事实的，是亏损方向依赖部分的符号。
- 对照：R_uu ≥ 0 是强能量条件，它通过 Raychaudhuri 方程使自由过程聚焦；聚焦使窗口次线性，即刚性。Λ（R_uu < 0 对所有 u）破坏刚性。
- 一般情形（非均匀）要分开两件事（对照族里的测地偏离）：**一对**自由过程是否重新靠拢（刚性）取决于沿它们间隔方向的潮汐分量，包括 Weyl 部分；而一**族**过程的平均聚焦（体积）只取决于 Ricci 部分，即内容。所以 C1 的一般形式是：**内容的聚焦 ⟺ 过程族平均意义上的刚性**；成对的刚性还受远处内容的潮汐（形状）影响——例如行星绕太阳的束缚来自 Weyl 型的潮汐，而不是当地的内容。FRW 里没有 Weyl 部分，两者重合。

## 4. 偶然的性质（由辨认决定）

- **正性**（沿自身轴聚焦）：不被强制。观测上普通物质满足，暗能量（Λ）不满足；在本框架里 Λ 按定义不是内容，所以"内容总是聚焦的"是一个可检验的陈述。
- **耦合 G**：内容量与亏损之比；框架里唯一随内容进入的有量纲量。
- **内容聚成束缚过程**（粒子、天体）：没有解释。框架里的"束缚"是刚性，所以问题是：什么样的内容模式会自我维持为一族窗口有界的过程？
  可积性只给出守恒与（无压时的）自由运动；束缚需要内容内部的横向应力（压强、内部相互作用），而应力的形式在框架里是偶然的——这正是"物质的种类"所在，框架不提供。

## 5. 分块下的内容：跑动的位置（锚点 2 的具体化）

- 一个大区间的亏损不是其中小区间亏损的平均：体积展开在 τ⁴ 阶含有曲率的平方项（包括 Weyl 的平方，即潮汐场）。
  所以在较粗的分辨率上读出的"τ² 系数"会包含细层潮汐场的贡献：**粗层的有效内容 = 细层内容 + 细层潮汐场的二次贡献**。
- 这就是内容在分块下的非可加性，也是律不跑动（F21）时唯一可能的跑动。修正的大小只依赖比值（区间尺度 / 内容变化的尺度），与 A5 相容。
- 对照：这对应宇宙学里的"平均化反作用"（Buchert 等：对非均匀宇宙平均后，平均方程出现有效的额外源）。在本框架里它不是修正项，而是"内容"这个概念在不同分辨率下必然不同的原因。
- **可解例子（`calc/c6_planewave_diamond.py`）**：真空平面引力波（Ricci 为零）里，沿观察者（相对波的快度 η）的小钻石体积精确为
  `V/V₀ − 1 = a⁴ τ⁴ e^{4η} / 1008 + …`（τ² 阶为零，因为无内容；手算核对一致）。三点：
  (i) **为正**：潮汐场让区间相对其最长链多出记录，像正的内容；
  (ii) **随尺度跑动**：在尺度 τ 读出的"τ² 系数"是 `a⁴ τ² e^{4η}/1008`，随 τ² 增长——内容在分块下的非可加性的一个精确实例；
  (iii) **对轴的依赖是四次的**（e^{4η} ∝ γ⁴），而真正的内容对轴的依赖是二次的（aγ² + b，D3）。所以在同一尺度上，**真内容与潮汐场的表观内容可以由计数区分**：看亏损随轴快度是二次还是四次。
- **多波长平均（`calc/c7_planewave_average.py`，数值，常数剖面核对到 10⁻⁵）**：剖面 h(u) = ε cos u 时，

  | U（钻石的 u 跨度） | 0.25 | 1 | 5 | 20 | 80 |
  |---|---|---|---|---|---|
  | (V/V₀ − 1)/(ε²U⁴) | 3.9×10⁻³ | 3.0×10⁻³ | 1.4×10⁻³ | 9×10⁻⁵ | 6×10⁻⁶ |
  | (V/V₀ − 1)/(ε²U²) | 2.4×10⁻⁴ | 3.0×10⁻³ | 3.4×10⁻² | 3.6×10⁻² | 3.8×10⁻² |

  短于一个波长时是局部潮汐（∝ U⁴，对轴四次，系数 1/252 × cos²）；长于许多波长时比值 ∝ U²，即 τ² 系数**不再跑动**、对轴的依赖变成二次（U² ∝ e^{2η}）——
  **平均后的潮汐就是内容**（零尘埃型，对照 Isaacson 的引力波有效能量）。常数已定准（`calc/c7b_planewave_average_constant.py`，相位平均、外推到 ε²U² → 0）：`V/V₀ − 1 → ε²U²/30`（精度约 0.3%），按 τ² 亏损公式即有效零尘埃 Ricci 分量 `R_UU = 2⟨h²⟩`。这给出"粗层内容 = 细层内容 + 细层潮汐的平均"的一个完整例子：跑动发生在跨越波长的那一段尺度上，之后停止。

## 6. 这给出了什么

- "内容"不再是输入：它是计数亏损场的方向依赖部分，其流向、量、守恒都由计数读出或由一致性强制。
- C1 把刚性（时间是不是事实）与内容的符号连起来，统一了 F3、F19 与引力的角色。
- 跑动的来源被定位为亏损的非线性（潮汐场的二次贡献）。
- 仍然是空的：内容为何聚成束缚过程（物质的个体性），以及任何量子特征。


## 3.1 刚性的一般形式：潮汐聚焦是否抵消相对速度（命题 C1′，对照族）

对两条相邻的自由过程，间隔 ξ(τ) 满足测地偏离 `ξ'' = −K(τ) ξ`，K 是沿间隔方向的潮汐分量（对照族里 `K = R(u, ξ̂, u, ξ̂)`）。
窗口约为往返距离，`ρ = W/τ ≈ 2ξ/τ`。所以**这一对的速率是序的事实 ⟺ ξ(τ)/τ → 0 ⟺ 渐近相对速度 ξ'(∞) = 0**。当 K ≥ 0 时 ξ' 单调不增，
`ξ'(∞) = ξ'(0) − ∫₀^∞ K ξ dτ`，于是：

**C1′** 一对自由过程的速率是序的事实 ⟺ 沿其间隔方向的潮汐聚焦恰好抵消其初始相对速度（`∫ K ξ dτ = ξ'(0)`），或它们振荡地保持有界（束缚）。

- 它统一了 F1（束缚：K 足够大，ξ 有界）、F2（平直：K = 0，相对速度 v ≠ 0 ⟹ 隐藏）、F3（FRW：`K = −ä/a`，共动对 `ξ' = ȧ d → 0 ⟺ p < 1`）。
- 内容是 K 在各间隔方向上的和：`Σ_i K(e_i) = R_uu`。所以内容决定**过程族平均**的聚焦，成对的刚性还取决于潮汐的方向（Weyl 部分）。
- F1–F3 的推广因此归结为一个可计算的判据。**具体例子（`calc/c9_schwarzschild_pairs.py`，Schwarzschild 外部的牛顿极限，从 20M 静止下落到 4M）**：
  径向相邻的一对间隔增大到 4.72 倍（散焦潮汐：速率趋于隐藏，如 F2），切向的一对缩小到 0.20 倍（聚焦：趋向刚性），圆轨道上的一对保持有界（束缚，F1）。
  同一团内容按方向给出全部三种情形；过程族平均（各方向 K 之和 = R_uu）在真空里为零——平均由内容决定，成对由潮汐方向决定。

## 4.1 应力与物质的种类（定义部分）

- 相对内容的主轴 w，亏损的二次型 A 在与 w 正交的方向上的分量就是**应力**（对照族里是 `T_ij`）：它由"以相对 w 在不同空间方向上运动的轴"做的区间的计数给出，所以也是可问的。
- **物质的种类 = 应力与内容量之间的关系**（物态方程）。可积性不固定它；它是偶然的。框架能说的是：
  (i) 无压时内容沿最长链运动（§2）；(ii) 一团内容要成为**束缚**的（刚性的，窗口有界）而又不塌缩，需要正的应力抵抗自身的聚焦（对照：流体静力平衡）；
  (iii) 应力若为负到使内容散焦快速过程，则违反 dynamics §8.2 的零正性。
- 所以"物质的个体性"的问题在框架里被表述为：**哪些物态方程允许内容自我维持为窗口有界的过程族。** 这是可以提出、但框架本身不回答的问题。
