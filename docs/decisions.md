2. **F3 的文献查证与定理化**：核对 p-ZFC 相变定理的条件（凹包络）对 `W ∝ t^p` 成立；
   认真查"宇宙时由因果结构决定"的已有工作（宇宙学时间函数、Andersson–Galloway–Howard 的宇宙时间函数、因果集宇宙学）。
   注意：F3 对径向一对观察者在 3+1 维同样成立（径向光线就是 1+1 问题）。
3. **L2b 内禀版本**：已完成（F6），单一撒点已复核（测地线聚合，W3 撤回旧解释）。
4a. **L3 新入口（H-密度，优先于 H-质量）**：共形因子 = 相对因果序的局域事件密度
   （`g = e^{2σ}η` 上密度 ρ 的撒点 = 平直坐标里密度 `ρ e^{Dσ}` 的撒点）；分辨率 = 观察者的采样密度
   （粗粒化 = 稀疏化，Poisson 律在稀疏化下不变）。于是旧版的"度规单位"与"分辨率"是同一种量：事件密度。
   平直律自相似（加密 = 伸缩），σ 的梯度破坏这种等价。这就是因果集的"序 + 数"加一层读法；
   要多出解释力，得让"加密流 = RG"算出东西：阈值（结构开始可分辨的密度）、稳定化、汇合（加密方向是有向的：两个加密有公共加密）。
   这也给 H-高度一个候选：宽度 = 因果未来（新记录），高度 = 加密（同一区域更细的记录）。
4. **L3 入口（旧）**：能量/质量之比 E/m = γ 是观察者链与粒子链的速率比，落在隐藏一侧（F2 已涵盖）。
   但**质量之间的比**不是固有时之比：所有类时链的元素密度都由离散尺度决定，彼此相同。
   **假说 H-质量**：粒子的内部事件是底层链的一条粗粒化子链，质量 = 粗粒化比例（记录底层事件的速率）。
   无质量粒子没有固有时，也就没有内部节拍。若成立，"能标 = 分辨率"就有了具体含义，
   RG 阈值 = 某个粗粒化层级开始可分辨的位置（与 p-ZFC 的稳定化、H-高度接上）。待检验，未算。
5. **开放**：几何本身的动力学。不借 GR 方程冒充推导。
