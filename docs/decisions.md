**D1（2026-09-29）推倒重写。** 旧版只作参考，存档在 `archive/scd-v1` / `scd-v1-final`。
理由：载体（环 + 导子 + 对角度规）只能表达局部代数恒等式；引力链借用 GR 真空方程；

**D2（2026-09-29）主干是"序 + 速率"（方向 A）。** 天球/Milne（方向 B）作为连续极限的对照，
p-ZFC 的语境/记录/粘合（方向 C）作为语言层。理由：单个标度撑不起引力（旧版自己的定理）；
Malament：因果结构决定度规，只差共形因子；p-ZFC：迹之外唯一的隐藏参数是速率。

**D3（2026-09-29）Lean 只用于我们自己的数学核心；物理计算用 Python。** 不追求完全形式化（用户明确）。
p-ZFC 的 Lean 代码在 `reference/lean*`，只形式化了有限部分（迹、交换性、三块夹逼、稳定化等），
需要时引用。根目录 `lakefile.toml` 的库名仍为 `SCD`，开始写 Lean 时再定。

**D4（2026-09-29）p-ZFC 只用过程层和概率层**（迹、速率、语境、上下文律、粘合、稳定化），
不引入力迫多宇宙那一层。宽度/高度两种扩张只作为假说 H-高度保留。

**D5（2026-09-29）不在全局粘合之下思考。** 不预设全局事件集、全局时间、全局 σ 场、全局态；
几何是律，事件是样本；全局对象只在可合并区作为结论出现。理由：用户指出初稿仍在 GLU₀ 之下；逐条检查属实（design.md §2）。

**D6（2026-09-29）与因果集理论的关系：要给出更强的解释力，而不是回避重叠。**
目前的抓手是 F2–F4："什么时候因果序决定一个时间"。文献底线：Brightwell–Luczak（序不变测度）。

**D7（2026-09-29）"隐藏参数 = 快度"降格为两体特例。** 三链测试（F4）表明一般是渐近切片。
design.md 已改为 v0.3。

**D8（2026-09-29）签名。** 提交用智能卡密钥 `A209366D…`，已设为全局默认。

**D9（2026-09-29）H-质量降级。** "质量 = 内部事件率"在因果集场论里已有：Johnston 的 hop-and-stop 传播子里，
质量以每个停留元素的权重 `b = −m²/ρ` 进入，主导链的停留数约为 mτ。我们在 L3 能加的只剩别的角度
（例如质量比作为束缚过程之间的刚性速率比），优先级下调。

**D10（2026-09-29）L0 的具体模型：世界 = 因果过去。** p-ZFC 的记录系统直接实现为因果结构：
世界 = J⁻(p)，扩张 = 因果序，M4 自动成立，共存 = 有共同未来，汇合（.2）= 有向性 = 无事件视界。
F7 是第一个实例。与 p-ZFC 的差别要说清：这个模型里"全局配对"与"合并"是同一个条件
（两个过去的共同扩张就是两个事件的共同未来），p-ZFC 的三层只实现了两层；刚性是另一根轴。
宽度/高度两种扩张在这里只有一种（因果序），H-高度仍然开放。

**D11（2026-09-29）计算密集的任务用 Rust。** 用户要求。`calc/rs/` 是无外部依赖的 crate（自带 SplitMix64），
输出写入 `calc/out/`。F9 的覆盖检验用 Rust 5 秒完成 3 万个，同类 Python 计算要几分钟。

**D12（2026-09-29）H-密度暂缓，先做视界覆盖与上下文性（F9）。** 理由：H-密度与因果集"序 + 数"重叠大、短期看不出增益；
F9 直接用到 p-ZFC 的上下文律定理，并且与 F7/F8 连成一条线（视界 → 汇合失效 → 共存神经 → 上下文性的空间）。

**D13（2026-09-29）写法：不以 GR/量子为规律形状。** 用户指出 F1–F9 已偏离（都在给定 GR 度规里算、F9 借用上下文性）。
此后定理一律用序、链、窗口、记录内禀陈述，GR 几何只作对照例子；短版预印本 `docs/preprint-short.md` 按此改写。

**D14（2026-09-29）B 的出发点：高度 = 民主粗粒化。** 每个事件独立地以概率 q 保留；不需要几何。
结果：σ 不跑动，内容跑动（F10，给出内禀版的"能标 × 尺度 ≈ 1"）；最长链过程的可区分性阈值 `ρ ≳ T⁴/d⁶`（F11）。

**D15（2026-09-29）现实检验优先。** 用户要求注意与物理实在的对应。F12 表明"过程 = 最长链"与观测冲突（ξ₄ ≈ 0.6 时每秒纳米级随机偏离），
所以 B 的下一个问题改为"什么是一个过程"：由过去决定的局域规则、持续存在的模式，而不是两端之间的极大。

**D16（2026-09-29）不引入固定离散尺度；离散而无尺度。** 用户指出：按固定密度 ρ 往给定流形撒点（D5 的"几何是律"、R5 的普朗克认定）
等于引入绝对单位和背景，抛弃关系主义，并会重蹈 LQG/因果集"强行量子化"路线的老问题。属实。修正：
- 框架只有计数比，没有量纲性的量；旧版 A5（只有比值）与"没有最小长度"恢复为约束；
- "离散"只表示每一层的记录可数；加密**没有最细一层**（p-ZFC 的 M3，旧 A6 的"开放"）；连续统是加密的极限，在 p-ZFC 意义上是局部的；
- **能标 = 两层之间计数比的对数**，与 σ（两个过程之间计数比的对数）同类型；
- 撒点只作生成测试用序的手段；F6、F11、F12、F13 标为条件性（以存在最细层为条件），H-密度删除，W4–W6 撤回；
- D5 的其余部分（不预设全局事件集、全局时间、全局 σ、全局态）保留。

**D17（2026-09-29）不采纳"层移不变性"，不预设阈值分布。** 它本质上是旧版 A5 加 CV² = 1 换了说法：证据弱（11 个手选间隔）、
现实世界并非尺度不变、质量阈值很可能是偶然输入（像 Yukawa 耦合）。框架应解释结构性事实，阈值位置当作输入；
若将来使用尺度不变假设，只能作为几个可检验候选之一，并写出零假设。

**D18（2026-09-29）分辨率 = 嵌入 + 影子，以分块为主。** 此前把加密当作嵌入（粗层是细层的子集，相当于 RG 的抽取），
这是未经检验的选择。物理上的分辨率更像分块：分辨率为 δ 的记录把 δ 以内的事件合成一个。p-ZFC 的粘合框架里，加密是一对嵌入与影子，
且加密迫使值代数变为非负实数，即粗层关系是权重。改为：粗事件 = 细事件的簇，粗层关系 = 权重（相关成员对的比例）。
嵌入版的结论要逐条复核（见 `docs/blocking.md`）。

**D19（2026-09-29）绝对因果：因果事实只在共存记录之间成立。** 框架此前预设了一个全局偏序（绝对因果），而 p-ZFC 的目标 R6 明确要替换它。
改为：世界是原始的（记录及其序），扩张加入记录；由 M4，两个事件只要共存于某个世界，它们的关系就是事实并在所有包含两者的世界里相同；
不共存的事件之间没有因果事实。绝对因果的有效范围 = 共存复形（F7、F8）；全局序只在可合并时作为粘合结果出现。
**开放选项（用户保留意见）**：共存记录之间的因果序也可能依语境而变、不能全局粘合（"不定因果序"）。
这需要放宽 M4 对序事实的要求；它不一定要借量子理论的形状，p-ZFC 的"局部一致、全局不粘合"本身就允许这种结构。待单独审视，不作否定。

**D20（2026-09-29）规律的出发原则 P1–P4，先检验传递渗流是否满足 P4。** P1 记录持久（M4）；P2 个体化不变；P3 局域不传信；P4 没有最细层（D16，"无穷可分"）。
P1–P3 在因果集理论里已推出 CSG 族（Rideout–Sorkin）；P4 是本框架特有的。第一步：传递渗流在粗粒化下是否封闭、参数如何流动。

**D21（2026-09-29 夜）动力学的位置 = 扩张律（用户同意的方向）。** 单个核是块宇宙，违反 R9；动力学放在"世界如何扩张"。
晚间探索记录在 `docs/extension.md`（未经用户审阅）：扩张量只能是份额的对数（Cauchy），自相似 + M4 在 FRW 测试族里挑出匀速膨胀（无内容基线），
刚性是律的性质而非记录的事实，静态网络 = 光学度规 + 势，引力耦合必然是唯一的有量纲量。
引力方向记录在 `docs/gravity-directions.md`（未经审阅）：A5 禁止质量项 + 局域 + 中心极限 ⟹ 势调和（三维 1/r）；自由下落 = 节拍最多的链（数值与测地线一致）；缺口是 γ = 1（内容必须改变序本身，只改速率不够）。放宽"世界对过去封闭"的枚举记录在 `docs/law.md` §7。
