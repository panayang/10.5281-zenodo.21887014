# 动力学：原则强制了什么，剩下什么是律（2026-09-30）

> 按 `docs/design.md` §0 的任务表述：先问 P1、P2、P4（P3 已移出，D22）**强制**了律的什么形式，再问剩下的**偶然**部分是什么。
> 不以推出 GR 为目标；已知物理只作对照。用到的数学定理都是已知的，新的是它们在这里扮演的角色。

## 1. 起点：F17/F18 的困境其实是两个方向的错配

- 序贯增长律（CSG，包括传递渗流）是**宽度方向**的律：新记录只加在已有记录之上，P1（记录的过去不被改变）自动成立。
  但它在**高度方向**（加细/粗粒化）不相容：稀疏化后协变与关系统计都不保持（F17、F18），隐藏间隔的影响随尺度分离变大（b4、b4b）。
  文献旁证：Brightwell–Georgiou（2010）证明 CSG 的连续极限总是半序，不能近似 ≥ 2 维的闵氏空间。
- 可交换的随机偏序（Janson 2011 的"偏序极限"）是**高度方向**的律：对均匀子抽样自动相容，个体化不变（P2）内建。
  但它不是增长律：多抽的点会落进旧记录的过去。
- 以前（review-2026-09-29 R9）把后者当作"块宇宙"排除。**重读后这个排除不对**：多抽样本落进旧记录的过去，正是**加细**（高度扩张）——
  同一区域里记录更细的记录，而不是给旧记录添加新的原因。P1 约束的是宽度扩张，不约束加细。

所以一个完整的律要同时有两个方向，并且两者相容。

## 2. 强制的部分：律 = 有序测度空间上的广义撒点（命题 D1，条件性）

**设定** 每个分辨率上，世界是有限的记录偏序（下集）；
- **P2**：律对个体化不变（可交换）；由对称性，粗粒化时每个记录被保留的权重相同（p-ZFC：权重由对称性强制，"随机袜子"）；
- **P4（高度）**：没有最细层——每一层都是某个更细层的粗粒化；
- **P1（宽度）**：宽度扩张只在世界之上添加记录；
- **汇合**：一个汇合分支内的各世界有共同扩张（F7：无视界）。

**命题 D1** 在一个汇合分支内：
1. （**稀疏化读法**）若粗粒化是独立稀疏化，则"每一层都是任意 p 的稀疏化"推出记录过程是 **Cox 过程**（以随机强度测度为条件的 Poisson 过程）——Mecke（实轴上的原始定理；一般状态空间上的推广见 Kallenberg，具体条件待核对）。
2. （**关系**）加上可交换，关系由一个核给出：存在（随机的）有序测度空间 (S, μ, W)，记录是按 μ 的 Poisson 样本，两记录的关系由 W 决定——
   有限情形是 Janson 的表示定理（偏序极限 = 有序概率空间上的核）；σ-有限情形（开放的宇宙，μ(S) = ∞）是它与第 1 条的合并，**未证明**。
3. （**分块读法**）若粗粒化是分块（D18），粗层权重就是核在格子上的平均 `w(X, Y) = ∬_{X×Y} W dμ dμ / μ(X)μ(Y)`；
   B1 的鞅收敛就是它回到 W 的微分定理。**分块与稀疏化在这个表示里是同一个对象的两种粗粒化**，两者都封闭。
4. （**宽度**）宽度扩张 = 把 S 里的下集 D 扩大到 D′ ⊃ D。D 是下集，所以 D′ \ D 中没有点在 D 的点之下：P1 自动成立。
   开放性（M3：每个世界都有真扩张）⟺ S 没有极大区域；世界的大小有限、S 的总测度无限。

**读法**
- **撒点被强制了，而且没有带回尺度**：Cox 过程的强度是随机的、只以比值出现，没有固定密度（与 D16 相容）。
  W5 撤回的是"给定流形 + 固定密度"；这里 (S, μ, W) 不是外加的舞台，而是**律自身的 de Finetti 型表示**——p-ZFC："隐藏的全局结构存在 ⟺ 局部律能粘合"。
- **它只在汇合分支内存在**：跨视界时局部律不粘合，就没有一个全局的 (S, μ, W)——与锚点 1 的 C4（跨视界的全体比例没有事实）是同一件事。
- **表示里总可以选出一个隐藏的线性序**（Hladký–Máthé–Patel–Pikhurko 2013：每个偏序极限都能表示为 [0, 1] 标准序上的核）。
  它是表示的选择，不唯一——正是 p-ZFC 的"一个时间 = 选一个线性延拓"。
- **与因果集的差别**：因果集用洛伦兹不变性（Bombelli–Henson–Sorkin）或"数目–体积"方差最优来论证 Poisson 撒点，并**给定**流形；
  这里 Poisson 性质来自"没有最细层"，而空间 (S, μ, W) 是律的参数，不是给定的。

**p-ZFC 检查**（按 `docs/review-2026-09-30.md` §2）：(S, μ, W) 属于律（全局，可由可数数据编码：标准 Borel 空间上的 Borel 测度与核）；
一组具体的样本点是样本（局部）；连续统（一条完成的加细路径）是局部的完成物。用到的"粘合"只有两处：加细方向是有向的（D16），在有向语境上权重粘合（p-ZFC 权重层 = Kolmogorov）；
宽度方向只在汇合分支内粘合。

### 2.1 D1 的严格化（2026-09-30，证明草稿）

**(a) 加细的方向是"子集"，所以粗粒化是稀疏化。** 按 M4，粗层的记录在细层里仍是记录（后来的记录不扰动先前的记录）；
所以细世界 = 粗世界 + 新插入的记录，粗层的记录集是细层记录集的子集。按 P2，这个子集不偏爱任何记录：给定大小时是均匀的子集。
由此，高度方向的粗粒化在记录层面就是（均匀的）稀疏化；D18 的分块是另一件事——它是**描述**一个细世界时对记录的分组（观察者分不清簇内的记录），
不是另一个世界。两者在表示里交换：先稀疏化再分块与先分块再稀疏化给出同样的期望权重。先前"稀疏化与分块哪个是分辨率"的分歧由此消解：
**稀疏化是世界之间的关系（哪些记录存在），分块是一个世界内的描述（哪些记录可分辨）。**

**(b) 一般空间上的 Mecke 定理（拉普拉斯泛函证明草稿）。** 设记录过程 ξ 是局部有限的点过程（在一个局部化的 Polish 空间上），
且对每个 p ∈ (0, 1) 有 ξ_p 使 ξ 与 ξ_p 的 p-稀疏化同分布。则
`E e^{−ξf} = E exp(−ξ_p g_p)`，`g_p = −log(1 − p(1 − e^{−f}))`。令 `η_p = p ξ_p`，则 `ξ_p g_p = η_p (g_p / p)`，且 `g_p / p → 1 − e^{−f}` 一致收敛。
η_p 在有界集上是紧的：给定 ξ_p(B)，ξ(B) 是二项分布 Bin(ξ_p(B), p)，η_p(B) 大时 ξ(B) 以高概率也大，所以 ξ(B) 的紧性推出 η_p(B) 的紧性。
取子列的淡极限 Λ，得 `E e^{−ξf} = E exp(−Λ(1 − e^{−f}))`，即 ξ 是以 Λ 为强度的 Cox 过程。反方向显然。∎
（原始定理在实轴上；以上论证只用到淡拓扑下的紧性判据，局部化 Polish 空间上成立。文献上的一般形式待核对，但不再是这里的依赖。）

**(c) 关系：σ-有限情形。**（2026-09-30 补：限制映射的相容性来自 P1——D 的记录与关系在 D′ 里是同样的事实，D 在 D′ 中由其生成记录的过去确定，而记录是全局的；所以 D′ 的表示在下集 D 上的限制与 D 的表示同律。剩下的技术点是各世界表示空间之间的标准 Borel 识别。） 在一个世界 D（有限记录，任意分辨率）上，记录的关系矩阵在重新标号下不变（P2），且可以无限加细（P4）——
所以它是**可无限扩展的**可交换随机偏序；由 Janson（偏序极限）与 de Finetti–Aldous–Hoover 的扩展性论证，它是核随机偏序的混合：D 上有（随机的）(S_D, μ_D, W_D)。
宽度方向上 D ⊂ D′ 时，D′ 的表示限制到 D 上给出 D 的表示（下集的限制），各世界构成有向系统（汇合分支内），
按 p-ZFC 在有向语境上权重粘合（Kolmogorov），这些表示的律粘合为一个σ-有限的随机 (S, μ, W)。∎（草稿；"随机核的律在限制下相容"是需要逐条写出的一步。）

**(d) 仍是条件性的地方**：(i) 可交换性要求标号不携带信息——宽度扩张的先后次序是不是一种标号？若把宽度扩张的次序当作标号，CSG 就是例子，P2 不成立；
D1 的读法是：**先后次序只以序本身出现**（新记录不在旧记录之下），不另外携带信息。这就是 P2 在宽度方向的精确含义。(ii) 汇合分支之外没有全局表示。

## 3. 偶然的部分：(S, ≺, μ) 就是律

锐利的连续极限（B1：极限权重几乎处处为 0 或 1）⟹ W 是某个可测偏序 ≺ 的指示函数。于是**律 = 一个有序测度空间 (S, ≺, μ)（或它们的混合）**。
原则不再限制它；限制只能来自进一步的、要明说的条件：

| 条件 | 对 (S, ≺, μ) 的限制 | 来源 |
|---|---|---|
| 无优先尺度（A5；extension E1） | 存在保序映射 φ 使 φ*μ = c μ（自相似） | 已有 |
| 无视界 | ≺ 有向（任意两点有公共上界） | F7 |
| 开放 | 无极大区域，μ(S) = ∞，下集的"世界"测度有限 | M3 |
| 平移齐性（假设） | S = ℝⁿ，≺ 平移不变 ⟹ ≺ 由一个闭凸锥 C 给出：x ≺ y ⟺ y − x ∈ C | 标准 |
| 各向同性（假设） | C 是圆锥 ⟹ **洛伦兹因果序**；n 不受限制 | 标准 |

- **1+1 维里任何锥都是"洛伦兹的"**（两条零方向）；≥ 3 维时，圆锥（洛伦兹）与多面体锥（如正卦限，乘积序）是不同的律。
  F2 的隐藏快度（束缚之外速率是隐藏参数）只要求有一族连续的保序映射改变速率；正卦限锥的对角伸缩也有，所以 **F2 不强制各向同性**。
- 维数 n、各向同性都不被强制：在这个框架里它们是**偶然的**（输入），除非找到新的强制理由。这是一个诚实的否定结果。
- 一个可能的线索（未做）：序维数。1+1 闵氏因果序的序维数是 2；≥ 3 维圆锥的因果序与"圆包含序"有关，后者已知序维数无界（待核对确切结论），而正卦限乘积序的序维数是 n。
  "忠实表示所需的标量个数"（p-ZFC 的序维数命题）是否能在两类锥之间做出内禀的区分，值得查。

## 4. 这给出了什么（实用性检验）

- **约束（对因果集动力学方向可用）**：任何同时满足个体化不变、没有最细层、并以独立稀疏化为粗粒化的律，必须是 Cox 型的广义撒点；
  所以序贯增长律不可能是基本律（与 F17/F18 和 Brightwell–Georgiou 一致，但这里给出了原因：它们只有宽度方向）。
- **问题的重述**：动力学问题 = 选择 (S, ≺, μ)（以及内容如何改变它）。这把"找动力学"从"找增长规则"变成"找有序测度空间上的原则"，
  而后者的候选限制（自相似、有向、齐性、各向同性）都是可以逐条检验的陈述。
- **远期锚点 2 的位置**：一旦 (S, ≺, μ) 是 n 维锥序，许多无量纲数就被强制（例如区间里相关对的比例是 n 的已知函数，最长链 ∝ N^{1/n}）；
  它们只依赖 n 和锥。真正非平凡的普适指数只能来自**内容**对 (≺, μ) 的形变——这正是引力该出现的位置（gravity §6 的内禀改写：内容改变 ≺ 的对称部分还是只改变 μ）。

2. 稀疏化与分块：已消解（§2.1(a)：稀疏化是世界之间的关系，分块是世界内的描述）。
3. **内容**：在 (S, ≺, μ) 的语言里，内容是什么？候选：μ 的非均匀（改变计数）与 ≺ 的形变（改变关系本身）。gravity §6 的内禀问题在这里有了精确的形式：
   内容是否可以只改变 μ 而不改变 ≺？若只改 μ，速率（σ）会变而关系的对称部分不变。
4. 序维数线索（§3）。
5. 文献：因果集里"Poisson 撒点由粗粒化一致性推出"是否已有人说过，需再查（目前未找到）。

## 6. 内容：只改 μ 不够，必须改 ≺（命题 D2，条件性）

**内禀的量** 对一个小区间 I（由两端点决定），有两个计数：区间里的记录数 N(I)，和两端点之间最长链的长度 L(I)。
在无内容的自相似基线（锥序）里，两者满足一个固定关系 `N = V₀(L)`（期望意义，律层面）。定义**计数亏损** `δ(I) = N(I)/V₀(L(I)) − 1`，
它只用记录和链，不用度规、不用光。区间的**轴**就是这条最长链（一个自由过程）。

**对照翻译**（洛伦兹流形 + 按体积撒点，只作对照；最长链 → 固有时是 Brightwell–Gregory 的结果）：小钻石体积
`V = V₀ [1 − τ² (R/180 − R_uu/30) + …]`（`calc/c1_diamond_volume.py` 用 de Sitter 与爱因斯坦静态宇宙定出系数，与 Gibbons–Solodukhin 一致）。
所以 δ 的领头项 = `−τ² (R/180 − R_uu/30)`，u 是轴的方向。

**候选原则 P5（无内容处不区分自由方向）** 在没有内容的地方，小区间计数亏损的领头系数不依赖区间的轴。
- 动机：F2——非束缚的自由过程之间的速率不是序的事实（没有由序决定的优先标架）；P5 把它提升到律的层面：空的地方，律不偏爱任何自由方向。
  **这一步是加上去的**（"序里隐藏"不蕴含"律对称"），不是 P1、P2、P4 推出来的。
- 等价的读法：**内容 = 使计数亏损依赖方向的东西**。这给了"内容"一个内禀定义（以前 D17 只是输入）；物理上的断言是它与物质过程的记录重合。

**命题 D2**（在对照族里）
1. P5 ⟺ 无内容处 `R_ab = Λ g_ab`（爱因斯坦空间）。证明：领头系数与 u 无关 ⟺ `R_uu` 在单位类时向量上为常数 ⟺ 无迹部分为零。
   **Λ 是允许的**：它就是各向同性的亏损（`δ = −Λτ²/18`），是真空里唯一的自由常数——框架不强制 Λ = 0。
2. **只改 μ（保持 ≺ 为平直锥序，即共形平直）不可能在内容外产生场**：共形平直 + 爱因斯坦空间 ⟹ 常曲率（de Sitter/反 de Sitter/平直），没有围绕源的场。
   所以**内容必须改变 ≺ 本身**——这回答了 gravity §6 的内禀问题，而且没有用到"光"。
3. 静态球对称的内容外，爱因斯坦空间就是 Schwarzschild–de Sitter（Birkhoff 定理的推广），弱场里 γ = β = 1。
   直接核对（`calc/c2_deficit_isotropy.py`，一阶弱场，r = 3 处）：

   | 度规（对照） | 静止轴 | 径向 v = ½ | 切向 v = ½ |
   |---|---|---|---|
   | 只改 μ（γ = −1，Nordström 型） | 0 | +2M/1215 | −M/1215 |
   | 一般 γ | 0 | M(1 − γ)/1215 | M(γ − 1)/2430 |
   | 线性化 Schwarzschild（γ = 1） | 0 | 0 | 0 |

   亏损与方向无关 ⟺ γ = 1。**Nordström 型被 P5 排除，理由是它在源外用计数就能区分方向（潮汐各向异性直接出现在记录数里）。**
4. d 维时，同样的推理给出 Tangherlini 外部解，γ = 1/(d − 3)：γ = 1 是 3+1 维特有的（与撤回前 g4 表里的数一致，但现在来源是计数，不是场论形状）。

**这给出了什么** 一个只用记录数与最长链陈述的原则，在对照族里等价于"真空爱因斯坦方程（含 Λ）"，并由此得到 γ = 1、排除 Nordström 型、允许 Λ。
它把"内容"从输入变成了可读的量（亏损的方向依赖部分）。**仍然缺的**：内容如何决定亏损的大小（耦合 G 与源的形式）——即内部的律；
以及 P5 本身的理由（为什么律在空处不偏爱方向）。

**限制**
- 只在领头阶（τ²）成立；更高阶里 Weyl 曲率会让 Schwarzschild 的亏损也依赖方向，所以 P5 必须限定为领头系数。
- 对照族假设了洛伦兹流形（§3 的各向同性锥）；在一般的 (S, ≺, μ) 里 P5 是内禀陈述，但"⟺ 爱因斯坦空间"只在对照族里成立。
- 用到连续极限（最长链 → 固有时、计数 → 体积），这是律层面的期望陈述，样本上有涨落。
- 文献：Gibbons–Solodukhin 提议用钻石体积测 Ricci；Jacobson（2016）从纠缠平衡在固定体积下推出爱因斯坦方程（前提是量子场与极大对称的局域真空）。
  "只用计数的方向无关性 ⟺ 真空爱因斯坦方程"作为原则，未找到先例；数学本身是初等的。

## 7. 内容内部：源不能是记录数（命题 D3，条件性）

**D3** 在对照族里，设无内容处满足 P5，内容处的亏损由内容的记录决定。
1. **源不能是内容记录的个数。** 内容记录的数目是每单位"体积"的记录数，是洛伦兹不变的标量；它对所有轴一样，只能产生**各向同性**的亏损 `R_ab = f g_ab`。
   但由收缩的 Bianchi 恒等式（Schur 引理），d ≥ 3 时 f 必须是**同一个常数**——一个随处变化的记录数根本不能作源。
   （这恢复了撤回前 g4 的结论"源不能是事件计数"，但现在只用计数与一致性，不用光、辐射、能量。）
2. **源必须依赖内容过程的方向**：一个轴为 u 的区间里，内容过程 w 的贡献依赖相对快度 `γ = −u·w`（可由计数读出：w 在自己同尺寸区间里的记录数与在 I 里的记录数之比）。
   亏损对 u 是二次的，所以贡献的一般形式是 `aγ² + b`——"两指标"的源是亏损的结构强制的，不是借来的。
   对照（`calc/c3_dust_deficit.py`，尘埃）：亏损领头系数 `= 4πGρ(3γ² − 2)/45`；静止轴为正：**有内容的区间比其最长链所对应的基线多出记录**。
3. **a : b 由"内容守恒 + 各区间的亏损来自同一个有序测度空间"（可积性 = 收缩 Bianchi 恒等式）固定**——这是爱因斯坦 1915 年用守恒定迹项的同一个论证，这里只是换成计数的语言。
   **耦合 κ（即 G）不被固定**：它是框架里内容带进来的有量纲量（与 extension §7.2 一致）；Λ 是另一个（真空的各向同性亏损）。

**诚实的定位** §6–§7 在对照族里重建了爱因斯坦方程的结构（真空 = 爱因斯坦空间；源为守恒的两指标量；γ = β = 1；Λ 允许）。
新的是**语言与地位**：每一步都用"记录数 vs 最长链"陈述，"内容"有了内禀定义；原则 P5 是唯一加上去的东西，G、Λ 是偶然的。
按任务表述，这是"强制/偶然"的分类结果，不是"推出 GR"：GR 的形状在这里是 P5 + 守恒 + 可积性在对照族里的推论，每一项都可以单独质疑。

## 8. P5 的理由（开放）

- 动机 1（已写）：F2 把"没有优先标架"提升到律层面。缺口："序里隐藏"不蕴含"律对称"。
- 动机 2（候选读法）：在对照族里 P5 ⟺ Ricci 是局域的，远处内容只产生**保体积**的形变（Weyl 在领头阶不改变体积）。
  用记录的话说：**远处的内容不改变一个空区间里相对其最长链的记录数，只改变它们的排列**——"记录数不被远处改变"。这与 M4（记录不被后来的记录扰动）是同一类陈述，
  但不是同一条：M4 说已有记录的事实不变，这里说空区间的计数关系不被远处内容改变。能否由 M4 推出，未知。
- 注意：这是一种**局域性**断言，但与已移出原则的 P3（Bell 因子化，即律层面的粘合）不同——它不涉及条件独立或隐变量，只涉及计数的依赖范围，可以单独检验。


### 8.1 P5 推不出来：独立性（命题 D4）

**D4** P5 独立于 P1、P2、P4、M4、汇合、A5（无优先尺度的基线）以及"自由过程 = 最长链"。
**证明（给出一个模型）** 取平直锥序 ≺（闵氏因果序），强度 `f·μ`（μ 为体积，f 为正函数、在一团内容外满足 f 的对数调和），按 Cox 撒点。
- P1：宽度扩张 = 扩大下集，自动成立；P2、P4：Cox 型撒点对个体化不变，对稀疏化与分块封闭（D1）；M4：记录一旦出现其事实不变；
- 汇合：锥序有向；A5：无内容时 f 为常数，基线自相似；自由过程 = 最长链：在共形因子梯度中最长链弯向钟慢处（gravity §7 的 g3 正是这样算的）。
- 但内容外亏损依赖方向（`calc/c2_deficit_isotropy.py` 第 (i) 行）：P5 不成立。∎
这个模型就是 Nordström 型的律。它是一个**内部一致**的律——没有任何一致性要求能排除它。

**所以 P5 的地位是"偶然"**（按 §0 的分类）：它是律的一个性质，由辨认决定，不由原则强制。
- 它是**可问的**：亏损的方向依赖是记录计数的期望比，可由有限读数以任意精度确定（p-ZFC：可测的描述都是可问的）。所以"P5 是否成立"有确定答案。
- 对照（只作辨认的证据）：γ = 1 在太阳系里被测到 2×10⁻⁵ 的精度；在本框架里这等价于 P5 在太阳附近成立到同样的精度。
- 这回答了"为什么 γ = 1"在框架里的形式：**不是被推出，而是被归结为一个可以直接用计数检验的陈述**：远处的内容只改变空区间里记录的排列，不改变它们相对最长链的数目（领头阶）。

**找过但不成立的理由**（记录，免得重复）
- 由 F2（隐藏快度）：F2 只说非束缚过程之间的**渐近**速率不是序的事实；局部相交的自由过程之间的快度可由计数读出，不隐藏。所以 F2 不能迫使空处的律不区分方向。
- 由 p-ZFC"律必须个体化不变"：轴的选择确是一种个体化，但亏损可以依赖"轴与远处内容的关系"，而这种关系是事实（不是选择）。Nordström 型正是这样。
- 由 M4：M4 管的是已有记录的事实，不管律如何在空处分配期望计数；而且静态源的历史在区间的过去里，M4 不排除它的影响。
- 由一致性（可积性）：Nordström 型内部一致。

## 9. 远期锚点 2 的重新定位：律本身不跑动

按 D1，律是 (S, ≺, μ) 上的 Cox 型撒点。**粗粒化作用在律上是平凡的**：稀疏化把强度乘以 p（A5：强度的绝对值不可观测），分块只是透过一个划分看同一个核。
所以**每一个律都已经是粗粒化的不动点**——P4 被表示吸收了。后果：
1. 律层面**没有跑动**，也就没有"从不动点流出来的普适指数"。原先设想的锚点 2（粗粒化不动点的普适指数）在这个表示里是空的。
2. 样本层面的指数（例如 1+1 维最长链长度的涨落 ∝ L^{1/3}，Tracy–Widom；F16 的模糊份额指数 1）是**相对分辨率**的：没有最细层（D16）时，
   加细使相对涨落趋于 0。它们不是某个分辨率无关的物理事实，只在给定观察者的分辨率时才有意义；而那个分辨率是偶然的、未知的。
3. **物理上的无量纲数因此只能是偶然的**：维数 d、以及由耦合组成的无量纲组合（例如 Λ 与内容耦合 G 的组合）。框架不产生它们。
4. **跑动若存在，只能在内容一侧**：内容分块后，一团内容作为源的贡献是否等于各部分之和（D3 的源依赖过程方向；束缚系统的内部运动会改变 γ² 加权）。
   也就是说，"耦合的跑动"= 内容在分块下的非可加性。这是锚点 2 的新位置，需要先有内容在分块下的定义。

**实用性检验** 这一节主要是否定结果：它告诉我们不要在律本身里找普适数，而要在内容的分块行为里找。


### 8.2 P5 的重述：一旦内容由计数定义，P5 变成"内容从不使近零速的自由过程散焦"（`calc/c5_null_positivity.py`）

`docs/content.md` 把内容定义为亏损的方向依赖部分。于是"空处亏损与方向无关"按定义成立——P5 本身变成同义反复。
实质内容转移到另一个问题：**在一团内容之外，按计数定义的内容是不是真的为零？** 在 Nordström 型的律里不是：源外有一个方向依赖的亏损场（∝ M/r³），
按定义那就是"内容"，只是它有一个奇怪的性质——

| 源外（一阶，r = 3） | 径向近零轴 R_kk | 切向近零轴 R_kk |
|---|---|---|
| 一般 γ | −2M(γ − 1)/27 | M(γ − 1)/27 |

**γ ≠ 1 时，源外按计数定义的内容总会使某个方向上近零速的自由过程散焦**（两者异号）；γ = 1 时两者都为零。
所以在这个单参数对照族里：

**P5 ⟺ "按计数定义的内容从不使近零速的自由过程散焦"**（零能量条件的计数形式）。

- 这是一个**符号条件**，比"空处各向同性"更有物理内容：它说内容只会让快速的自由过程靠拢，不会把它们推开。
  按 C1（内容的聚焦 ⟺ 刚性），它就是"内容只制造刚性，不破坏刚性"——与 extension §7.1"引力是把隐藏速率变成结构事实的机制"是同一件事。
- Λ 与之相容：爱因斯坦空间的 R_kk = 0，真空的各向同性亏损不使零速过程聚焦也不使其散焦（Λ 破坏的是有质量过程的刚性，见 C1）。
- **地位不变**：它仍是加上去的（偶然的），D4 的 Nordström 型模型仍满足全部原则；但现在排除 Nordström 型的理由可以说成"它需要到处负聚焦的内容"，而不是"它区分方向"。
- 限制：只在单参数族（静态、一阶、球对称）里核对；一般情形下"零正性 ⟹ 源外无内容"需要证明或反例。
