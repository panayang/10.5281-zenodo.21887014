# 量子问题在框架里的位置（2026-09-30）

> 不以量子理论为形状（D13）；量子现象只作对照：现实里观测到 Bell 违背（到 Tsirelson 界 2√2 为止，不到 PR 盒的 4）、Kochen–Specker 型上下文性、干涉、离散的读数。
> 本文件回答：框架的原则允许什么样的关联，量子的限制从哪里来，以及先前 F24、F25 的读法需要怎样修正。

## 1. 三个位置，要分开（修正 F24 的读法）

| 位置 | 问的是什么 | 框架现状 |
|---|---|---|
| A. 同一世界的不同描述 | 一个世界的记录按不同分块/问题读出 | D1：所有描述是同一个 (S, ≺, μ) 的边缘，η = 0（F24 Q1）；η > 0 需要加细不有向 |
| B. 不同的扩张（"设置"选择哪些记录被产生） | 过去的记录选择了问题，新记录是回答；不同选择对应互斥的扩张 | **P1 ⟹ 不传信；此外原则不限制**（§2） |
| C. 全局世界必须是偏序 | 若干两两回答的先后问题能否拼成一个偏序 | 循环核产生违背；η = max(0, 3q − 2)（F25）——这是**因果不等式**型，不是 Bell/KS 型（§3） |

F24 说"上下文性 ⟺ 加细不有向"只对位置 A 成立。现实里的 Bell/KS 上下文性属于位置 B：每次测量产生新的记录（p-ZFC：独立性就是扩张，新样本不在原世界里），
上下文性问的是：不同设置下的回答律能否是同一个全局律的边缘。

## 2. 位置 B：原则给出恰好是"不传信"（命题 QB1）

- **P1（律层面的读法）⟹ 不传信**：设 Alice 的世界 W_A 包含她的设置与回答，不包含 Bob 的设置（类空）。M4 本身只说已有记录的事实不被扰动；把它读到律层面——**一个世界里记录的律只由这个世界决定，不依赖别处发生哪一种扩张**——就得到：她的回答的边缘律不能依赖 Bob 的设置。
  注意：这需要把"设置"当作可替换的扩张（干预）。
- **自由选择的定义（用 p-ZFC 的新鲜样本）**：Bob 的设置记录 s_B 相对 Alice 的世界 W_A 是**自由的**，若它是 W_A（连同两者的共同过去）上的新鲜样本——p-ZFC：新鲜样本避开该世界里一切事先可描述的点集；"独立就是扩张"。于是"不传信"的精确形式是：**W_A 上记录的律，在把 W_A 之外的新鲜扩张换成另一个新鲜扩张时不变**。这把 M4 的律层面读法落到一个已定义的概念上；Bell 型论证里的"测量独立性"就是设置对隐藏结构新鲜。
- **此外原则不限制**：局域性（Bell 因子化）已不是原则（W10）。D1 约束的是实际记录的律（一个全局的随机结构），它不提供反事实设置下的回答；
  回答的标记可以通过全局结构以非局域的方式关联。所以框架允许**整个不传信多面体**，包括 PR 盒（CHSH = 4）。
- **地位**：量子集合（CHSH ≤ 2√2）比框架允许的小。量子限制因此是**另加的原则或偶然的律性质**，框架本身不强制它。这与 p-ZFC 一致：任何在重叠处相容的律族都可以出现。

## 3. 位置 C：F25 的正确读法

F25 的三个语境各只回答一对先后，三个问题两两**不**可同时回答。若全局候选允许任意的回答组合（包括成环的），全局律总是存在；
η > 0 只是因为**全局世界必须是偏序**（P1）。所以 η = max(0, 3q − 2) 度量的是"与确定因果序的不相容"——正是过程矩阵理论里因果不等式的类型（Oreshkov–Costa–Brukner）；
三方的经典非因果过程（Baumeler–Wolf）与之相近。它与 Bell/KS 上下文性不是一回事。标准量子理论遵守确定的因果序；过程矩阵可能违背因果不等式，其物理可实现性有争议。

## 4. 量子限制从哪里来：一个与框架对接的候选（命题 QB2，候选）

**排他性原理**（Cabello 等）："两两互斥的命题，概率和不超过 1"。它的核心是 Specker 的观察："两两可判定的命题是联合可判定的"。
排他性原理加两条附加假设恰好挑出 CHSH 的 Tsirelson 界；其图论形式（Cabello–Severini–Winter）以排他图的 Lovász 数给出量子界。它不能完全刻画量子集合（已知有"几乎量子"的反例），但排除 PR 盒。

**在框架里的翻译** 两个可能的记录**共存**，若有某个世界同时包含它们。Specker 条件就是：**一组可能的记录能共存，当且仅当它们两两能共存**——共存复形是**旗复形**（由边决定，Helly 数为 2）。
- 这是 F8 的语言：F8 研究的正是"哪些事件族能被一并记录"的共存复形与 Helly 数。在单一历史、汇合分支内，任何有限记录族都共存（有向），旗性质平凡成立。
  在位置 B（互斥的扩张之间），旗性质是一个实质约束。
- **候选原则 P6（共存由成对决定）**：可能的记录的共存复形是旗复形。它 ⟹ Specker 条件 ⟹（加排他性的概率公理）排除 PR 盒、在 CHSH 上给出 Tsirelson 界（按文献所需的附加假设）。
- **与已有结构的张力**：F8 表明加速宇宙里视界足迹的共存由 d + 1 元组决定（d ≥ 2 时不是旗复形）。但那是"哪些实际事件能被同一观察者记录"，
  P6 说的是"哪些可能的回答能同时出现"——两种共存。它们是否应当服从同一原则，是需要判断的问题（我倾向于不同：前者关于访问，后者关于存在）。
- **地位**：P6 是加上去的（偶然的），与 P5 同类。它的价值在于把量子限制表述为一个关于记录共存的组合性质，而不借用希尔伯特空间。

## 5. 其他量子特征的位置（只列地位，不作推导）

| 特征 | 框架里的位置 | 状态 |
|---|---|---|

| 不相容的测量 | 互斥的扩张（位置 B）；同一世界内则需加细不有向（位置 A） | 已有位置 |

## 6. 结论与下一步

- 框架目前对量子的立场是清楚的：原则给出不传信；Bell/KS 型上下文性被允许但不被限制到量子；因果序型的违背可由循环核产生（F25）。
- 量子限制的一个无希尔伯特空间的候选是 P6（共存由成对决定），它把 Tsirelson 界与 F8 的共存复形接在一起。
- 下一步：(i) 在位置 B 写出一个具体的扩张律族，看 P6 能否作为扩张律的性质被检验；(ii) 干涉与 Born 型权重在记录语言里的形式（p-ZFC 的"扰动 ⟹ 干涉"、"对称性强制权重"）。


## 7. 三个界的数值（`calc/q3_exclusivity_bounds.py`）

排他图：顶点 = 事件（可能的记录），边 = 两者从不共存。三个量对应三种全局要求：

| 图 | α（存在一个回答所有问题的全局世界） | θ（Lovász 数） | α*（排他性只用于团） |
|---|---|---|---|
| KCBS 五边形 | 2 | 2.23607（= √5） | 2.5 |
| CHSH（8 个获胜事件） | 3 → CHSH = 2 | 3.41421 → CHSH = 2√2 | 4 → CHSH = 4 |

- 经典界 = 存在一个全局世界（p-ZFC 的全局截面）；不传信的上限 = 只要求团上的排他性；量子界 = θ。
- CHSH 图是顶点传递的，θ(G)·θ(Ḡ) = 8（数值核对）。Cabello 的两份论证：G 与其补图的"对角"事件 (i, i) 两两互斥，所以 Σ pᵢqᵢ ≤ 1；
  若补图的实验能达到它的 θ，则 G 上总和 ≤ θ(G) —— Tsirelson 界。**这里用到的正是 P6 型的"成对"原则作用于乘积实验**；单份实验上排他性只到 4。

## 8. Born 型权重：θ 体（命题 QB3，引用 + 读法）

在 Cabello–Severini–Winter 的图方法里，一个排他图上**量子可实现的概率分配恰好构成 θ 体 TH(G)**，其点由正交表示给出：
每个事件对应一个单位向量，互斥的事件对应正交的向量，概率 = 与一个态向量内积的平方。
- **读法**：希尔伯特空间在这里不是输入，而是"两两互斥结构 + 概率"的几何：给定排他图，与 P6 型原则相容的最大分配集合就是 θ 体（排他性原理是否在一切图上精确给出 θ 体，是文献里的开放问题）。
- **p-ZFC 的对称性强制**：在对称的语境里（一组回答被律的对称性传递地置换），θ 体里对称的点给出均匀权重 1/n——"随机袜子"。
- **地位**：Born 型权重在框架里是"候选原则 P6 + 概率公理"的推论，候选原则本身是偶然的。

## 9. 干涉：Sorkin 层级（命题 QB4，读法）

- **分块权重是可加的**（D1：粗层权重是细层权重的平均）：在同一世界的描述里没有干涉，Sorkin 的二阶干涉项 I₂ = 0。
- 干涉（I₂ ≠ 0）只能出现在**没有被记录的互斥替代**之间：它们不在任何世界里，按 p-ZFC"事实粘合、存在不粘合"，它们的权重不必相加。这与 p-ZFC 的"在公开的世界里，扰动表现为干涉"一致。
- 量子理论的特征是 **I₃ = 0**：测度由成对的干涉项决定，没有三阶干涉（Sorkin 1994）。

**一个统一的观察（假说）** 量子结构的两个已知刻画都是"**成对决定**"：共存由成对决定（Specker/排他性 → θ 体、Tsirelson 界），干涉由成对决定（I₃ = 0）。
在本框架的语言里，这两条都是 F8 意义上的"**Helly 数为 2**"。与此对照：视界的共存 Helly 数是 d + 1（F8），循环团违背因果不等式（F25）——框架自身的机制给出的都是"超过成对"的结构。
所以候选原则可以统一写成 **P6′：可能记录之间的一切组合关系（共存、干涉）由成对关系决定**。它是偶然的；它是否能单独推出量子集合，是开放问题。
