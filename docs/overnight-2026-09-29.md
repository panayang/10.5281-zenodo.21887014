## A. 引力的几个方向（`docs/gravity-directions.md`）

| 机制 | 结果 |
|---|---|
| 公开计数 | 无空间衰减：每个内容事件最终在所有后来者的过去里，不被稀释 |
| 独占量子（直线 / 扩散吸收） | 1/r²；有吸收时屏蔽成汤川型 |
| 局域共识（窗口内平均） | 调和：1 维线性、2 维对数、**3 维 1/r**（数值，残差 0.034 / 0.028 / 0.063） |
| 沿链接交换 | 因果序的链接太非局域，势被完全抹平（数值） |
| 最小二乘粘合 | 同局域共识；L² 是选择 |

**最有原则性的一条（§5）**：A5（只有 σ 的差可观测）= 平移不变 ⟹ **禁止质量项**；加上局域（马尔可夫）+ 分块求和的中心极限 + 各向同性，
长距离领头项只能是 (∇σ)² ⟹ 给定内容时 σ 的期望调和 ⟹ 三维 1/r。无质量场是粗粒化的不动点（数值：有质量时屏蔽长度 8.81 → 4.96 → 2.51 流走，无质量不流动），P4 重新有了选择力。
**自由下落（§7）**：节拍最多的链在 σ 梯度中落向钟慢处，中点偏移 19.52 ± 0.99、36.46 ± 0.97，精确测地线 19.49、36.34。
**所以牛顿引力的两半都有了从原则出发的草图。**

**缺口（诚实）**：光偏折的空间一半（γ = 1）。只改变速率的动力学是 Nordström 型的（γ = −1，不偏折）或只改时间（γ = 0，一半偏折，旧版正是如此），都已被排除。
必须让内容**改变序本身**。一个诱人的想法（用 A3 补上这一半）检验后**否定**：A3 作用于光学尺寸只是时间膨胀的推论，定不了 γ。
候选是张量路线（我们的个体化不变 ≈ 微分同胚不变），但它最容易从后门引入 GR，今晚没有推完。γ 已写成一个纯计数的检验（§10）。

**源是什么（§12，`calc/g4_source_coupling.py`）**：一般线性响应下 γ = −b/(a+b)。"源 = 内容事件计数"（洛伦兹不变，因果集最自然的源）只耦合迹 ⟹ γ = −1，且辐射既不产生引力也不被偏折，被观测两次排除；所以源必须是相对观察者的能量。束缚系统的源在框架里良定义（F1 使速率比是事实，Laue 定理使远场只依赖总能量），但定不了 γ。**γ 只由未束缚的无质量内容决定**——恰是框架最弱的对象（无内部节拍、速率隐藏）。规范不变张量给 γ = 1/(D−3)，γ = 1 是 3+1 维特有的。

**更正一处自己的判断**：先前说"宇宙学与局域引力来自不同方面"，那只属于公开计数机制；随机场路线里两者可以统一。

## B. 放宽"世界对过去封闭"（`docs/law.md` §7）

空心三角的 27 种局部合法配置中：19 种能粘合，**2 种因果循环，6 种传递性缺口**（a≺b≺c 但 a、c 无关）。
所以放宽后出现的"不定因果序"主要是**因果不再全局传递**，循环只占少数。代价：F7–F9 的定理不再成立；需要新约束防止可观测的悖论（关于关系的"报告"也不能共存）。
p-ZFC 的"任意形状"（非良基、可循环）种类正好是它的归宿。与观测相容（单个观察者看不到），但也因此难以检验。
**续（§7.1）**：传递性 = "影响可以中继"；缺口需要原则上不可中继的影响，我倾向于视为副作用。保留中继后，循环退化为**不能加细成偏序的团**——一种来自结构而非尺度的分辨率下限，与分块读法（D18）接得上；商掉团后 F7、F8 直接成立。建议把放宽收窄为这一种。
