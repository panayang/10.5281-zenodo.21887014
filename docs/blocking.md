# 分辨率作为分块：嵌入 + 影子（D18）

> 2026-09-29。取代 `docs/refinement.md` 里"加密 = 嵌入"的选择（那一版相当于 RG 的抽取，保留作对照）。
> 只用计数比。没有最细一层，没有背景，没有量纲性的量。

## 1. 为什么改

分辨率为 δ 的记录不会挑出一部分事件，而是把 δ 以内的事件**合成一个**记录。所以粗事件是细事件的**簇**，
粗层里两个簇之间的关系一般只对部分成员成立——它是一个**权重**，不是 0/1。
p-ZFC 的粘合框架里，加密本来就是一对"嵌入 + 影子"（复合为恒等），并且"加密迫使值代数变为非负实数"。
嵌入版只用了一半。

## 2. 定义

**分块分辨率系统** 有向集 Λ（层）。每层 λ 有一个可数的**簇**集 `C_λ`。对 `λ ≤ μ`（μ 更细）有
- **影子**（投影）`π : C_μ → C_λ`，满射：每个粗簇是一些细簇的并；
- **份额** `m(X') > 0`，对每个粗簇 X 有 `Σ_{X' ⊂ X} m(X') = 1`：细簇在粗簇里所占的比例（计数比，不是绝对大小）；
- **权重** `w_λ(X, Y) ∈ [0, 1]`：X 的成分先于 Y 的成分的比例。

**相容性（塔性质）** `w_λ(X, Y) = Σ_{X'⊂X, Y'⊂Y} m(X') m(Y') w_μ(X', Y')`：粗层权重是细层权重按份额的平均。
**无底**：每一层都有真加细。
**嵌入** 把粗簇 X 送到它在细层上的份额分布；影子 ∘ 嵌入 = 恒等（p-ZFC 的形式）。
粗层的**锐利序**：`X ≺ Y ⟺ w(X, Y) = 1`（可验证是偏序）。

**过程** 在每层是一条由簇构成的链，并在每个簇里有一个**份额** `m_P(X)`（过程在该簇中的成分比例），跨层可加。
过程的"节拍数"不是它经过的簇数，而是份额之和。

## 3. 命题

**命题 B1（连续极限存在：Doob）** 取两条嵌套的簇序列 `X_λ ⊃ X_μ ⊃ …`、`Y_λ ⊃ Y_μ ⊃ …`，按份额随机选取。
由相容性，`w(X_λ, Y_λ)` 是关于加细的有界鞅，所以**几乎必然收敛**。
- 极限点（嵌套簇序列）构成"连续统"；它是极限，在 p-ZFC 的意义上是**局部**的，不是背景。记录永远是簇。
- （2026-09-30 补充）"几乎必然收敛"是关于**律**（各层相容的权重族）的陈述；任何一条具体的嵌套簇列及其极限值都是样本，是局部的完成物。全局的只有各有限层的记录与跨层的律；"光滑连续统"是相对某个完成了的加细路径的对象。
- 若极限几乎处处取 0 或 1，系统就有一个**锐利的连续极限序**（除一个零测集，即"光锥上"的模糊部分）。
  这是对系统的一个可检验条件，不是预设。
- 这就是 p-ZFC 的"有向语境上的加权粘合就是 Kolmogorov 定理"：全局描述存在且唯一。

**命题 B2（σ 不变，但由份额承载）** 两个过程在对齐区间上的速率比 = 份额之和的比。份额跨层可加，所以比值与层无关（σ 不跑动，红移消色差）。
**注意**：两个过程经过的**簇数**之比不是 σ——那是分辨率的假象。嵌入版里两者碰巧一致，分块版里必须区分。

**命题 B3（F14 保留）** 以份额计的互窗口之比仍趋于速率比（同一带形论证，计数换成测度）。

**命题 B4（可区分性不再是按钮；结构逐渐显现）** 粗层里两个簇"不可比"（`0 < w < 1`）可能只是分块的假象：
加细后子簇之间可以全部可比。反过来，两个过程若落在同一个簇里，它们在该层根本不可区分。
所以嵌入版的命题 1（可区分性一旦成立就永远成立）在分块下**不成立**。取而代之的是：
**未分辨份额**（落在模糊权重上的份额）是一个鞅的函数，随加细平滑变化，极限由 B1 给出。
结构不是在锐利阈值处出现，而是在一个分辨率范围内**逐渐显现**。

**命题 B5（过程被粗层钉住）** 过程在细层的实现位于它在粗层经过的簇之内，涨落被关在簇里，不随持续时间累积（同嵌入版命题 3）。

**命题 B6（合并与分离）** 两个过程窗口为 W（以份额计）。簇的尺度远大于 W 时它们落在同一簇里（合并）；远小于 W 时分离；
中间是一个平滑的过渡，其形状由窗口附近的权重决定。"能标 × 尺度 ≈ 1"仍成立，但只作为过渡的**中心**，不是锐利阈值。

## 4. 与物理实在的对应

| 陈述 | 对应 | 强弱 |
|---|---|---|
| B1：连续统是加细的极限，存在性由鞅收敛保证 | 宏观物理是光滑的，不需要最小长度 | 结构性 |
| B2：σ 由份额承载，不随分辨率变 | 红移消色差 | 强 |
| B3（= F14） | 两座钟互相雷达测距，读数之比 = 红移因子 | 强（纯序恒等式） |
| B4、B6：结构在一个分辨率范围内逐渐显现 | **形状因子**：质子等复合体的内部结构随探测分辨率平滑显现，不在锐利阈值处跳出 | 定性，比嵌入版的锐利阈值更像现实 |

## 5. "关系强度"与它如何跑动（下一步，不预设形式）

嵌入版里没有任何东西像耦合常数那样跑动；分块版里**权重**会随分辨率变。两个候选的内禀"关系强度"：
1. **模糊份额**：A 与 B 之间落在 `0 < w < 1` 上的份额——"还没被分辨的那部分关系"；
2. **直接影响**：A 的簇与 B 的簇之间、中间没有任何正权重簇的关系所占的份额——中间的内容会"屏蔽"直接影响。

**命题 B7（纯几何只给幂律；标度论证）** 在没有额外结构的测试序里，簇之间的权重只在光锥附近模糊，远离光锥处为 0 或 1。
光锥是余维 1 的边界，被它切到的簇在尺度为 L 的区域里约占 `δ/L`。所以两个候选"关系强度"的分辨率依赖都是
`(簇尺度 / 窗口)¹` 型的幂律，指数 = 光锥的余维数 = 1，与时空维数无关。
**条件性推论**：若某个关系强度随分辨率**对数**变化，它必须来自在许多分辨率上都有分布的额外内容（中间的其他过程）。
这是条件句，不预设内容如何分布（D17）。现实对照：规范耦合对数跑动；在这个框架里，那需要"每个尺度上都有内容"。

要做的：在测试用的序上把它们作为跨层比（簇尺度 / 窗口）的函数算出来，**看算出来是什么**，再与物理比较；
先核对 B7 的幂律指数，再加入分布在多个尺度上的中间内容，看跑动的形式如何改变。
一个需要检验而不是假设的预期：纯几何（没有额外结构）的测试序是尺度无关的，只能给出关于"簇尺度 / 窗口"的幂律；
对数型的跑动若出现，必须来自在各个分辨率上都有分布的额外内容。
