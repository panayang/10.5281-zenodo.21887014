# 术语表（一行一个；一个词只指一件事）

- **记录**：语境中一个可数的、被记下的事实（一个事件、一次计数、共存事件间的一个序关系）。全局的。
- **语境**：一个观察者可以问的问题族及其已有记录；p-ZFC 意义上的"世界"在物理里的对应。
- **序 / 因果序**：事件之间的偏序 `a ≺ b`（a 在 b 的过去光锥里）。
- **链 / 世界线**：全序的事件序列；这里指一个过程的节拍。
- **线性延拓（个体化）**：与因果序相容的全序排列；物理上是"一种全局时间排序"。时间是个体化，不是原语。
- **序不变测度**：线性延拓上的概率测度，给定前 k 个元素的集合时，它们的每种相容排序等可能（Brightwell–Luczak；p-ZFC 称"中心线性化"）。
- **刚性**：序不变测度唯一；等价于中间时刻的速率不依赖终点（同时面）。
- **同步窗口 W**：在某一时刻，另一条链上与它类空（不可比）的那一段的长度。
- **经过时间 P**：从起点算起的固有时。
- **无标度同步**：`W/P` 不趋于 0。p-ZFC：刚性 ⟺ `W/P → 0`（凹包络条件下）。
- **速率比 / σ**：两条链的渐近固有时之比；σ = 它的对数。永远是一对之间的量，只有比值有意义（旧 A5）。
- **结构事实**：由因果序唯一决定的量（例：束缚对之间的速率比、Doppler 因子）。
- **隐藏参数**：序不决定、但在所有个体化下作为全局参数出现的量（例：退行对之间的速率比）。
- **快度 η / φ**：`η` 是两个观察者的相对快度（Doppler 因子 `e^η`）；`φ` 是用来切片的标架的快度。
- **切片**：一族同时面（时间函数的等值面）；"渐近切片"指它在远处决定的各链速率比。
- **律 / 样本**：律是关于可数记录的全局描述；样本是它在某个语境里的实现。（D16：律不是给定的流形。）
- **加密系统**：一族可数偏序与嵌入（粗的一层是细的一层的子序），没有最细一层；连续统是其极限。
- **能标**：两层之间计数比的对数；与 σ 同类型，只有比值有意义。
- **束缚 / 退行**：相对运动有界 / 相对距离无界增长（窗口有界 / 窗口随时间增长）。
