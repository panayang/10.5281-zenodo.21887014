# 序与速率：因果序什么时候决定一个时间（短版草稿）

> 2026-09-29，内部草稿，整合 `docs/findings.md` 的 F1–F9。
> 写法约定：定理只用本框架的原始概念陈述（事件、偏序、链、窗口、记录）；
> 广义相对论的几何只作为**对照例子**，说明某一类内禀性质在哪里出现；不把 GR 或量子理论当作规律的形状。

## 摘要

我们以两个原始概念出发：事件之间的**偏序**，以及过程（链）之间的**相对速率**。
不假设全局时间、全局事件集或全局态；这些东西只在满足条件时作为结论出现（同作者的 p-ZFC 思路）。
主要内容有三块。
(1) 两条链之间的**窗口**（一条链上与另一条链某元素不可比的元素个数）按增长方式分四类：次线性、线性、超线性、无穷。
次线性时相对速率被序唯一决定；线性时速率成为全局隐藏参数，其取值区间的端点本身是序的事实；无穷窗口时共同上界消失。
(2) 取"世界 = 一个事件的过去"，p-ZFC 的记录系统就由偏序本身实现：汇合公理 .2 等价于有向性，
一族事件能否被一并记录由"共存复形"刻画，局部记录上的律能否粘成全局律由该复形的无环性决定。
(3) 对照：这四类窗口恰好出现在相对论里的束缚、退行、减速膨胀、加速膨胀四种情形；
狭义相对论里"Doppler 因子不变、时间膨胀依赖参考系"正是"序的事实 vs 隐藏参数"。
数学上多为朴素结果或已知定理的推论，价值在于把"时间何时存在"变成一个关于偏序的可判定问题。

## 1. 原始概念

- **事件与序**：集合 E 上的严格偏序 ≺（`a ≺ b`：a 能影响 b）。只要求局部有限。
- **链**：全序的事件序列 `a_1 ≺ a_2 ≺ …`，代表一个过程的节拍。节拍数就是这个过程自己的时钟读数。
- **线性延拓（个体化）**：与 ≺ 相容的全序排列。一个"全局时间"就是一种个体化；它不是原语。
- **序不变测度**：线性延拓上的概率测度，给定已排出的元素集合时，它们的每一种相容排序等可能。
  它代表"不偏好任何个体化"（这是一个读法，登记为 R1）。
- **速率比**：两条链沿一个线性延拓的节拍数之比的极限。σ = 它的对数。只有比值有意义。
- **记录与世界**：事件 p 的世界是它的过去 `↓p = {e : e ⪯ p}`；p 的记录是关于 `↓p` 中事件的事实。
  世界沿序增长，已有记录之间的关系从不改变（p-ZFC 的 M4 在这里自动成立）。

## 2. 两条链：窗口的四分类

设 A、B 是两条链。对 A 的第 i 个元素 `a_i`，B 中在它之前的元素构成一个前缀，在它之后的构成一个后缀，
中间与它不可比的一段记为**窗口**，长度 `W(i)`。窗口完全由序决定。

A、B 并起来的子偏序的线性延拓，就是 (i, j) 格点平面上一条单调路径（i、j 为已排出的 A、B 元素数），
它必须留在由窗口决定的**容许区域** R 里。

**定理 1（速率 = 窗口的渐近斜率）** 设 R 的下、上边界 `lo(i)`、`hi(i)` 满足 `lo(i)/i → s₋`、`hi(i)/i → s₊`。
1. 任何线性延拓的速率都落在 `[s₋, s₊]` 中。
2. **次线性窗口**（`W(i)/i → 0`，于是 `s₋ = s₊ = s`）：一切个体化的速率都等于 s——**速率是序的事实**。
3. **线性窗口**（`s₋ < s₊`）：对每个 `s ∈ (s₋, s₊)` 都存在速率为 s 的序不变测度。
   显式构造：每步以概率 p 排 A、以 1−p 排 B 的 Bernoulli 游走，条件在"永远留在 R 内"；
   前缀概率只依赖终点，故序不变；漂移 `(1−p)/p = s` 严格在区间内时生存概率为正。
   端点 `s₋`、`s₊` 本身是序的事实（节拍计数之比）。
4. **超线性但有限的窗口**：同 3，区间无上界（或无下界）。
5. **无穷窗口**（`a_i` 与 B 的整个尾部都不可比）：`a_i` 与 B 的后段没有共同上界（见 §4）。

**已知部分** 有界窗口 = 有界不可比，此时序不变测度唯一（Brightwell–Luczak）；
凹窗口且 `W/P → 0` 时唯一（p-ZFC 相变定理）。定理 1 的 1–4 本身是初等的。

**数值** 精确计数（对数域逐行累加）确认：有界窗口时中间时刻的速率不依赖终点；线性窗口时极值外推后与 `s₊`、`s₋` 吻合到三位有效数字
（`calc/t1_rigidity_map.py`、`calc/t2_rapidity.py`）。

## 3. 多条链：隐藏参数的维数

k 条链时，序不变测度的渐近速率向量填满容许区域的渐近锥。三条两两"线性窗口"的链给出二维的隐藏参数族；
若其中一对是次线性窗口，这一对的速率比被锁定，维数降为一。
（数值：`calc/t4_three_chains.py`，N = 120、240 时终点取在任意容许方向都能在中间重现；这里的一般陈述是猜想，
两链情形由定理 1 给出，p-ZFC 的多链定理给出同样的维数计数。）

**读法** 隐藏参数不是某个特殊的"参考系"，而是"如何切分同时性"的渐近自由度；
在对照例子里，惯性参考系只是其中一条曲线。

## 4. 记录系统：汇合与共存

**定理 2（汇合 = 有向）** 以"世界 = 过去、扩张 = 序"构成的记录系统满足 p-ZFC 的汇合公理 .2，
当且仅当任意两个事件有共同上界（有向性）。有向时，沿记录变化有限次的问题有唯一的极限答案（p-ZFC 稳定化定理）；
不有向时，"极限"记录的是所走的路径——**最终能知道什么取决于走哪条链**。

**推论**（假设每个事件的过去有限）若两条链之间的窗口处处有限，则两链上任意两个元素有共同上界：`a_i` 之前的 B 元素只有有限个，窗口也有限，所以 B 的尾部都在 `a_i` 之上，它们同时也在 B 的任何更早元素之上。窗口无穷是汇合失效的内禀征兆。
所以定理 1 的四类窗口里，前三类（次线性、线性、超线性有限）都与汇合相容，只有无穷窗口破坏它：
**刚性（唯一时间）⊂ 汇合（记录可合并）⊂ 一般**，是 p-ZFC"全局性分层"在偏序上的样子。

**共存** 一族事件**共存**（能被某个世界一并包含）⟺ 有共同上界。共存的事件族构成一个单纯复形。
- 在"足迹型"偏序里（每个事件对应无穷远处的一块凸区域，两事件有共同上界当且仅当区域相交），
  共存复形就是这些凸区域的神经：由 Helly 定理，判断只需检查每 d+1 个；由 Wegner 定理，只能出现 d-Leray 复形。
  这里 d 是足迹所在空间的维数（`calc/t6_coexistence.py`，精确判据，0 次违例）。
- 把极大共存族当作"语境"，局部记录上的律能否粘成全局律，由语境超图是否 α-无环决定（Vorob'ev；
  Beeri–Fagin–Maier–Yannakakis）。d = 1 时足迹是区间，超图总是无环，**局部一致的律总能粘合**；
  d ≥ 2 时不一定（Rust 计算，每种 5 万个覆盖：d=1 全部无环，d=2 约 63–73%，d=3 约 51–57%）。
  注意：若每个事件带一个与"谁来记"无关的记录，全局律平凡存在；这一条说的是偏序**允许**的粘合失效。

## 5. 对照例子（不是前提）

用相对论里已知的因果序检验上面四类窗口出现在哪里：

| 对照情形 | 窗口类 | 结论 |
|---|---|---|
| 相对静止或束缚运动的两个观察者 | 有界 | 速率比是序的事实（红移；振荡运动的 ⟨1/γ⟩） |
| 相互退行的两个惯性观察者（快度 η） | 线性，端点 `e^{±η}` | Doppler 因子 `e^η` 是序的事实；时间膨胀随切分同时性的方式变，区间恰为 `(e^{−η}, e^{η})` |
| 减速膨胀宇宙 `a ∝ t^p, p<1`，共动观察者 | 次线性（`W ∝ t^p`） | 宇宙时是序的事实（精确窗口最终凹，测度也唯一） |
| 匀速膨胀（Milne，p=1） | 线性 | 没有由序决定的宇宙时；记录仍可合并 |
| 加速膨胀（p>1、de Sitter） | 无穷（事件视界） | 汇合失效；共存由视界足迹的神经决定 |

这些例子表明四类窗口都是"真实地出现"的；它们不是本框架的出发点，本框架也不依赖其中任何一个的动力学方程。

## 7. 账目

- **已知的**：有界不可比 ⟹ 测度唯一（Brightwell–Luczak）；闵氏因果序的逻辑为 S4.2（Goldblatt）；Helly、Wegner、Vorob'ev/BFMY；
  p-ZFC 的隐藏速率与相变定理（纸面证明）。
- **本草稿的**：窗口四分类及其与"序的事实 / 隐藏参数 / 汇合失效"的对应；线性窗口下区间的显式构造；
  刚性 ⊂ 汇合 的分层；共存复形与粘合的对应；对照例子的计算。数学本身朴素，新意在对应关系。
- **没有的**：动力学（什么决定序本身）；物质；能标。
- **与旧版 SCD 的关系**：旧版的核心直觉"能标与尺度相关"在这里只落实了一半——
  "尺度"是链之间的对数速率比；"能标"（分辨率）还没有进入。这是下一步（B）。

## 8. 下一步（B）：分辨率作为第二种扩张

p-ZFC 有两种扩张：宽度（同一层加记录）与高度（加层）。本草稿只用了一种（沿序向未来）。
候选：**高度 = 加密**——同一段过程在更细的分辨率下有更多节拍，粗的序嵌入细的序。
要回答的问题：窗口类、速率、共存在加密下怎样变；"能标"能否定义为加密方向上的位置；
沿加密方向变化有限次的问题（"某结构是否可分辨"）是否有唯一极限（汇合）。

**初步结果**（取高度 = 民主粗粒化：每个事件独立地以概率 q 保留，不需要几何）：
- 速率比与窗口类在粗粒化下不变：**尺度不跑动**；
- 随分辨率变化的是**内容**：窗口长度为 W 的一对过程，在 `q·W ≈ 1` 以下合成一个过程。
  要分辨尺度 W 的结构，节拍密度至少要到 1/W——这是"能标 × 尺度 ≈ 1"的内禀版本，只用计数推出（F10）；
- （条件性）若存在最细层且过程取为最长链，可区分性还依赖持续时间：`ρ ≳ T⁴/d⁶`（F11）。

**地基修正（D16）** 离散而无尺度：每一层记录可数，加密没有最细一层，连续统是极限。能标 = 跨层计数比的对数，与 σ（跨过程计数比的对数）同类型，只有比值。
