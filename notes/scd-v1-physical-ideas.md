## 0. 核心直觉：能标与尺度是同一件事

**【思想】** 局域能量标度 = 局域长度标度的倒数（A3：`ε·s = 1`）。来源据原文是"把
Heisenberg 关系和 Einstein 方程并排放"：`E·L ~ ħc`（康普顿/不确定性），以及引力红移
（局域测得的能量随局域单位反比变化）。由此希望：
- 引力 = 标度的非均匀性（位置依赖的单位）；
- ħ = 沿标度轴的一步；
- 粒子内容 = 在某个分辨率上的"截面"（重整化群、有效场论阈值）；
- 宇宙学 = 标度整体在跑。
"统一"不是把力塞进一个群，而是它们是**同一个量的不同读数**。

**【判定】** 直觉本身站得住，而且物理学里有几处严格实现了它（见 §9）。旧版的毛病是
"尺度"一词同时指**三种不同的东西**：
- (a) 位置依赖的度规单位（共形因子、引力红移）；
- (b) 观察者/探针的分辨率（RG 的 μ、粒子阈值）；
- (c) 宇宙学尺度因子 a(t)。

A3 对三者**单独**都成立，所以直觉上"统一"了；但 (a) 依赖位置、(b) 依赖探针，它们是
不同的变量。旧版里三者住在互不相通的类型里（据其自查：一度 59/107 个文件从不提公理代数；
"逃到实数"这件事重复发明了 8 次，没有任何定理把其中两次联系起来）。

**【可用性】** 重写的第一原则：**明确区分 (a)(b)(c)，然后用一个结构把它们真正连起来**，
而不是靠同一个名字。

## 2. 几何与引力扇区

### 2.1 "引力是尺子在变，不是空间在弯"
**【思想】** 不假设弯曲流形；假设平直记账 δ 加标度 σ，物理线元 = 裸线元用局域单位重读，
`g = e^{2σ}δ`。曲率 = 标度的二阶非均匀性。潮汐 = 尺子的二阶变化；一阶（整体缩放）
不可观测，正是 A5。
**【旧版做法】** `Conformal.lean` 用代数方式算出共形平直度规的 Christoffel、Riemann、Ricci
（教科书恒等式，形式化干净）。标度联络 `A = dσ` 可积，所以没有 Weyl 的"第二钟效应"。
**【判定】** 共形平直度规就是 **Nordström 标量引力**（1913；Einstein–Fokker 形式 `R ∝ T`）。
它不偏折光、近日点进动符号错。旧版自己的 `Frame.isotropic_reciprocal_forces_flat` 就说明了
**单个标度撑不起引力**。

### 2.2 方向标度与 Schwarzschild："时钟压缩多少，径向尺子就拉伸多少"
**【思想】** Schwarzschild 的 `g_tt·g_rr = −1` 在标度语言里是 `s_t·s_r = 1`（倒数性）。
**【旧版做法】** 引力链：对角度规 → Levi-Civita 联络 → R_tt、R_rr → 组合消去 →
`σ_t' + σ_r' = 0` → `s_t s_r` 为常数 → 取 1 → PPN γ = 1 → 1.7515″、42.99″/世纪。
- 消去的结构性解释：该组合只由**横向**方向贡献，前因子是横向标度梯度之和
  （areal 坐标下为 `(n−2)/r`）。"一对方向不携带自己的曲率，由补集携带"。
- `2β = 1 + γ` 由 tt 真空方程得到；把引力扇区读作"用平直 Laplace 当成 h-Laplace"
  会得到 β=1/2 这个陷阱。
**【判定】（本轮用 sympy 验证）**
1. 真空条件 `R_tt = R_rr = 0` 就是**爱因斯坦真空方程**，是借来的；框架自己的源律只是一个
   标量迹方程，定不了度规其余分量。所以 γ=1 等结论是 **GR 的结果**。
2. **"静态"谓词表达的是平面对称，不是球对称。**旧版把"静态球对称"定义为"每个方向标度
   只沿一个方向（径向）变化"，但球坐标里 `g_φφ = r² sin²θ` 依赖 θ。平面情形下完整真空
   （加上横向 `R_22 = 0`）且 `AB = 1` 给出 `f = C/r`：**没有牛顿极限，也不渐近平直**。
   链条只用了 R_tt、R_rr 组合（它与横向曲率 k 无关），所以一直没暴露。
   `NCSize.spherical_static_gives_zero`（"量子修正在 Schwarzschild 构型里为零"）建立在同一错误上。
**【可用性】** "引力 = 单位的变化"作为**动机**可以保留，但必须承认单个标度（共形模）不够，
度规其余部分（因果/共形结构）需要自己的原始地位。见 §9 方向 A。

### 2.3 没有奇点、没有视界
**【思想】** s 是单位（可逆），所以度规永不退化，`g_tt = −s_t² ≠ 0`，红移永远有限。
"黑洞任意黑，但不全黑"；没有因果隔断，没有信息销毁。
**【判定】** 这是**载体选择的产物**，不是推论：在坐标片上的函数环里，"单位"只意味着
"在这片上不为零"。而且与"外部几何与 GR 完全一致"自相矛盾——外部解在 `r = 2M` 处
`g_tt → 0`。
**【可用性】** "无奇点"只能作为需要动力学支撑的**猜想**，不能靠定义得到。

### 2.4 光与因果结构
- 零锥与标度无关（共形不变）⟹ 光子无能量依赖色散（"零阶禁止"）；引力波走光锥。
- 一个度规、一个锥 ⟹ 各扇区之间的 Lorentz 破缺系数全为零。
- 迈克耳孙–莫雷零结果是定理（尺子和光时由同一标度设定）。
- 红移不是光的属性，而是**两个观察者标度之比**（`Observation.lean`，这一条讲得好）。
**【可用性】** "因果结构不看标度、标度只进比值"与 Malament 定理（§9）完全一致，值得保留。

### 2.5 源律与耦合常数
- A6″ `Δσ = Δ·ν`：标度的 Laplacian = 标度周期 × 缺陷数（"Gauss 定律的代数影子"），
  推出 `κ = −2(n−1)Δ`。**判定**：只是把源律代进共形曲率恒等式，系数 −2(n−1) 纯属几何；
  Δ 本来就是任意环元，推导没用到它的任何性质。
- 带号差重做后算符是达朗贝尔算符（双曲），泊松方程是静态极限；标度扰动走零锥。
- **引力源不可能是拓扑荷**（`DegreeSource`）：群上可加且非负的实值函数恒为零，而引力普适吸引
  （反氢往下掉）要求源非负。**只有计数（ℕ 是幺半群）能活下来**。
  这是旧版最扎实、最有指向性的结果之一：**引力的源是计数**，与因果集的"序 + 数"一致。

### 2.6 宇宙学
- A6 耗散 ⟹ `ε(t) = ε₀e^{−λt}` ⟹ `a(t) ∝ e^{λt}`，精确 de Sitter；"暗能量不是物质，是开放宇宙的耗散率"。
- A5 ⟹ λ 为常数 ⟹ w = −1（后撤回：有第二个标度时 A5 只要求依赖于差，w 可以演化）。
- "宇宙不在膨胀，是分辨率在扫描"（`Scanning`）；w 在阈值谱设定的对数尺度上变化（从未算成曲线）。
- 没有第一时刻（标度永不为零），只有"流逝的比值"。
- 局域束缚系统不膨胀：空间均匀的漂移只动常数项，几何只看导数（`Covariance`）。
- 两个时间箭头是一个序（熵 = ρ ln R 的读法下）。
**【判定】** 与代数部分无类型连接；w 的具体预言从未成形。
**【可用性】** "时间是标度跑动的方向"有精确实现：闵氏未来光锥 = `e^{2σ}(ℝ × H³)`，σ 就是
Milne 时间（§9 方向 B）。

## 3. 转动、洛伦兹群与维数

### 3.1 "两个缩放交出一个转动"（旧版称"本理论最硬的一步"）
**【思想】** 缩放 = 纯拉伸 = 对称算子，转动 = 反称算子，两个对称算子的对易子必反称
（Thomas–Wigner 转动、Terrell–Penrose 效应）。"一个方向：平直；两个以上：曲率由缩放自己生成。"
**【判定】** `[p,p] ⊆ k` 是对的（Cartan 分解 gl = so ⊕ sym）。但：
- A4′ 的"每方向一个标度"是**对角**的，对角矩阵彼此**对易**，一个转动也交不出来；
- 旧版的例子 K₁、K₂ 是**非对角**的对称矩阵（boost/剪切），不是"沿某轴的伸缩"；
- 把度规在 GL(n)/SO 里的伸缩与 SO(n,1) 的 boost 混为一谈。真实几何里洛伦兹群是度规的
  **稳定子**，不是它的伸缩部分。
**【可用性】** 正确版本是**标架场（vielbein）** `e ∈ GL(n)`：对称部分是度规/"标度"，
反称部分是局部洛伦兹转动。这是标准的标架引力，把"标度 + 转动"放对了位置。

### 3.2 实秩一 ⟹ 洛伦兹族
**【思想】** 漂移只是一个线性泛函 ⟹ 只有一个标度坐标 ⟹ 极大对易伸缩子代数一维 ⟹ 实秩一
⟹（引用分类）so(n,1)、su(n,1)、sp(n,1)、f₄；只有 so(n,1) 的标度是实比值。
副产品：秩一对称空间 = 双曲空间，其洛伦兹形式是 AdS，标度坐标是径向。
**【判定】** 与 A4′ 的 n 个对易标度**直接矛盾**。但"秩一、唯一的对易方向就是尺度"这个结构有真实对应：
- so(3,1) 在天球 S² 上作共形变换，**boost 在天球上就是伸缩**；
- so(n+1,1) 是 ℝⁿ 的共形群，秩一方向正是伸缩生成元 D；
- H³ = SO(3,1)/SO(3) 是 Milne 切片的空间截面。
**【可用性】** 值得在方向 B 里重新拿起来（§9）。

### 3.3 其余
- 方向是代数的定义表示，不是代数本身（dim so(3,1) = 6 ≠ 4）。
- 记账度规 δ 可由迹型 `κ(x,y) = τ(xy)` 给出（不必另外公设）。
- 号差：漂移方向单独拿出来 ⟹ `1 + (n−1)` 分裂；但**哪个号是类时**没有推出（旗 ≠ 二次型）。
- 旧版后期发现：κ 是在欧氏 δ-迹里算的，可观测量在带 η 的扇区里算的，两者唯一的桥要求
  η ≡ 1，与物理互斥（`TwoMetrics`）。用 η 重算后系数 −2(n−1) 保住，但算符变成双曲的。

## 4. 粒子与标签扇区

- **没有基本粒子**（`Emergence`）："存在什么"是某个分辨率上的截面；任何标度之上都还有
  未分辨的内容；**质量不是物种携带的参数，而是它在标度轴上出现的位置（阈值）**。
- **标签多少度量的是覆盖的对数范围，不是物理深度**（`Slice`）：跨越一个区间的描述必须为
  区间内出现过的所有内容备标签——这正是壳外内容与规范冗余的形状。
- **内部对称只能是标度花样的稳定子**（`Gauge`）：多重态 = 标度简并块；没有独立的内部空间。
- **引力和规范场是一个输运对象**（`Transport`）：单位全不同时输运唯一（引力），有简并时
  输运差一个稳定子元素（规范自由）。
- **粒子是标度场里梳不开的结**：
  - 早期：圆值标度的缠绕数 = 电荷，几何质量塔 `m_k = m₀e^{|k|Δ}` ——被胶球比值和质量谱**证伪并撤回**；
  - 后期：标度是比值所以看不见方向的正负 ⟹ 序参量是**无定向轴**（射影），π₁ = ℤ/2（线缺陷）、
    π₂ = ℤ（点缺陷）⟹ 一个被禁闭的二值荷 + 一个自由整数荷。
  - "颜色 = 3"的尝试失败（几何只给 2），撤回。
  - "带荷必带转动"（`v ∧ ∇v`），"不存在带电的基本自旋 0 粒子"。
- **CV² = 1**：A5 ⟹ 阈值由对数尺度上的常率泊松过程放置 ⟹ 对数质量间隔的变异系数 = 1。
  观测 CV² = 0.875（11 个间隔，63 百分位）。旧版唯一能区分 SCD 与 GR+SM 的预言。
  **判定**：样本太小、手工选取；真正能说的只是"排除等间距塔"。这是一个关于**律**的断言
  拿**样本**去检验（p-ZFC 恰好区分这两层）。
- **跑动**：常密度缺陷积分 ⟹ `g⁻² ∝ t`，即单圈形式；渐近自由 ⟺ 正密度。**判定**：重述，
  系数没有来源。
- **暗物质**：大量低能标激发，引力响、探测器不响（探测器能标由其分辨率决定，A3）。
- **寿命的动量依赖**：γ = E/m 就是两个标度之比读了两遍。

**【可用性】** "内容依赖分辨率、质量 = 阈值位置、标签数 = 覆盖范围"这组思想有价值，它本质上
是 Wilson 式 RG / 有效场论的重新表述。p-ZFC 的"沿记录的稳定化"给出了严格的语言（§9 方向 C）。
拓扑缺陷那一支已被旧版自己的定理（`DegreeSource`）削弱，不建议继续。

## 5. 量子扇区

- **交换 = 经典，非交换 = 量子，是同一条公理的两个区域**（`Quantum`）：内导子 `ad p` 满足
  Leibniz；由 `[X,P] = c` 推出幂法则；Robertson/Heisenberg 不等式。
- **ħ 是标度轴上的一步**（`Crossed`）：位置与标度平移不对易，`[U, M_a] = M_{Ta−a}U`，精确、
  非一阶。后被降格为"归一化"（A3′：标度群与其对偶的配对；自对偶 LCA 群分类给出 ℝⁿ、𝕋×ℤ、有限、adelic）。
- **ℝ 支与 𝕋 支**：实值标度（无缺陷、平直）vs 模周期标度（能缠绕）；"引力选 𝕋 支"。
  后来证明不存在周期标度场：σ 只模周期定义时不是环元素，只有梯度是（梯度闭而不恰当，
  `Circle`/`Torus`）。
- **量子修正 = `[σ_b, σ_e]`，纯反对称**：非交换情形 Ricci 不对称，
  `Ric_{be} − Ric_{eb} = (n−2)[σ_b, σ_e]`，联络无挠，标量曲率完全不动 ⟹ "经典量不受任何阶量子修正、
  G 不跑动、没有 ħG/r³ 修正"。**判定**：没有态、没有 Hilbert 空间、ħ 无来源，只是非交换
  微分代数；此类现象在 Beggs–Majid 量子黎曼几何里有已知同类。
- 算符次序：非交换提升不唯一，差异进入真空条件；静态构型不受影响。

**【可用性】** "经典/量子是同一结构在交换/非交换两区"是常见而合理的动机（形变量子化）；
但真正缺的是**态与概率权重**，p-ZFC 的上下文/加权粘合正对应这一块（§9 方向 C）。

## 6. 观察者、分辨率与动力学

- **动力学 = "什么决定什么"**（`Determination`）：不是"下一刻是什么"，而是一个位形各部分之间的
  决定关系；"一个部分由其补集决定，从不由自己决定"；力 = 补集的贡献；作用反作用 = 影响的对称性。
  二维时没有动力学。
- **观察者 = 已越过的阈值集**（`Observer`）：观察者之间取交就是观察者（格结构）；观察者是一个差
  而不是位置；漂移给出箭头，但横向分辨率是永久的门（第一个不从度规来的"视界"）。
- **内部观察者**：越大的观察者记录越少（条件越多）；观察者的并 = 记录的交；分离的观察者 = 占据
  所有方向的那一个。测量扰动 ⟺ 系统中有相互作用。
- **分辨率 = 双边理想的递减滤链**（`Resolution`/`Layers`）：不相容 = `ad` 在某分辨率下被读出；
  结果 = 不可分辨类；**缺的是类上的权重**（G4）。阈值可从环里算出（Xʲ 的阈值是 j）。
- **观察者与被观察者同类型**（`Vantage`）："分辨率"和"阈值"都是 `Fin n → ℝ`，视角空间是以观察为序的
  偏序集；框架**没有位置空间**，所以"观察者与时空的关系"没有第二项。
- **预层**（`Content`）：代数扇区与实值阈值扇区是同一个预层写了两遍；观察者是反变的预层。
  **size/权重**是缺失的对象，G4 的权重与宇宙学断开是同一个缺口。

**【判定】** 这一整块一直在摸索"语境 + 记录 + 粘合"的语言，但没有现成工具，全靠自建。
**【可用性】** 直接换成 p-ZFC 的框架（§9 方向 C）。

## 8. 方法论教训（重写时必须避免）

1. **载体决定能说什么。**"环 + 导子"只能说局部代数恒等式，于是每个数都要逃到另一个实数文件里。
   先选能表达**解、边界、谱、不等式、不变性**的载体，再谈"最小公理"。
2. **一个词不能承担多件事。**"尺度"指三件事、"方向"一会儿指指标一会儿指位置、"源"指三个不同的整数。
   旧版自己诊断出同一类错误（"用标量推理代替方向结构"）五次。
3. **不要借 GR 的方程再宣称推出了 GR 的结果。**真空 Ricci 平直是 Einstein 方程；算出 γ=1 不是预言。
4. **形式化的"干净"不等于物理内容。**1275 条定理全部 `#print axioms` 干净，但大部分是定义展开、
   教科书恒等式或关于项目自身措辞的元定理。
5. **自审不能代替计算。**9 月以后新增约 35 个文件，大多在审计项目自己的措辞，没有算出任何可观测量
   （这一段是接手后与 Claude 的会话做的，同样的失败模式）。登记册一个文件 3588 行。
6. **"由定义得到"的结论要标明。**无奇点、无视界来自"s 是单位"这个类型选择。
7. **凑数要标明。**A7 为了得到 4 而设。

## 9. 本轮提出的重构方向（2026-09-29，待讨论）

### 9.1 p-ZFC 预印本要点（`reference/pzfc-preprint.tex`，同作者）
- 去掉 GLU₀（"局部数据在唯一全局语境里唯一粘合"）。基础理论 B：ZFC 世界族 + 力迫/秩扩张，
  不假设合并；公理 M4 = "记录不被后来的记录扰动"（可数核心在扩张下不变）。
- **可数记录是全局的**；ℝ、幂集、选择对象这类完成整体是**局部的**。**律是全局的，样本是局部的**。
- 稳定化：沿记录系统，答案改变有限次的问题 = 有限个持久答案的布尔组合；汇合性（.2）⟹ 极限唯一
  （Ershov 层级推广到分支时间）。ZFC 独立命题四分类：可判定 / 预言机位 / 极限可判定 / 开关（如 CH）。
- 上下文性是有限的、算术的粘合障碍；与世界合并相互独立。
- 过程层："事实看得见结构，看不见位置"；**线性时间是个体化的指标**；"谁在问"不是事实。
- **隐藏速率定理 + 相变**：对部分可交换过程，在迹（事件偏序）之外，**唯一的全局隐藏参数是渐近
  相对速率**；它们存在 ⟺ 同步是无标度的（窗口/经过时间 `W/P` 不趋于 0）；否则速率被锁死为相等（刚性）。
- 加权粘合 GLU(π)：权重由对称性强制（"随机一只袜子 = 1/2"）；有向语境上的加权层就是 Kolmogorov 定理。

### 9.2 三个方向
- **A（推荐作主干）序 + 速率 = 几何。** 原始概念：事件偏序（全局记录）+ 对数速率 σ。
  Malament（1977）、Hawking–King–McCarthy（1976）：**因果结构决定度规，只差一个共形因子**——
  这个共形因子正是"尺度"。p-ZFC 的隐藏速率定理是它的离散版。A3 从公理变成定义：
  **能量 = 事件速率**（E = ħω），长度单位 = 速率倒数；红移 = 两条链的速率比；A5 = 速率的整体归一化。
  可检验的结构性命题：**非平凡标度场只存在于无标度同步区；有特征尺度的同步使速率锁死、σ 无梯度、时空平直。**
  与旧版 `DegreeSource`（源必须是计数）和因果集"序 + 数"一致。
- **B（连续极限的对照目标）天球 / Milne。** boost `diag(e^{η/2}, e^{−η/2})` 在天球上作用为 `w ↦ e^η w`，
  无质量粒子能量变为 `ω ↦ e^{−η}ω`——**能量按伸缩因子的倒数变换，即 A3 的群论版本**；Mellin 变换
  ω ↔ Δ 是精确的"能标 ↔ 尺度"词典。闵氏未来光锥 = `e^{2σ}(ℝ × H³)`，σ 就是时间（"时间是标度跑动的方向"），
  H³ 是 so(3,1) 的秩一对称空间。(a)(b)(c) 在这里是同一个单参数伸缩子群在不同切片下的作用。
  文献：de Boer–Solodukhin 2003；Pasterski–Shao–Strominger 2017。
- **C（语言层）** 用 p-ZFC 的语境/记录/粘合框架承载观察者、不相容性和概率权重，取代"一个环 + 一张全局坐标卡"。

**警示先例**：Nottale 的尺度相对论（分辨率当坐标、分形时空）走过相似的路，停在边缘——
正是"位置依赖与探针依赖混为一谈"的教训。
